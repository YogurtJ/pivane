# 微信与消息渠道

本功能为源码候选；安装或更新 Pivane 后，以服务端 `messageChannels` 能力和实际连接状态为准。它把微信 ClawBot 的文字私聊绑定到普通 Pivane 持久线程，网页和微信共用原生上下文、模型、助手身份与工具。当前支持文字、最终回复和 `/stop`；图片、文件、语音、普通微信群、主动通知与微信内交互确认尚未开放。包含其他类型的微信消息不会只取其中一部分交给 Agent，管理页会说明未进入线程。

## 安装与连接

1. 打开 **扩展 → 发现 → 在微信继续对话 → 安装与连接**，或直接打开 **扩展 → 消息渠道**。
2. 点击 **安装微信组件**。安装发生在运行 Pivane 的机器上；确认后才下载组件。默认安装 Pivane 不下载微信平台依赖、不启动微信连接，也不安装完整 OpenClaw 或 Hermes。
3. 点击 **扫码连接微信**，用手机微信扫描页面里的二维码。部分登录需要把手机显示的数字填入验证码框。二维码五分钟过期；离开页面不代表取消服务端登录，可返回继续查看或显式取消。
4. 登录成功后，扫码用户默认进入允许列表。允许用户可以在绑定线程内调用该线程已有的工具，因此只应加入你信任的用户。凭据仅在服务端私有存储保存，不放进聊天记录。
5. 选择微信账号、允许的微信用户 ID、项目和已有线程，或选择 **新建微信对话线程**，点击 **绑定线程**。也可以从线程菜单的 **连接微信…** 进入，自动选中该线程。
6. 在微信向已连接的 ClawBot 发送一条新的文字消息。绑定前的消息不会回放。先在网页配置可用模型；新建线程沿用现有创建规则与默认模型。

扫码连接的是 iLink bot 身份，不会把个人微信号的所有聊天自动接管。普通微信好友和群聊的能力取决于腾讯服务，当前 Pivane 仅开放私聊。长轮询不要求公网 webhook；部署机器需要访问 npm registry 和微信 iLink 服务，并使用 Pivane 既有网络/代理配置。

## 线程与回复

- 一个账号下的一个微信聊天同时绑定一个当前线程。更改或解除绑定前，先处理其待发送、执行中或待核对消息。
- 微信消息按线程空闲顺序处理。每个聊天最多保留 20 条待处理消息；最多同时派发 3 个线程。最近最多 4,500 个接收回执用于平台消息 ID 去重；原生当前分支也核对已登记的运行 ID。
- 微信执行期间，现有 worker 的独占操作保留到原生回合结算或进程实际退出。网页仍可读取实时记录；另一个会话写操作须等空闲。不会另开同文件 worker。
- 只把微信发起的这一轮最终回复发送回其原聊天。网页新发起的回复不会自动转发，绑定也不会分享既有历史。
- 长回复按平台预算分段。超过 60,000 个字符时，微信回复明确提示到网页查看完整结果，原生记录保持完整。
- 微信发送 `/stop` 或消息渠道页点击 **停止任务**，只请求停止对应的微信运行；停止不撤销已经发生的操作。其他斜杠文字不透传为宿主管理命令。
- Agent 请求交互确认时，管理页显示等待状态，请回到对应 Pivane 线程处理。媒体生成仍需网页里的确认卡，不因绑定微信自动执行。

线程被绑定时，网页删除或跨项目移动会要求先解除绑定。解绑、停用连接、卸载组件均不删除原生线程和历史。停用会取消尚未进入原生会话的排队消息；已运行的任务继续完成，回复保留为待发送。重新启用后可发送这些已完成回复，或先标记为已核对。

## 失败、重启与核对

**最近消息与投递**区分等待、运行、回复待发送、已送达和需要核对。页面刷新只读取状态，不重放写操作；保存冲突或结果不明后，必须先显式刷新再操作。

发送前先保存投递状态，发送成功后再保存平台回执。分段发送中途失败可能已送达部分内容，页面保留已确认分段数量。发送结果不确定时不会自动重发，也不会重跑 Agent。

服务重启时，执行中和发送中的记录标为需要核对。若尚未开始向微信发送，**核对并发送原生回复**只读取原线程的当前分支完成记录；有明确完成证据时恢复发送，不重新执行任务。没有完成证据，或已经开始发送而结果不明时，请在网页和微信核对，然后选择 **标记已核对**；这不会补发回复。需要核对的运行会阻止同一线程后续微信任务自动派发。

连接出现网络错误时，长轮询有退避重连；这与消息执行和回复重放是不同操作。凭据过期时重新扫码。安装失败先刷新状态；校验失败不会加载不完整的组件。

## 组件、数据与维护

Pivane 锁定腾讯 `@tencent-weixin/openclaw-weixin` 2.4.10 和 `qrcode-terminal` 0.12.0 的官方 npm 归档与 SHA256，下载后仅编译审查过的 API、无损消息 ID 解析、格式/加密辅助与二维码模块。账户配置、网络传输和日志由 Pivane 适配，不执行上游插件入口、npm 安装脚本或安装 OpenClaw peer dependency。更新兼容清单随 Pivane 源码审查；当前不自动追踪上游 latest。两份归档约 220 KiB，具体安装大小以实际产物为准。上游字节、许可与适配说明保留在私有组件回执。

数据位于当前 Pi 身份目录的 `pivane-channels/`：

- `component.json`：可卸载的连接组件、完整性回执、上游原件与许可证。
- `state.json`：账号凭据、允许用户、微信上下文令牌、绑定、接收游标、尚未入会话的消息意图及投递元数据。消息进入原生线程后移除意图正文，不保存第二份聊天历史。
- `owner.sqlite`：服务所有权协调。同一身份只允许一个渠道服务持有账号；进程中断后的所有权在数据库事务内核对。

这些文件使用私有权限或 Windows DACL，位于应用版本目录之外；随身份目录一并备份。Git 与发行源码发现排除该目录。卸载只移除连接组件，保留账号与线程关联数据；当前没有删除账号/凭据的网页入口。组件未安装时不会启动账号连接。

登录、配置写入、执行和发送计入维护忙碌；常驻长轮询可在正常停机时中止。更新不得中断承载当前维护任务的服务。Linux 隔离测试或模拟微信接口不代表真实微信扫码与三平台实机验收。
