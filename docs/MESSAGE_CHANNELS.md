# 微信与消息渠道

安装或更新 Pivane 后，以服务端 `messageChannels` 能力和实际连接状态为准。它把微信 ClawBot 的私聊绑定到普通 Pivane 持久线程，网页和微信共用原生上下文、模型、助手身份与工具。

当前支持：

- **文字与图片输入**：微信发送文字或最多 6 张图片（经微信 CDN AES-128-ECB 解密并校验图像尺寸与格式），进入目标线程上下文。
- **确定性最终回复**：不推送流式过程碎屑，避免微信气泡刷屏；任务完成后按平台预算分段回传最终回复。
- **原生“正在输入…”状态栏心跳**：每次任务重新获取票据；上次请求完成后约 5 秒续期，不并发堆积心跳。任务结束会等待在途心跳并尝试取消；票据或网络失败时有界刷新，连续失败后暂停本次提示，消息处理仍继续。管理页显示提示异常，下次任务重新获取票据。
- **交互确认主动提醒**：当 Agent 请求网页交互确认（`confirm`、`select`、`input`、`editor`）时，立即向微信发送一条提示，提醒用户打开 Pivane 网页端处理。
- **常用斜杠指令（Slash Commands）**：支持 `/help`、`/status`、`/stop`、`/confirm [卡片ID或摘要]`、`/new [标题]`（或 `/reset`）、`/resume [序号|关键词|ID]`、`/name <新标题>`、`/model`、`/thinking`、`/compact`、`/reload`，直接返回管理简报或执行控制操作。
- **图片、媒体与文件成果回传**：本轮通过 `deliver_files` 发布的图片或文件，以及 `media_generate` 自动生成完成的图片/音频（合计最多 6 个、单文件 ≤ 16 MiB），自动加密上传至微信 CDN 并作为微信图片或文件消息发回；待确认的媒体生成卡片（如视频）在微信回复中附带卡片摘要，支持发送 `/confirm` 直接确认生成。
- **定时任务主动推送**：定时任务启用“完成后推送至目标线程已绑定的微信私聊”（`notifyWeixin`）后，完成结果及本轮交付文件会自动投递给绑定该目标线程的微信用户。

语音转写、视频、普通微信群与微信内直接点击按钮确认暂未开放。包含未开放类型的微信消息不会截断交给 Agent，管理页会说明未进入线程。

## 安装与连接

1. 打开 **扩展 → 发现 → 在微信继续对话 → 安装与连接**，或直接打开 **扩展 → 消息渠道**。
2. 点击 **安装微信组件**。安装发生在运行 Pivane 的机器上；确认后才下载组件。默认安装 Pivane 不下载微信平台依赖、不启动微信连接，也不安装完整 OpenClaw 或 Hermes。
3. 点击 **扫码连接微信**，用手机微信扫描页面里的二维码。部分登录需要把手机显示的数字填入验证码框。二维码五分钟过期；离开页面不代表取消服务端登录，可返回继续查看或显式取消。
4. 登录成功后，扫码用户默认进入允许列表。允许用户可以在绑定线程内调用该线程已有的工具，因此只应加入你信任的用户。在账号卡片输入微信用户 ID 后回车添加，点标签上的 × 移除，“快速添加”列出扫码用户和最近联系过的用户；有未保存的修改时才出现保存栏，可撤销。已启用的连接不能保存空列表。凭据仅在服务端私有存储保存，不放进聊天记录。
5. 选择微信账号、已保存的允许用户、项目和已有线程，或选择 **新建微信对话线程**，点击 **绑定线程**。微信用户只能从已保存的允许列表中选择。也可以从线程菜单的 **连接微信…** 进入，自动选中该线程。
6. 在微信向已连接的 ClawBot 发送文字或图片消息。绑定前的消息不会回放。先在网页配置可用模型；新建线程沿用现有创建规则与默认模型。

页面顶部汇总连接组件、账号连接、线程绑定和需处理的消息；安装与绑定未完成时，组件卡片按步骤给出下一步操作，全部完成后显示“已就绪”。卸载组件和停用连接放在对应卡片的 `⋯` 菜单，执行前确认；解除绑定同样需要确认，绑定行可直接打开对应线程。

扫码连接的是 iLink bot 身份，不会把个人微信号的所有聊天自动接管。普通微信好友和群聊的能力取决于腾讯服务，当前 Pivane 仅开放私聊。长轮询不要求公网 webhook；部署机器需要访问 npm registry、微信 iLink 服务及微信 CDN，并使用 Pivane 既有网络/代理配置。

## 斜杠指令（Slash Commands）

在已绑定的微信私聊中直接发送以下指令，由渠道服务直接处理。管理指令本身不作为聊天问题发送给模型；`/compact` 可调用模型生成摘要，`/confirm` 会按卡片参数调用媒体服务。

| 指令 | 作用 |
|---|---|
| `/help` | 查看微信端支持的全部斜杠指令说明 |
| `/status` | 查看当前绑定线程名称、会话 ID、项目路径、助手身份、运行状态（含等待确认提示与自动压缩开关）、当前模型与思考等级、上下文用量与占比、消息与压缩次数统计及累计 Token/费用 |
| `/stop` | 停止当前正在运行的任务；停止不会撤销已发生的外部操作 |
| `/confirm [卡片ID前缀\|摘要关键词]` | 确认生成当前分支最新的待确认媒体卡片（如视频），或查询最新卡片的完成结果并回传微信 |
| `/new [标题]` 或 `/reset [标题]` | 在当前项目下新建一条持久线程，并将当前微信聊天切换到新线程，原线程历史完整保留 |
| `/resume` 或 `/resume list` | 列出当前项目下最近活跃的前 10 条线程（带数字序号 `[1]..[10]`、标题、ID 前缀与消息数） |
| `/resume <序号\|标题关键词\|ID前缀>` | 按刚列出的序号、标题关键词或会话 ID 前缀切换当前微信聊天绑定的线程 |
| `/name <新标题>` | 重命名当前绑定的持久线程 |
| `/model` 或 `/model list` | 查看当前线程使用的模型、思考等级及可用模型列表 |
| `/model <名称或 provider/modelId>` | 切换当前空闲线程的模型 |
| `/thinking` 或 `/thinking <等级>` | 查看或切换当前线程的思考等级（如 `off`、`minimal`、`low`、`medium`、`high`） |
| `/compact [附加要求]` | 手动压缩当前线程上下文（支持附加自定义摘要保留要求），返回压缩前后 Token 对比 |
| `/reload` | 重新加载当前空闲线程的技能、提示词与扩展资源 |

`/resume` 的编号固定对应刚展示的候选 ID，在同一项目内 30 分钟有效。列表缺失、过期或选中线程已删除时，会要求刷新列表，不把编号挪给另一个线程。网页绑定与 `/resume` 都拒绝管理助手线程。`/model` 的裸模型 ID 若对应多个供应商，会要求指定完整 `provider/modelId`。

未知斜杠开头的文本仍按普通消息处理，不会透传为宿主内部导航命令。

## 线程、多模态与定时推送

- 一个账号下的一个微信聊天同时绑定一个当前线程。更改或解除绑定前，先处理其待发送、执行中或待核对消息。
- 同一微信聊天的普通消息和修改指令按顺序处理；`/new`、`/resume` 成功后，其后仍在排队的输入随该次切换进入新目标，不静默丢弃。无法证明原绑定有效时，只发送未执行说明，要求用户确认线程后重发。微信消息按线程空闲顺序处理。每个聊天最多保留 20 条待处理消息（`/stop`、`/status`、`/help` 控制指令不受普通队列满额限制）；最多同时派发 3 个线程任务。最近最多 4,500 个接收回执用于平台消息 ID 去重；原生当前分支也核对已登记的运行 ID。
- 微信执行期间，现有 worker 的独占操作保留到原生回合结算或进程实际退出。网页仍可读取实时记录；另一个会话写操作须等空闲。不会另开同文件 worker。
- 回复、交付文件和生成媒体均按原生轮次的开始与结算边界收集。延迟投递或恢复读取不会收集后来网页、微信或定时轮次的文件。网页新发起的普通对话不会自动转发，绑定也不会分享既有历史。
- 定时任务在完成时固定当时允许接收的绑定，并持久保存通知意图；只补处理尚未确认的本地投递入队，不重新执行任务，也不重放结果不确定的微信发送。之后替换绑定、撤销账号权限或关闭该任务的微信通知，会阻止对应尚未发送的内容。定时任务页显示待入队通知及无法建立的通知。
- 微信发图需要目标线程当前模型支持 `image` 输入；若模型不支持视觉输入，微信端会收到明确提示，可用 `/model` 切换模型后再发。
- 长回复按平台预算分段。超过 60,000 个字符时，微信回复明确提示到网页查看完整结果，原生记录保持完整。

线程被绑定时，网页删除或跨项目移动会要求先解除绑定。解绑、停用连接、卸载组件均不删除原生线程和历史。停用会取消尚未进入原生会话的排队消息；已运行的任务继续完成，回复保留为待发送。重新启用后可发送这些已完成回复，或先标记为已核对。

## 失败、重启与核对

**最近消息与投递**按最新在前显示服务端提供的最近最多 60 条记录，每页 5 条，用“上一页／下一页”切换；刷新保留当前页，记录减少时自动回到有效页。“需处理”筛选结果不确定、失败或等待网页确认的记录并高亮显示，“进行中”筛选排队、运行和待发送的记录；筛选和翻页都只读。列表区分等待、运行、回复待发送、已送达、部分送达和需要核对，合并展示已发送文字段数与图片／文件数量。超过数量或大小限制、读取校验失败、媒体尚未生成完成时，微信回复及管理页会说明哪些附件尚未发送；不会把这些情况标为完整送达。页面刷新只读取状态，不重放写操作；保存冲突或结果不明后，必须先显式刷新再操作。

发送前先保存投递状态，发送成功后再保存平台回执（包含已发送文本分段数 `sentChunks` 与已发送媒体文件数 `sentMedia`）。分段或附件发送中途失败可能已送达部分内容，页面保留已确认数量。发送结果不确定时不会自动重发，也不会重跑 Agent。

有副作用的指令在执行前保存占位，实际提交前重新核对权限、绑定和取消状态；修改线程时保留受管 worker 互斥。已提交操作不能因后续撤权被撤销。服务重启时，执行中和发送中的记录标为需要核对，指令不会自动重新执行；指令结果不确定时只能查看实际线程／卡片并标记已核对。普通微信轮次若尚未开始向微信发送，**核对并发送原生回复**只读取原线程的当前分支完成记录；有明确完成证据时恢复发送，不重新执行任务。没有完成证据，或已经开始发送而结果不明时，请在网页和微信核对，然后选择 **标记已核对**；这不会补发回复。需要核对的运行会阻止同一线程后续微信任务自动派发。

连接出现网络错误时，长轮询有退避重连；这与消息执行和回复重放是不同操作。凭据过期时重新扫码。安装失败先刷新状态；校验失败不会加载不完整的组件。

## 组件、数据与维护

Pivane 锁定腾讯 `@tencent-weixin/openclaw-weixin` 2.4.10 和 `qrcode-terminal` 0.12.0 的官方 npm 归档与 SHA256，下载后仅编译审查过的 API、无损消息 ID 解析、格式/加密辅助、CDN 上传下载与二维码模块。账户配置、网络传输和日志由 Pivane 适配，不执行上游插件入口、npm 安装脚本或安装 OpenClaw peer dependency。更新兼容清单随 Pivane 源码审查；当前不自动追踪上游 latest。两份归档约 220 KiB，具体安装大小以实际产物为准。上游字节、许可与适配说明保留在私有组件回执。

数据位于当前 Pi 身份目录的 `pivane-channels/`：

- `component.json`：可卸载的连接组件、完整性回执（v2）、上游原件与许可证。
- `state.json`：账号凭据、允许用户、微信上下文令牌、绑定、接收游标、尚未入会话的消息意图及投递元数据。旧版保存的 `typingTicket` 兼容保留但不再复用，新票据只在本次运行内存中使用。消息进入原生线程后移除意图正文与图片引用，不保存第二份聊天历史。
- `owner.sqlite`：服务所有权协调。同一身份只允许一个渠道服务持有账号；进程中断后的所有权在数据库事务内核对。

这些文件使用私有权限或 Windows DACL，位于应用版本目录之外；随身份目录一并备份。Git 与发行源码发现排除该目录。卸载只移除连接组件，保留账号与线程关联数据；当前没有删除账号/凭据的网页入口。组件未安装时不会启动账号连接。

登录、配置写入、执行和发送计入维护忙碌；常驻长轮询可在正常停机时中止。更新不得中断承载当前维护任务的服务。Linux 隔离测试或模拟微信接口不代表真实微信扫码与三平台实机验收。
