# Pivane 1.0.0-rc.4 · 扩展中心、应用更新与后台常驻

本次为 **RC4 同版本修订**，应用版本仍为 `1.0.0-rc.4`，Pi Coding Agent 和配套官方依赖统一绑定 **0.86.1**。替换之前绑定 Pi 0.86.0、SHA256 为 `25b5b6f514303404dcc881632bf2d4168bcec84109efc98088ca702dd6748608` 的 RC4 归档。新归档、源码标签和验收附件一起更新；RC1、RC2、RC3 不变。

## 本次新增

- **扩展中心**：集中浏览精选、已安装 Packages 与 Skills；展示安装状态、全局/项目范围与刷新入口，提供扩展助手配置入口。发现或查看扩展不代表授权自动安装。
- **Pivane 应用更新**：有更高版本时在设置中直接核对、下载、校验和安装完整发布包，停机备份后切换，启动失败尝试恢复旧版。Pi 独立更新保留。忙碌时拒绝操作，不自动重放任务。
- **默认后台常驻**：普通安装使用 `node scripts/install-service.cjs`。Linux 配置 systemd 用户服务，macOS 配置 LaunchAgent，Windows 配置登录计划任务；Mac/Windows 创建桌面网页入口。Linux 服务器开机常驻需配置 linger，个人电脑睡眠或注销期间不保证可达。
- **Pi 0.86.1**：配套依赖和 lockfile 同步固定版本，继续兼容原生 system transcript、工具检查点、compaction 和会话 HTML/JSONL 导入导出。
- 包含任务线程、侧聊工具确认、更新提醒、选区提问/朗读、子 Agent 设置及导航体验改进。

## 安装与现有 RC4

下载 `pivane-1.0.0-rc.4.tar.gz` 与同名 `.sha256`，核对校验值后按[安装指南](../INSTALL_RECOVERY.md)操作。推荐 Node 22.x。首次安装执行 `npm ci`，配置实例后安装[后台常驻](../BACKGROUND_SERVICE.md)；已有服务保留原服务与数据身份，不重复注册。

**旧 RC4 不会因为应用版本号相同而自动检测到本次修订。** 当前网页应用更新只安装更高 SemVer，不提供同版本重装。旧 RC4 用户需要按手动升级流程切换到本次修订；首次使用应用更新能力还需加载配套新版 launcher。不要覆盖正在运行的目录或把新旧服务同时指向同一个会话文件。

已有安装升级前结束任务、暂停预约、保存草稿，停止同一 Pi 身份的外部写入，整批备份。正常升级保留模型、会话、媒体、配置与 `PI_*`/`pi5-*` 标识。不自动安装新的第三方扩展或重放付费请求。

## 验证与限制

准确验收结果见同一 Release 的 `pivane-1.0.0-rc.4.validation.json`，其 `artifactSha256` 必须与本次下载包一致。结果附件在冻结归档后生成，包内不循环写入最终哈希。

- Linux ARM64 / Node 22 的隔离安装、原生 RPC、浏览器、旧归档升级和同路径恢复以附件逐项结果为准。
- 后台安装器已在 Linux 独立身份测试服务注册、HTTP 就绪、停止和再次启动；macOS/Windows 仅完成模板与转义检查，尚无本次原生常驻验收。
- 应用更新信任官方 GitHub HTTPS 与 SHA256，尚未提供独立发布签名；launcher 不随子服务更新自动替换，不承诺任意未来协议升级。
- 浏览器手机宽度不等同原生手机或 Safari 验收；其他平台、真实供应商、付费媒体和全部第三方扩展未纳入本次认证范围。
