# Pivane 1.7.0（Pi 1.1.0）候选说明

本版正在准备公开发行，尚未发布。当前正式版与可下载附件以 [GitHub Releases](https://github.com/YogurtJ/pivane/releases) 为准。最终归档、源码提交、SHA256、系统与验证结果绑定在包外的 `pivane-1.7.0.validation.json`；源码预检和旧版平台报告不能代替该准确包的验收。

## 本版变化

- **Pi 1.1.0 成组升级**：应用、Pi 官方组件、适配层与隔离档案记忆一同更新，保留内置子 Agent 和已有能力。显式工具白名单保持严格，子任务授权使用已解析的精确名字；可单次禁用 MCP，避免原生工厂重复注册或恢复被禁用的能力。取消结算不再把较早的成功回复当作当前任务成功。
- **Codemode 图片与输出**：可读取和显示图片，将图片上下文交给已配置的分类模型；私有临时图片不等于永久成果。大量纯文本输出采用线性合并，保留文本、console、返回值、截断与完整输出文件的语义；混合图片输出保持原生路径。输出限额、取消、用量、分支 store 和失败不重放保持。图片分类不授予生图权限，生成继续通过可编辑确认卡片和一次性执行票据。
- **成果中心与独立成果库**：已保存文件与待保存来源分开，支持逐文件保存、星标、合集、项目标签、重命名和导出。库内原字节不依赖来源会话继续存在；详情抽屉、筛选标签、类型封面、桌面快捷选择与手机长按、上下文批量栏和可撤销操作统一整理。确认后可直接永久删除库内副本，保留修订、文件身份、哈希、持久意图和丢失响应不重放边界。通过局域网 HTTP 地址访问时，缺少 `crypto.randomUUID()` 的浏览器使用 Web Crypto 随机数生成操作标识。
- **Markdown 兼容显示**：完整表格公式中的绝对值竖线不再拆列；兼容中文标点后紧接加粗结束标记和汉字的边界。主聊天、侧聊和文件预览共用，保留原始消息、代码示例、转义与安全清洗。
- **侧栏阅读位置**：修复“动态”列表在后台轮询后轻微滚动的问题，按可见会话保持阅读位置和键盘焦点，保留最近会话展开状态。
- **多目录与手机导航**：文件区可记忆项目关联目录或临时浏览其他服务器目录，区分仅预览与关联；保留访问资格和系统权限。手机项目／线程抽屉保留顶部入口，导航前收起抽屉并保护草稿和附件。
- **聊天媒体与参考素材**：聊天上传或已生成图片可作为图片编辑输入；按模型声明复用多图、首尾帧和视频素材。已接受的异步视频请求可继续查询原任务，失败或不确定结果不自动生成第二份。明确失败／取消终态显示为失败，断线与超时等未确认结果保留不确定状态。
- **助手与回复信息**：助手页常驻身份管理入口；空分类删除先核对关联会话，已有会话或无法核实时只归档。默认关闭的回复请求平均速度按请求边界计算，保留部分统计标记，不推算旧记录。修复工具行展开后的来源显示和记忆内容扫描错误提示。
- **登录与维护**：网页自设登录 Token 最少10位。开发验证按局部功能、共享基础能力和公开发行分别选择范围；正式发布仍要求最终准确包的完整平台门槛。

详细操作见[成果中心](../ARTIFACTS.md)、[原生 MCP/Codemode](../MCP.md)、[文件与交付](../FILE_VIEWER.md)、[媒体接入](../MEDIA_CONNECTIONS.md)和[用户指南](../USER_GUIDE.md)。完整累计变化见 [CHANGELOG](../../CHANGELOG.md)。

## 安装、升级与恢复

使用 Node 22.x，最低版本要求由包内锁定的 Pi 1.1.0 定义；本候选使用 Node 22.23.2 验收。不要复用其他系统或架构的 `node_modules`，也不要单独升级 Pi。内置 pi-subagents 0.74.0、Hermes 0.9.9 及已固定的安全依赖保持；实际解析与审计结果见验证附件。

正式附件可用后，下载 `pivane-1.7.0.tar.gz` 与同名 `.sha256` 并核对来源及摘要。解压到新的独立应用目录，执行 `node scripts/install.cjs`，沿用已核对的身份、项目、媒体、档案记忆、预约与启动配置绝对路径。先保存草稿和附件，等待主／子任务、Shell、侧聊、定时、媒体、转录、文档解析、会话移动及配置活动空闲；暂停预约、正常停机并完成同一时点的完整备份后再切换。新旧服务不能同时写同一身份。

普通应用升级不执行全局 JSONL 替换，不搬迁真实会话，不删除用户数据，也不重复已完成的原生 MCP 迁移。成果库、办公原件、交付快照和媒体参考素材须随身份及媒体根一起备份。旧代码或备份不能覆盖新服务已经接收的新消息；恢复前停机核对原路径字节，启动后核对会话 ID、完整分支与语义。详见[安装与恢复](../INSTALL_RECOVERY.md)和[版本与更新](../UPDATES.md)。

## 验收与兼容范围

正式公开发布前须完成最终准确包在每个宣称平台上的独立安装、全量 Node、语法／文档、最新生产 audit、全量自动浏览器与相关手动专项，以及从正式1.6.2升级、正常停机和原路径恢复。准确摘要在包外附件维护，避免把归档自身 SHA 写回包内造成循环重打包。

Linux、macOS、Windows 的实现与安装指南继续保留；本候选的实际通过范围只以当前验证附件为准。尚未取得本批 macOS 或 Windows 准确包证据时，不能引用1.6.2报告声称本版已通过。Chromium 手机宽度不代表 Safari、真实手机键盘、麦克风或后台行为；独立合成服务不代表真实付费模型、媒体供应商或用户 GPU 已验收。

自定义 Pi Provider 扩展应核对1.1.0的流接口；原生 `AssistantMessageEventStream` 与旧扩展中的自定义基类不能仅凭 import 成功认定兼容。已打开的模型／资源配置可在空闲重载后生效。应用发布、当前实例启用和真实供应商账户测试分别进行。

## English upgrade notes

This is an unpublished Pivane 1.7.0 candidate bound to Pi 1.1.0. It adds the independent artifacts library and management UI, LAN HTTP compatibility for artifact operations, multi-directory file navigation, reusable media references, and request-level reply statistics. Markdown table formulas retain absolute-value bars and Chinese bold closing boundaries render correctly; sidebar background polling preserves reading position and keyboard focus. Codemode keeps its native execution and permission boundaries while avoiding repeated string rebuilding for large text-only results.

Verify the final archive checksum, extract into a separate application directory and run `node scripts/install.cjs`. Preserve identity and data paths, save drafts, pause scheduled work, wait for active operations, stop the old service and back up before switching. Never run both versions against one identity. Exact archive, source commit, platform results and remaining limitations belong to the validation attachment; older release reports and mobile viewports do not establish native platform acceptance.
