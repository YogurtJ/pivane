# Pivane 1.9.0（Pi 1.3.0）发布候选

本版正在准备发布。源码完成、本机启用和公开发布分别核对；准确归档、校验和与各平台验收以最终 Release 附件为准。当前公开正式版仍为1.8.0，不能沿用其验收结果作为本包证明。

## 本版变化

- **Pi 1.3.0 与档案记忆0.9.10**：官方 Pi 包成组绑定1.3.0，pi-subagents保持0.78.0，pi-hermes-memory更新至0.9.10。模型控制和能力按运行时定义读取；保留原生会话、用量、MCP授权与任务归属边界，检索显示命中数量。
- **助手身份五页工作区**：概览、设定、记忆、技能、学习各有独立入口，概览汇总待处理事项和最近变化；记忆可筛选条目或编辑全文，技能集中审核草稿。身份移入回收站后可恢复；学习预算提供预设与自定义，已有预算不会自动提高。
- **可选微信消息渠道**：按需安装微信连接组件，扫码后设置允许用户并绑定线程，支持文字、图片、交付文件、输入状态及常用斜杠指令。指令提交前重验权限、持久占位，不重放未知结果；原生通知和附件只交给其所属轮次，定时通知持久入队。连接管理提供状态总览、分步引导、用户标签、投递诊断和分页记录。详见[消息渠道](../MESSAGE_CHANNELS.md)。
- **扩展发现与版本检查**：发现页可按类型和安装状态筛选，在卡片内展开前提与示例；已安装扩展包和技能显示版本。可手动检查 npm/Git 更新，发现版本后由用户执行更新；固定版本、本地路径、内置组件和离线模式不检查更新。
- **媒体与设置体验**：图像、视频、语音服务以紧凑入口卡片呈现，对话自动生成按类型设置；图像和语音卡片可按设置自动执行，视频继续按确认策略处理。微信可接收生成结果并通过指令确认。媒体卡片复用播放器、保留参数草稿、释放离开线程的读取；旧版curl可访问ComfyUI，只读请求可有界重试，生成提交不自动重发。
- **加载、长会话与公式性能**：设置与功能页按需加载，设置页首屏使用对应内容的骨架；慢连接有积压保护，持久线程重连从原生快照恢复。会话扫描、索引并发、搜索、静态压缩及任务结果分页减少重复工作；Markdown与多行公式边界修复，公式缓存、嵌套工具和对话目录更新有界合并。保留原文、完整文件身份与失败回退。

完整变化见[CHANGELOG](../../CHANGELOG.md)，实际操作见[用户指南](../USER_GUIDE.md)。

## 安装、升级与恢复

1. 下载 `pivane-1.9.0.tar.gz` 及同名校验文件，用 `sha256sum -c pivane-1.9.0.tar.gz.sha256` 核对；macOS可使用 `shasum -a 256 -c`。
2. 解压到独立新目录，以受支持的Node22执行 `node scripts/install.cjs` 安装锁定依赖。不要复用其他系统的node_modules，Pi及内置组件随应用成组升级。
3. 升级前保存草稿和附件，等待主任务、子任务、Shell、侧聊、预约投递、媒体、渠道发送和配置操作结束；按实际范围备份身份、会话、媒体、队列、配置和外部数据，再正常停机切换，保持数据路径。
4. 启动后核对版本、能力、完整分支、书签、附件和队列。查询原回执处理未知结果，不自动补发；新实例已接受写入后，不用旧备份覆盖新消息。需要恢复时先停机核对原路径字节，再用原生SDK核对会话ID与语义。

详见[安装与恢复](../INSTALL_RECOVERY.md)、[版本与更新](../UPDATES.md)；普通升级不搬迁会话树，也不全局替换JSONL正文。已有微信渠道应核对允许用户与绑定线程，应用更新不自动重放旧发送。

## 验收与限制

本候选的准确包验收正在进行。发布前须完成当前准确归档的完整Node、语法、文档、生产audit、自动浏览器，以及宣称平台的独立安装、从正式1.8.0升级和原路径恢复。结果、实际环境、首次失败及补验绑定到同名validation附件；在完成前不宣称三平台已通过。

Chromium手机宽度模拟不代表真实手机键盘、麦克风或后台行为；Safari/Firefox、Intel macOS、Windows ARM64及真实供应商计费不由现有记录证明。微信与外部媒体服务仍需用户自己的接入配置，合成服务验收不等于真实账户端到端验收。

## English upgrade notes

Pivane 1.9.0 binds Pi 1.3.0, pi-subagents 0.78.0 and pi-hermes-memory 0.9.10. It adds the five-page assistant workspace, optional WeChat messaging with owned turn results and durable notifications, redesigned extension discovery and explicit update checks, media execution settings, and improvements to startup, long conversations, math rendering and slow connections.

This is a release candidate. Exact-archive validation is being prepared; prior release results do not establish support for this archive. Verify the final checksum, install in a separate directory, preserve data paths, back up and stop the old instance before switching. Never replay uncertain submissions or overwrite messages accepted by the new instance with an old backup. See the final validation attachment for tested systems and limitations.
