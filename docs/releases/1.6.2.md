# Pivane 1.6.2 · 发布候选

本版沿用 Pi 1.0.2，整理 1.6.1 之后的办公附件、聊天媒体生成、文件阅读和工作台改进。候选准备和公开发布是不同状态；正式下载、准确 SHA256 和验收附件以 [GitHub Releases](https://github.com/YogurtJ/pivane/releases) 为准。

## 新增与改进

- **办公文档附件**：持久聊天线程可上传 DOCX、XLSX、PPTX 和 PDF 原件，单文件 20 MiB、每条最多五份。聊天卡片提供原件下载，Agent 使用 `read_document` 按段落、工作表／行列或页读取。表格保留公式原式与缓存值；部分读取、未 OCR 和解析限制明确返回。原件私有保存，解析并发、时间和展开量受限。预约消息可使用同样的文档附件。
- **聊天媒体生成**：Agent 读取已配置的图片、视频和语音模型，准备可编辑的确认卡片；用户在卡片中确认后才执行。结果进入实验室历史，刷新、换设备和重连同步同一请求状态。
- **生成排队与等待**：卡片按确认顺序排队，可取消；远端合计四项、其中视频两项，本地后端一项，和实验室共用名额。开始前重新校验参数，失败和不确定结果不自动重试。生成中显示等待时间与超时说明；新接入的同步图像／视频模板以及未填写时的默认最长等待改为 600 秒，已有明确配置保留。
- **全屏文件阅读**：文件查看器可全屏阅读，Esc／返回侧栏保持阅读状态。图片和 SVG 支持拖动、滚轮及双指缩放；PDF 保持页码、缩放和文字展开状态，按阅读区重绘，并保留画布预算。
- **媒体配置与参考素材**：按图像、视频、TTS 分类管理，点击模型名称直接编辑；新增模型可复用服务或建立新服务。实验室支持模型声明的多张参考图、首尾帧、参考视频和排序，参数可直接编辑；修改素材后须重新确认。保存设置保留列表和实验室草稿，共享凭据及删除影响有提示。快速关闭后重开媒体／语音配置时，迟到关闭事件不会清空新页面或隐藏新转录页面。
- **工作台与手机**：桌面详情、文件、历史和侧聊与主聊天并排，保留保存宽度并随空间收窄。手机继续使用抽屉，项目／线程抽屉保留底部导航，导航后自动收起；输入框采用整宽文本区和独立按钮行，保留 16px 字号、长草稿内部滚动和附件保护。
- **文档整理**：用户指南聚焦操作，专题文档保存契约，减少重复说明并清理过时入口；旧版验收结论继续绑定对应发行归档。

用法见[命令与附件](../COMPOSER_TOOLS.md)、[文件查看](../FILE_VIEWER.md)、[媒体实验室](../MEDIA_LAB.md)、[媒体接入](../MEDIA_CONNECTIONS.md)及[用户指南](../USER_GUIDE.md)。

## 升级与恢复

正式包发布后，下载 `pivane-1.6.2.tar.gz` 并核对校验文件，解压到独立应用目录，执行 `node scripts/install.cjs`。Pi 1.0.2 随应用安装，不单独升级 Pi 或第三方扩展。

保存草稿和附件，等待任务、Shell、子 Agent、侧聊、定时、媒体、转录、文档解析、会话移动及配置活动空闲。先停机并备份，再切换应用；保留身份、原生会话、模型、项目、媒体、记忆、调度和交付物的数据绝对路径，特别是 `PI_WEB_DEFERRED_FILE`。新旧服务不能同时写入同一身份。新上传的办公原件保存在身份目录的 `pivane-uploads/` 下，应随身份备份。普通升级不迁移真实线程、不删除用户数据，也不重复已完成的原生 MCP 迁移。

已有网络、登录和媒体设置保持。新服务接收消息后，不能直接用旧备份覆盖新消息。恢复前停机核对原路径字节，启动后核对会话 ID、完整分支和语义。详见[安装与恢复](../INSTALL_RECOVERY.md)、[发布流程](../development/RELEASING.md)及[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)。

## 候选验证与限制

本版发布前需要完成准确归档的独立安装、Node 全量、语法／文档检查、生产依赖审计、从正式 1.6.1 升级、原路径恢复和相关 Chromium 桌面／手机回归。通过结果和准确归档 SHA256 记录在对应 `pivane-1.6.2.validation.json`，不以源码报告替代包内验收。

传递依赖 `proxy-addr` 从 2.0.7 更新到兼容修复版 2.0.8，修复 GHSA-jqcg-44mw-7w3h 严重告警。锁文件只调整该包的版本、下载地址与完整性哈希；Pi 与其他应用依赖版本保持。

办公附件不提供 Office 原版预览、在线编辑或 OCR；旧二进制 DOC/XLS/PPT 和加密文档不在支持范围。Chromium 手机宽度模拟不代表 Safari 或真实手机软键盘、麦克风和后台行为已验收。正式发布前分别在 Linux ARM64、原生 Windows x64 和 Apple Silicon macOS 验证准确归档；实际系统、Node、浏览器和通过范围以验收附件为准。其他架构与真实模型／媒体供应商另行验证，测试使用独立身份和合成服务。

## English upgrade notes

Pivane 1.6.2 adds DOCX/XLSX/PPTX/PDF attachments, editable media generation cards in chat, generation queues, full-screen file reading, richer media references, and desktop/mobile layout improvements. Office uploads retain private originals and support bounded `read_document` extraction; native Office preview, editing and OCR are not included.

After publication, verify the checksum of `pivane-1.6.2.tar.gz`, extract it into a separate application directory and run `node scripts/install.cjs`. Save drafts, wait for active work, stop the old service and back up before switching. Preserve all identity and data paths, including `PI_WEB_DEFERRED_FILE` and the identity's `pivane-uploads/` directory. Never run both versions against the same identity. Pi remains at 1.0.2. Exact archive, platform and validation results belong to the release attachments.
