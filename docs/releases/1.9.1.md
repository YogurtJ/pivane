# Pivane 1.9.1（Pi 1.3.0）

本版处于发布候选阶段，尚未公开发布。最终归档、SHA256、三平台准确包验收结果和已知限制将作为独立发布附件提供；下文描述已实现的候选行为，不表示验收已经完成。当前正式下载见 [GitHub Releases](https://github.com/YogurtJ/pivane/releases)。

## 本版变化

- **大文件下载与交付**：项目文件与交付快照提供独立的受认证下载接口，超过 16 MiB 预览预算仍可下载。默认单文件下载／交付上限 512 MiB，交付组上限 1 GiB；复制采用分块读取，保留完整文件身份、哈希、分支与前后变化校验。预览预算内、签名识别的 MP4 可直接播放。详见[文件与交付](../FILE_VIEWER.md)。
- **聊天交付卡片**：成功的 `deliver_files` 结果显示文件类型、名称、大小与下载入口，小图片显示缩略图；超过五项可展开。简洁视图与刷新后历史保留卡片，回复中的文件链接带类型图标。
- **结构化提问**：默认受管工具新增 `ask_user_question`，一次提交 1–4 题，可选择选项、自写回复、跳过、前后切换后统一提交。输入区上方显示作答面板，对话保留回答摘要；取消、超时、停止、缺少 UI 与跳过分别记录，不作为默认选择或同意。默认等待 10 分钟，最长 30 分钟。详见[用户指南](../USER_GUIDE.md)。
- **微信绑定线程结果通知**：默认接收绑定线程的全部最终结果，包括网页、微信及默认跟随线程的定时任务；运行途中绑定可接收当前任务，已完成历史不补发。保留仅微信问答模式和单个定时任务关闭通知，固定原生轮次的回复与附件并持久去重；修复网页停止被微信任务锁挡住的问题。详见[消息渠道](../MESSAGE_CHANNELS.md)。
- **主题与导航**：晴空、薄荷、燕麦、石墨与夜间使用重新设计的配色和统一主题强调色；成功状态继续使用绿色。导航改为线性图标，桌面折叠后保留 Logo，支持鼠标、键盘与触屏展开；修复触屏收起后 Logo 空白。平板使用窄栏，手机五个底栏入口等宽，英文长标签可换行。
- **消息队列界面**：引导／后续消息的队列入口并入输入区状态标签行并显示数量，窄屏可换行；队列窗口按执行时机分组，取回记录独立显示，保留草稿、附件、旧后端只读展示和防重复追加行为。关闭窗口时保留用户已明确选择的输入焦点。详见[运行控制](../NATIVE_CONTROLS.md)。

Pi 1.3.0、pi-subagents 0.78.0 与 pi-hermes-memory 0.9.10 保持，依赖未升级。完整变化见 [CHANGELOG](../../CHANGELOG.md)。

## 安装、升级与恢复

1. 下载 `pivane-1.9.1.tar.gz` 及同名 `.sha256` 文件，使用 `sha256sum -c pivane-1.9.1.tar.gz.sha256` 核对；macOS 可用 `shasum -a 256 -c`，Windows 可用 `Get-FileHash -Algorithm SHA256` 比较。
2. 解压到独立新目录，用 Node 22 执行 `node scripts/install.cjs` 安装锁定依赖，不复用其他系统的 `node_modules`。
3. 升级前保存草稿和附件，等待主任务、子任务、Shell、侧聊、预约／定时投递、媒体、渠道发送与配置操作结束；按实际范围备份身份、会话、媒体、队列、配置及外部数据，再正常停机切换，保持原数据路径。
4. 启动后核对版本、受管工具、会话分支、书签、附件、队列与微信通知模式。新增受管工具需在安全空闲时重新加载 worker；线程绑定默认接收全部最终结果，需要时可改为仅微信问答。
5. 未知提交先查询原回执，不自动补发。恢复先停机核对原路径字节，再用原生 SDK 核对会话 ID、完整分支与语义；新实例已接受写入后，不用旧备份覆盖新消息。

详见[安装与恢复](../INSTALL_RECOVERY.md)、[版本与更新](../UPDATES.md)。正常升级不搬迁会话树，也不改写 JSONL 正文。

## 验收与限制

发布前须对同一最终准确包，在 Linux ARM64、Apple Silicon macOS 与 Windows x64 完成独立安装、全量 Node、语法、文档、生产 audit、完整自动浏览器及相关手动专项、从正式 1.9.0 升级和原路径恢复。准确环境、原始结果、失败诊断与必要补验记录在同名 `validation.json` / `validation.md` 附件中，绑定归档 SHA256；既有开发测试和 1.9.0 结果不替代本包验收。进度入口见[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)。

本候选已修复此前两项既有问题：共享线程显式 `/quit` 在 Shell/RPC 实际结束后同步到其他已连接页面，清除运行展示并保留各页草稿和附件，避免显式退出销毁期间由Shell中间快照触发退役实例同步错误；Windows 导入在文件系统边界使用长路径形式，保留规范原生路径和不覆盖目标的原子发布。需要重新打开已退出线程才能继续发送，页面内存中的草稿在刷新前仍需保存；系统路径组件和权限限制保持。行为见[运行控制](../NATIVE_CONTROLS.md)与 [Windows 指南](../WINDOWS.md)，最终准确包范围与原始失败另见验收附件。

Chromium 手机视口检查不证明真实手机键盘、麦克风或后台行为；Safari、Firefox、Intel macOS、Windows ARM64 与真实供应商计费不由合成服务测试证明。微信和媒体仍需用户自己的接入配置。

## English upgrade notes

Pivane 1.9.1 is a release candidate. It adds authenticated large-file downloads, compact delivery cards and structured user questions; forwards final results from bound threads to WeChat; and updates themes, navigation and the message queue interface. It preserves explicitly selected input focus when closing the queue. Pi 1.3.0, pi-subagents 0.78.0 and pi-hermes-memory 0.9.10 remain unchanged.

This candidate fixes stale Shell state on other connected pages after an explicit `/quit`: terminal notification follows actual Shell/RPC shutdown, preserves local drafts and attachments, avoids synchronization errors triggered by intermediate Shell snapshots during explicit disposal, and does not automatically reopen the runtime. Windows imports use extended-length paths at filesystem boundaries while retaining canonical native paths and atomic no-replace publication. Reopen the thread explicitly to continue; save in-memory drafts before refreshing. OS component-length and permission limits still apply.

Exact-archive acceptance is required on Linux ARM64, Apple Silicon macOS and Windows x64 before publication, including installation, the real 1.9.0 upgrade and original-path restoration. The checksum and validation attachments record the actual results. Install into a separate directory, preserve data paths, save drafts, back up and stop the old instance before switching. Reload managed workers while idle to enable the new tool. Check the WeChat notification mode after upgrading. Do not replay uncertain submissions or restore an old backup over newly accepted messages.
