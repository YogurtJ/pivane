# Pivane 1.2.0 · 发布候选

本版锁定 **Pi Coding Agent 0.87.1**，推荐 **Node.js 22.x（至少 22.19）**。当前正在进行发布验收；正式下载以 [GitHub Releases](https://github.com/YogurtJ/pivane/releases) 为准，1.1.0 及更早版本的资产保持不变。

## 本版变化

- **助手身份与独立工作区**：按用途配置名称、头像、个性与行为、用户偏好和长期记忆；多个助手项目可关联同一工作目录，并分别组织线程。身份编辑支持草稿保护、保存反馈、快捷键及手机列表与详情切换。
- **可管理的记忆与学习**：逐项搜索、编辑、删除、恢复记忆和已学习技能，查看来源与撤销回执。后台学习默认关闭，启用后使用单独配置的辅助模型和每日预算；纠错、复盘及边界提炼各自可控。整理方案需确认后应用，生成的技能先作为草稿。聊天显示记忆反馈，可查看下一轮注入预览。
- **随包提供子 Agent 与记忆组件**：内置 pi-subagents 0.71.0、pi-hermes-memory 0.9.9，统一准备锁定依赖及 SQLite。保留既有 Pi CLI 包声明、过滤配置和记忆数据；子 Agent 后台任务纳入空闲回收与维护判断。
- **线程通信与任务反馈**：Agent 可在用户授权的任务范围内联系同项目其他线程。消息在接收方空闲时投递，带循环唤醒限制；任务结果、子 Agent 和当前进度集中在输入框上方，支持展开、定位原文与标为已读。
- **简洁视图与界面整理**：每轮完成后保留最终回复，过程收进可展开的用时与工具摘要；旧浏览器保留原显示偏好。扩展中心合并已安装资源，手机导航和抽屉按钮、标题建议、分叉及删除反馈同步改进。
- **性能与可靠性**：减少会话列表与预约轮询的重复工作，按帧合并流式显示、复用未变化的历史节点，工具详情按展开加载。修复长会话通信索引反复等待、切线程连接取消误报、带图消息重复及任务结果已读失败。

完整功能、限制和接口见 [CHANGELOG](../../CHANGELOG.md)、[用户指南](../USER_GUIDE.md)、[助手身份](../AGENT_PROFILES.md)、[记忆学习](../PROFILE_MEMORY.md)及[内置能力](../BUNDLED_CAPABILITIES.md)。

## 安装与从 1.1.0 升级

新包解压后使用：

```sh
node scripts/install.cjs
```

Windows 使用 `node.exe scripts/install.cjs`。此入口安装锁定依赖，使用 SQLite 随依赖提供的原生二进制，并验证组件就绪。不要直接套用旧包的 `npm ci` 命令：部分 npm 版本会对 SQLite 无谓调用本机编译工具。没有可用二进制的目标需按[内置能力说明](../BUNDLED_CAPABILITIES.md)准备编译环境。旧归档没有新脚本时继续使用该归档的原安装方式。

已有实例可使用“设置 → 版本与更新”的 Pivane 应用更新；只升级 Pi 不会加入本版应用功能。手动安装、后台常驻与恢复步骤见[安装与恢复](../INSTALL_RECOVERY.md)。升级前保存草稿和临时对话，结束任务、子任务与 Shell，暂停预约，并停止共用身份的外部 CLI。停机整批备份后切换，保留原身份、媒体、项目和预约路径；原生会话不做文本迁移。恢复旧版时使用对应的整批停机备份。

默认端口改为 **11408**，显式自定义端口仍有效。原 3001 实例若切换端口，须同时更新 `PORT`、`PI_WORKSPACE_BASE_URL` 和访问地址；先把 `PI_WEB_DEFERRED_FILE` 固定为原队列的绝对路径，避免新默认端口选择另一份预约队列。

升级不会自动开启后台学习或改用主聊天模型。已有学习配置继续保留；需接管旧复盘配置时，由用户在身份页确认。导入或分叉的学习基线之前的历史不会被集中补学。项目记忆仍按物理目录划分；逻辑助手项目不是独立的文件系统或工具权限边界。

刷新浏览器加载新界面。历史工具的详细输出在展开后才进入浏览器页内查找，服务端历史搜索和导出仍读取完整记录。

## 验收与已知范围

最终验收结果将绑定确切归档 SHA256，随 Release 提供 `validation.json`、逐文件清单、校验文件和版本说明；本页不预先宣称候选通过。

内置组件此前已在 Linux ARM64、Apple Silicon M2 和 Windows 11 x64 上验证统一安装、SQLite、更新探测及运行专项。这些结果属于先前组件候选，不代替最终发行包的整包验收。其他历史平台范围见[平台验证](../RELEASE_INSTALL_VALIDATION.md)。Chromium 手机宽度测试不代表 Safari 或真实手机后台通知验收；合成供应商测试不代表全部真实模型或媒体服务。

## English summary

Pivane 1.2.0 adds assistant identities, managed memory and opt-in background learning, bundled subagents and memory components, direct thread messaging, compact conversation views and performance improvements. Pi remains pinned to 0.87.1. Install the new archive with `node scripts/install.cjs`; preserve existing identity and data paths during upgrades. The new default port is 11408; pin the original scheduled-message file before changing an existing instance's port. Final release validation is tied to the exact archive checksum.
