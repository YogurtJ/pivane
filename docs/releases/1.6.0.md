# Pivane 1.6.0 · 媒体参考附件、文件预览与阅读优化

本版为发布候选，尚未公开发布。保持 Pi Coding Agent 1.0.0、pi-subagents 0.74.0 和 pi-hermes-memory 0.9.9，推荐 Node.js 22.x（至少 22.19）。准确归档的 SHA256、平台结果和测试范围随发行附件 `pivane-1.6.0.validation.json` 提供，包内文档不回填归档自身哈希。

## 主要变化

- **媒体参考附件**：模型可声明参考图片与 MP4 参数，网页支持上传、预览和移除；图片可交给辅助规划模型，视频只交给生成模型。支持 JSON data URL／inlineData 和受限 multipart 文件映射，提供参考图与首帧模板。附件改变后须重新校验执行票据，历史只保留素材元数据。见[媒体实验室](../MEDIA_LAB.md)和[接入协议](../MEDIA_CONNECTIONS.md)。
- **文件与交付预览**：新增 PDF 分页、缩放与本页文字，CSV／TSV 分页表格、受限 SVG 和浏览器音频播放。PDF.js 从本地按需加载，关闭或切换文件释放解析与播放资源；沿用鉴权、文件预算和原字节下载。见[文件查看](../FILE_VIEWER.md)。
- **统一语音配置**：图像、视频、语音共用模型配置弹窗；语音默认 TTS 页签，可切换 ASR，服务和凭据共享。麦克风直接开始录音，结束后转成可编辑草稿；移除音频文件上传入口。保留取消、线程隔离、并发编辑和不自动发送的行为。见[输入与转录](../COMPOSER_TOOLS.md#语音转录)。
- **线程移动修复**：大历史引用检查改用分块投影与完整身份校验，避免无关超大正文导致 `Unsafe maintenance file`；默认目标排除零会话旧项目，仍可手动输入路径。修复普通 HTTP 下缺少 `crypto.randomUUID` 导致确认失败。见[会话工作流](../SESSION_WORKFLOWS.md#移动线程到其他项目)。
- **阅读与输入体验**：未变化的长会话快照复用布局，历史展开后的重排保留阅读锚点，首次加载同步连接与错误状态；引导／后续投递方式在加号菜单中统一为可展开选项。未引入历史分页或虚拟列表。

完整改动见 [CHANGELOG](../../CHANGELOG.md)、[用户指南](../USER_GUIDE.md)和[API](../API.md)。

## 安装与从 1.5.0 升级

在独立应用目录解包，执行 `node scripts/install.cjs`（Windows 使用 `node.exe`）。保留身份、会话、凭据、模型、项目、媒体、调度和交付物，数据绝对路径与 `PI_WEB_DEFERRED_FILE` 不变。先保存草稿，核对任务、Shell、侧聊、媒体、转录、线程移动和配置活动，等待空闲后停机并备份，再切换代码。新旧服务不能同时读写同一身份。

Pi 与本项目适配成组安装；已完成的原生 MCP 迁移不重复执行。普通升级不移动真实线程、不删除用户知识、不重新安装无关扩展。安装与恢复步骤见[安装与恢复](../INSTALL_RECOVERY.md)、[Windows](../WINDOWS.md)及[发布流程](../development/RELEASING.md)。

恢复须先停机，并在打开 Pi 前逐项核对原路径字节；新服务接受消息后不能直接用旧数据覆盖新消息。保留旧代码与一致停机备份，核对原生 ID、分支和语义，不改写 JSONL 正文冒充迁移。

## 验证范围与限制

本候选准备在树莓派 Linux ARM64 和原生 Windows 11 x64 使用独立身份、Node 22.23.2 与合成供应商执行安装、完整测试、浏览器、正常关闭及原路径恢复验收。完成情况以绑定准确归档 SHA256 的外部 validation 附件为准，不能将计划或源码检查当成归档通过。

PDF 不执行服务器转换或 OCR，表格不计算公式；预览预算和支持类型见文件指南。参考附件合计最多 20 MiB，图像／视频格式及映射由模型定义约束；基础签名校验不替代完整媒体解码。真实供应商请求仍须用户确认，不因配置存在而自动生成。

Chromium 手机宽度检查不代表真实手机麦克风、软键盘、后台行为或 Safari 验收。本版不新增 macOS、Windows ARM64、Windows Server、网络共享及所有真实供应商账户的验收结论。
