# Pivane 1.10.2（Pi 1.4.0）

2026-10-24已[正式发布](https://github.com/YogurtJ/pivane/releases/tag/v1.10.2)，并确认为GitHub Latest。冻结源码`9aa4647dec9890f35311763912f88707b658629f`，归档SHA256`ad9691b616795978a9eaf2d0870edfdb80e86a730a8083d5825c8ede52235ab2`，1730个清单文件。九份公开附件匿名HTTP200回下载逐字节一致；标签与归档不因主分支补写发布记录改变。本版修复 Windows 微信组件安装失败和界面静态翻译串位。Pi 1.4.0、pi-subagents 0.80.0、pi-hermes-memory 0.9.10、锁定依赖及原生组件版本保持。公开发布不自动切换已有实例。

## 修复

- **Windows 微信组件安装**：原安装器将模块文件 URL 写成不含 Windows 盘符的地址，上游加载时调用 `fileURLToPath()` 会抛出 `ERR_INVALID_FILE_URL_PATH`。现通过 `pathToFileURL()` 从本机绝对路径生成 URL，正确处理盘符和路径转义；官方归档哈希校验、审查模块范围和安装自检保留。
- **安装错误说明**：安装失败显示读取、下载、归档校验、编译、加载／二维码自检或保存阶段，以及可安全展示的系统错误码。响应正文、代理凭据和本机路径不进入错误提示。刷新状态后核对结果，不自动重试。
- **静态界面翻译**：改为以页面原文和属性原值查找译文，旧数字标记只定位文字，不再引用词典行号。修复“助手身份”导航、“消息显示／简洁”、引导／后续消息说明，以及主题、字体等相邻标签的串位。词典增删和排序不再改变绑定；标题、可访问名称和占位提示使用同一规则。
- **回归保护**：新增微信模块加载、回执重载和安全错误提示测试；翻译回归故意重排词典，并验证中英文桌面／手机界面。浏览器证据输出使用平台临时目录，不依赖固定 POSIX 路径。

## 升级

从 1.10.1 正常更新即可，保留身份、账号、会话、附件及媒体数据，不迁移或文本改写 JSONL。已能正常加载的微信组件无需为了安装器修复而卸载；此前安装失败的 Windows 用户，在更新 Pivane 后刷新渠道状态再安装。重装同一未修复版本不能消除文件 URL 错误。

切换前保存草稿，等待实际工作结束，按[安装与恢复](../INSTALL_RECOVERY.md)正常停机备份。提交结果不确定时先查原回执，不能自动重放或用旧数据覆盖更新后新消息。

## English

Pivane 1.10.2 was released on2026-10-24 and is the GitHub Latest release. All nine public assets were downloaded anonymously and verified byte-for-byte. It is a patch release for Windows WeChat connector installation and static interface translations. The connector now derives its module file URL from a native absolute path, fixing `ERR_INVALID_FILE_URL_PATH` on Windows. Installation failures identify a safe stage and selected system error code without exposing response bodies, credentials or local paths.

Static translations now use the original UI text or attribute value as the lookup key. Legacy numeric markers locate text only; catalog insertion or reordering no longer replaces navigation labels, message-view controls or steering/follow-up descriptions with unrelated messages. Pi, locked dependencies and native components remain unchanged.
