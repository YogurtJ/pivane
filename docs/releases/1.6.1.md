# Pivane 1.6.1 · Network settings, side chat and memory fixes

Pivane 1.6.1 brings a unified Network & access page, a desktop side chat that stays beside the main conversation, clearer assistant knowledge controls, and fixes for forked-session learning, search continuity and English UI labels. Pi Coding Agent and its official package family are pinned together to **1.0.2**; bundled pi-subagents remains **0.74.0** and pi-hermes-memory **0.9.9**.

本版已在 [v1.6.1 Release](https://github.com/YogurtJ/pivane/releases/tag/v1.6.1) 正式发布。源码标签与归档保持发布前冻结字节；当前分支文档补记最终结果，不重写已发布包。准确归档 SHA256、源码提交、平台结果及验收范围随发行附件 `pivane-1.6.1.validation.json` 提供。推荐 Node.js 22.x（至少 22.19）。

## 主要变化

- **网络与访问**：统一管理登录验证、监听范围、出站代理及远程接入指引。新安装默认仅本机访问，已有受管安装保留可识别的监听范围；网络配置保存后等待安全重启，不自动开放防火墙或中断任务。更新与受管模型／媒体请求支持明确的环境、直连及 HTTP/HTTPS 代理选择，测试草稿不调用生成模型。见[网络与访问](../ACCESS_CONTROL.md)。
- **桌面侧聊**：主会话与侧聊优先并排，随可用宽度收窄分栏而保留浏览器保存宽度；窄桌面暂藏线程列表，手机继续使用抽屉。修复笔记本窗口和较宽侧栏偏好导致主会话被遮罩的问题；切换视口保留连接、记录和草稿。侧聊思考等级随中英文界面显示。见[侧聊](../SIDE_CHAT.md)。
- **分叉与后台学习**：记录并核实原生分叉继承边界，避免换了会话 ID 后重新学习旧问答；分叉后新增内容继续学习，重启、历史编辑和分支切换保留进度。提供服务端逐项审计的幂等额度对账，只返还已证明的误预留额度，保留真实模型用量与费用。见[记忆适配](../PROFILE_MEMORY.md#background-learning)。
- **助手会话与知识**：分叉后立即同步分类；同一助手、同一目录的会话支持“更改分类…”，核对修订并等待运行空闲。修复分类保存请求缺少 JSON 类型的问题。USER／MEMORY 保存显示服务器确认或索引待同步状态，知识列表默认隐藏已删除条目，另提供查看、恢复和就地展开。见[助手档案](../AGENT_PROFILES.md)。
- **搜索、输入与阅读**：关闭再打开搜索保留关键词、范围、结果页和阅读位置；迟到响应不会覆盖新弹窗。侧栏增加定位当前线程。加号菜单扩大面板和留白，“创建定时任务”移入加号。长行内代码、路径及标识符在各消息视图中换行，代码块保留独立横向滚动。
- **Pi 1.0.2 与 MCP**：在本项目的 SDK／RPC 边界适配新版，保留现有子任务工具授权。MCP 项目配置可部分覆盖启用与工具暴露方式，继承全局连接与凭据；省略字段或 null 恢复继承，修订与信任校验保持。采用上游 Codemode 输出预算与供应商兼容修复，已完成的操作不因脚本超限而回滚或重放。见[原生 MCP](../MCP.md)。
- **中英文介绍与界面**：项目首页改为英文优先并保留中文版，加入合成数据的桌面、手机、多 Agent、媒体截图及任务动图。补齐英文媒体提交确认的费用说明，思考段数、工具调用／失败数和子 Agent 轮数正确区分单复数。

完整记录见 [CHANGELOG](../../CHANGELOG.md)、[用户指南](../USER_GUIDE.md)、[英文用户指南](../en/USER_GUIDE.md)和[API](../API.md)。

## 安装与从 1.6.0 升级

核对下载包的 `.sha256`，在独立应用目录解包，执行 `node scripts/install.cjs`（Windows 使用 `node.exe`）。Pi 与 Pivane 适配成组安装，不单独升级 Pi；统一安装入口核对锁定依赖的实际解析，保留 brace-expansion 5.0.12、undici 8.11.2 与现有安全约束。

保存草稿和附件，等待任务、Shell、子 Agent、侧聊、定时、媒体、转录、会话移动及配置活动空闲；先停机并备份，再切换应用。保留身份、原生会话、凭据、模型、项目、媒体、记忆、调度和交付物的数据绝对路径，特别是 `PI_WEB_DEFERRED_FILE`。新旧服务不能同时写入同一身份。普通升级不迁移真实线程、不删除用户知识、不重装无关扩展，也不重复已完成的原生 MCP 迁移。

已有网络与登录设置保持；新安装默认回环监听。需要其他设备访问时先启用登录验证，再核对监听、防火墙和远程接入方式。代理设置不接管浏览器、系统 VPN、独立 CLI、任意 Shell 或第三方扩展。

恢复前停机并逐项核对原路径字节；启动后检查原生会话 ID、分支和语义。新服务已接收消息后不能直接以旧备份覆盖新消息。安装和恢复步骤见[安装与恢复](../INSTALL_RECOVERY.md)、[macOS](../MACOS.md)、[Windows](../WINDOWS.md)及[发布流程](../development/RELEASING.md)。

## English upgrade notes

Download `pivane-1.6.1.tar.gz` and verify its checksum. Extract it into a separate application directory and run `node scripts/install.cjs`. Keep all identity and data paths, including `PI_WEB_DEFERRED_FILE`, unchanged. Save drafts, wait for active work to finish, stop the old service and back up before switching. Never run both versions against the same identity. Pi 1.0.2 is installed with the application; do not upgrade it independently.

Existing authentication, listener and proxy settings are preserved. New installations bind to loopback by default; enable sign-in before allowing access from other devices. The attached validation report binds the installation, 1.6.0 upgrade, restoration and browser results to the exact archive. This release does not add native Windows, macOS, Safari or real-phone validation.
