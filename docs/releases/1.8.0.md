## 本版变化

- **Pi 1.2.0 成组升级**：使用原生 Codemode executor、输出及子 Agent 包解析，移除退役的 server/protocol/Chord 依赖和旧 host alias／输出适配。工具行显示原生耗时；保留 MCP 精确授权、任意 JSON 结构化结果、认证取消与失败不重放、媒体生成确认和会话所有权。
- **更可靠的运行生命周期**：启动 hook 使用原生命名 prompt section；慢 hook 与延迟 custom wake 在实际调用结束前保持占用，临时会话按原生内存会话 ID 识别。保存的模型不可用时等待用户明确选择，避免自动切换付费模型或发送草稿；模型 Token 限制统一校验，资源发现前验证原生主题。
- **持久队列和附件管理**：持久主线程在 RPC 前保存待发送文字、图片和文档引用，可跨 worker／服务重建恢复。保存证据不足时保持不确定，核对后明确追加。附件管理按全部分支、分叉凭据、预约、队列、定时任务及本页草稿检查引用，单文件预览后确认清理；忙碌、引用不完整或身份变化时保留数据。
- **完整的会话工作流**：复制／分叉有稳定请求编号、私有创建回执及结果查询，响应丢失不自动重建。移动后分叉继承经过验证的文件资格，支持嵌套分叉、父线程删除和服务重建；历史版本只指向当前会话文件中的有效分支。前缀核验有界读取，后续合法追加不会因总历史长度超过旧预算而丢失文件资格。
- **对话目录与压缩前回看**：桌面左缘刻度可定位问题、预览回复并加书签；手机在问题标题操作。压缩前问答按需每次读取12组，插入时保留阅读位置，与目录、历史搜索和原生书签联动。只读回看不改变模型的摘要上下文，也不改写原生历史。
- **清晰的加载与运行反馈**：启动屏、骨架占位、发送／思考／工具进度和压缩提示统一；长时间等待可见，网络设置结果就近显示。后台刷新保持动态列表阅读位置，正文输出不再关闭侧栏悬停统计，没有几何变化时保留线程菜单。文件卡片的延迟聚焦尊重用户后续选择；从管理页返回助手时重新读取项目与线程，保留草稿和附件。
- **显示兼容与保留策略**：公式兼容常见中文标点，保留原文、安全清洗及预算。受管保留默认保留最近5个发布目录和3份原生备份，并额外保护当前／回退、备份依赖及可验证恢复点；支持预发布版本。实际删除仅在具备目录描述符保护的 Linux 边界执行，缺少证明、损坏或身份变化时保留，macOS/Windows记录跳过。

## 安装、升级与恢复

1. 下载本归档及同名 `.sha256`，用 `sha256sum -c pivane-1.8.0.tar.gz.sha256`（macOS用 `shasum -a 256 -c`）核对。
2. 解压到新的独立目录，用Node22执行 `node scripts/install.cjs` 安装锁定依赖。不要复用其他平台的node_modules，也不要单独升级Pi或子Agent包。
3. 更新前保存草稿和附件，等待主／子任务、Shell、侧聊、预约投递、媒体和配置写入结束，暂停预约并正常停机；完整备份原生身份、媒体、队列、配置、旧代码和实际外部数据范围，再切换。新旧实例不能同时写同一身份。
4. 切换后核对实际版本、能力、完整分支、文件与队列。不确定请求查询原回执，不自动补发；新服务接收写入后，不得以旧备份覆盖新消息。恢复前停机核对原路径字节，再启动验证ID及语义。

最低Node22.19.0。完整步骤见[安装与恢复](../INSTALL_RECOVERY.md)。普通升级不执行全局JSONL替换，不搬迁真实会话，也不重复已完成的旧MCP迁移。公开发布不会替既有实例执行升级。

## 范围与限制

Chromium手机宽度模拟不等同于真实手机键盘、麦克风、系统剪贴板或后台行为。Safari/Firefox、Intel macOS、Windows ARM64、真实供应商计费及用户自有GPU环境不在本次验收范围。归档中的候选／旧正式版措辞保持冻结，以本Release及验证附件为准；主分支只补记发布文档，不重打包或改变标签。
