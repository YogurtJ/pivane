# Pivane 1.10.1（候选，Pi 1.4.0）

本版正在完成DOMPurify安全补修，尚未公开发布；当前正式版仍为[1.10.0](1.10.0.md)。修复已在GPU Linux和树莓派本机启用，最终归档、SHA256及平台覆盖以[GitHub Release](https://github.com/YogurtJ/pivane/releases)附件为准。Pi 1.4.0、pi-subagents 0.80.0、pi-hermes-memory 0.9.10与原生组件保持；本轮安全补修将undici更新至8.12.2、body-parser更新至2.4.0，并更新其必要的qs/iconv-lite依赖。

## 修复与改进

- **安全依赖**：修复body-parser压缩请求尾部处理和undici EventSource、完整性校验及过多内容编码相关公告；原有可选peer依赖保留，不降级Pi。DOMPurify直接依赖与Mermaid内嵌副本均更新至3.4.17；Mermaid11.17.2官方模块以锁定依赖重新打包，KaTeX内嵌依赖同步至0.18.7，构建审计为零漏洞。主安装图审计和渲染专项以最终验证附件为准。
- **执行归属与恢复**：打开会话、启动、命名和退出共享所有权；已提交命名超时保留不确定状态。线程间消息先保存原生发送意图再发布，中断后沿原ID恢复，不因准备响应丢失提前投递。Shell拒绝与不确定消息或迟到启动并行。
- **媒体方案**：先保存当前原生分支来源，再消费一次性自动执行资格。取消、响应丢失、重开或压缩后可查询原卡片，不重复生成；并发工具预占单轮额度，排队项先落盘再派发。
- **文件与附件**：下载取消后等传输和描述符清理结束才释放占用；附件用量通过全量流式校验减少完整Buffer保留。合法上传不再被已验证的清理残留单独堵住；未发送原件沿实际移动链和备份核对资格，分叉区分总原件与办公文档限额。
- **配置与记忆**：配置写入绑定读取时的原字节版本，所有等待和替换阶段遇外部修改均拒绝覆盖。长记忆修改要求完整正文唯一匹配，512字符预览不能授权替换或删除。学习任务的取消、历史、并发槽与实际工作结束同步。
- **交互与性能**：线程/页面切换拒绝迟到导航；录音转录不混入下一份草稿；文件补全仅共享同次编辑的在途请求，完成或失败后不缓存。学习状态复用同次可信快照计数，问答提取每次只建立一次上下文编辑索引。更新提示点不再挤偏导航布局。
- **成果库与兼容**：目录和回执按实际UTF-8字节检查预算，避免写出不可读目录；管理助手身份继续受消息寻址和渠道绑定限制。更新开发导航与过时功能契约。

完整变化见[CHANGELOG](../../CHANGELOG.md)。性能比较来自合成负载，不保证所有实际实例获得相同比例收益；文件身份、完整内容核验、CAS、来源复核和不重放边界保留。

## 兼容注意

旧内置 **MiniMax TTS adapter及入口已移除**。已有registry条目加载时停用，原配置、凭据、历史音频和记录保留；MiniMax视频、聊天模型、自定义HTTP模型及其他语音Provider不受这一移除影响。依赖旧adapter的用户需明确选择其他已配置语音模型，不会自动改用付费服务。

升级沿用原身份、会话、附件与媒体路径，不迁移或文本改写JSONL。保存草稿，等待实际工作结束，正常停机备份后切换独立代码目录；不确定提交先查原回执，恢复不能覆盖升级后新接受的消息。详见[安装与恢复](../INSTALL_RECOVERY.md)。

## 验证与已知限制

按[验证范围与证据复用](../development/RELEASING.md#验证范围与证据复用)引用匹配源码的GPU定向结果和树莓派安装、ARM64原生/SDK、相关Node/浏览器及真实部署证明；最终包的平台定向补验与完整性结果将记录在包外验证附件中。复用不是再次执行全量，Linux实机证据也不冒充Mac或Windows原生检查。

DOMPurify直接依赖和Mermaid内嵌副本均为3.4.17。官方Mermaid预构建仍含旧副本，因此采用其11.17.2官方模块，使用独立构建锁与esbuild0.28.2重新打包；KaTeX0.18.7同步修复构建图中的旧数学依赖公告。构建来源、锁和哈希见[Mermaid指南](../MERMAID.md)，最终生产审计及受影响渲染验证分别记录于发行附件。手机视口不代表真机键盘、麦克风或后台行为，合成服务不证明真实供应商计费；不宣称Safari、Firefox或其他架构已验证。

## English

Pivane 1.10.1 is completing its sanitizer security update before public release. It fixes session ownership, durable message/media recovery, attachment handling, configuration conflicts and several navigation/voice-input races, while reducing repeated file queries and memory usage. Pi and native components remain unchanged. This release updates undici to 8.12.2 and body-parser to 2.4.0, including required qs/iconv-lite updates, and upgrades both direct and Mermaid-embedded DOMPurify to3.4.17. The official Mermaid11.17.2 module is rebuilt using a pinned isolated recipe and KaTeX0.18.7. The legacy built-in MiniMax TTS adapter is removed without deleting stored configuration or audio; MiniMax video and chat support are separate.

Use the final SHA256-bound validation attachment for current checks and explicitly reused evidence. Preserve data paths, back up while stopped, and never replay uncertain submissions or overwrite new messages during recovery. The production and isolated browser-build audits are reported separately, with rendering and isolation coverage bound to the final archive.
