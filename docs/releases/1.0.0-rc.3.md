# Pivane 1.0.0-rc.3 · 会话整理与 Pi 更新

本候选版汇总 RC2 之后的工作台改进，并将 Pi Coding Agent 及配套官方依赖锁定到发布时 npm 最新正式版 **0.85.1**。

## 本版变化

- **AI 会话标题**：新建未命名线程在首轮有效问答后自动命名；支持手动重新生成、预览编辑后保存。已有名称和历史受保护。可选择专用标题模型，失败时保留原标题。
- **辅助模型**：在使用偏好中按用途统一管理标题生成和媒体规划模型，保留已有设置，支持统一保存与全部设为自动。
- **版本与更新**：分别查看 Pivane、当前 Pi 和包内配套版本，检查 GitHub/npm 更新。Pi 可在网页确认后受管安装、兼容检查、停机备份和切换，显示真实命令输出、退出码和最终版本；另提供仅备份与重启。Pivane 应用仍按发布包手动更新。
- **项目与会话归档**：独立归档、恢复和查看项目或线程，搜索可包含已归档项；归档保留原始数据，运行及待处理状态仍可追踪。“历史与记录”集中相关会话工具。
- **系统提示词**：查看当前会话实际加载的系统提示，编辑全局或项目的 Pi 原生 SYSTEM.md / APPEND_SYSTEM.md，支持预览、差异、恢复默认和显式重新加载。
- **设置与运行细节**：改善使用偏好与 Packages 的手机布局、资源概览和失败恢复；补齐 RPC 启动就绪检查、正常停机进程清理及中英文更新反馈。

功能与限制见[用户指南](../USER_GUIDE.md)、[辅助模型](../AUXILIARY_MODELS.md)、[原生设置](../NATIVE_SETTINGS.md)和[版本与更新](../UPDATES.md)。

## 安装与升级

下载 `pivane-1.0.0-rc.3.tar.gz` 和同名 `.sha256`，校验后使用 **Node.js 22.x** 执行 `npm ci`、`npm start`。无需全局安装 Pi、前端构建或现场编译包内原生组件。Pi 受管更新入口支持 Node 22.x / 24.x；本发行安装验收基线为 Node 22.23.2。

从 RC2 或更早版本升级，先结束任务、暂停预约、保存草稿和附件，停机并整批备份。将发布包解压到新的版本目录，沿用原身份、数据和项目绝对路径及启动配置；不要让新旧服务同时写同一身份。使用受管 Pi 快照的实例更新 Pivane 时，也应从新的发布目录启动，具体见[更新文档](../UPDATES.md)。

`npm start` 和 `node server.js` 自动使用受管启动器；只读安装或开发可使用 `npm run start:direct`，该入口不提供网页受管更新。自动标题默认开启，额外模型请求最多摘录 8,000 字符问答正文，可能产生供应商费用，可在使用偏好关闭或指定模型。

安装步骤：[Linux](../INSTALL_RECOVERY.md) · [macOS](../MACOS.md) · [Windows](../WINDOWS.md) · [English](../en/INSTALL.md)。

## 验证范围

精确包 SHA256、测试数量、浏览器专项及 RC2 升级和原路径恢复结果随本 Release 的 `pivane-1.0.0-rc.3.validation.json` 提供。验收使用独立身份、实际归档安装与合成服务，不调用真实付费供应商。

本版验收平台为 Linux ARM64、Node 22.23.2。macOS、Windows 和 Linux x86_64 的 RC1 原生基线仍可参考，但未在本 RC3 包重跑；尤其 Pi 自动维护流程在这些平台尚无原生实机验收。桌面和手机宽度 Chromium 测试不等于 Safari 或手机操作系统验收。Pi 0.85.1 基础兼容通过不代表未来所有 Pi 版本、第三方扩展或真实模型组合均已验证。

原生会话和现有 PI_* / pi5-* 标识保持兼容；归档不会删除会话，保存提示词不会停止当前任务。已接受的更新操作不会因关闭页面而取消，失败或结果不确定的请求不会自动重放。发布不会自动升级已有部署，旧 RC 标签与附件保留。

## English

RC3 brings AI session titles with a dedicated model option, unified auxiliary model preferences, project/session archives, native system prompt viewing and editing, and improved settings and Packages layouts. **Pi Coding Agent and its companion dependencies are pinned to 0.85.1**, the latest stable npm version checked for this release.

Settings now checks Pivane and Pi versions separately. Managed Pi updates install and validate an isolated snapshot, stop and back up the instance, then switch versions. The UI shows real command output, exit status and the final version; backup and restart actions are also available. Pivane application upgrades still use release archives. See [updates](../UPDATES.md).

Verify the archive checksum, use Node.js 22.x, and run `npm ci` followed by `npm start`. Both `npm start` and `node server.js` use the managed launcher; `npm run start:direct` is available for development or read-only installations. Before upgrading, finish tasks, pause schedules, save drafts, stop the old instance and back up all data. Install into a new code directory while retaining absolute data/project paths. Automatic titles are enabled by default and may incur model charges; disable them or select a model in Preferences.

The attached validation JSON binds checks to this exact archive. RC3 acceptance covers Linux ARM64 with Node 22.23.2, isolated synthetic services and Chromium desktop/mobile viewports. macOS, Windows and Linux x86_64 were not rerun with this artifact; earlier platform results remain historical baselines. No real paid providers or native mobile operating systems are certified by these checks. Publishing does not update existing installations.
