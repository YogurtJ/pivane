# Pivane 1.3.0 · 候选（未发布）

此页记录已完成隔离验收的 1.3.0 源码候选，不是下载链接或正式发行公告。**当前公开正式版仍为 [1.2.0](1.2.0.md)**。本版保持 Pi Coding Agent 0.87.1，建议 Node.js 22.x（至少 22.19）。最终归档的 SHA256 与对应验收报告须随包单独提供；不得把源码、历史浏览器回归或此前内置组件的其他平台验证当作本包整包验收。

## 主要变化

- **定时任务和主线程**：服务端提供五段 cron、单次时间、时区、生效时间与未来五次预览；可投递文字问候或在线程内执行工作。默认新任务停用，启用或手动运行才实际调用模型。忙时排队、错过处理、静默结束、预算、占位和不确定运行核对详见[定时任务](../SCHEDULED_TASKS.md)。预算是估算控制，不是供应商账单硬上限。
- **文件预览与交付物**：明确调用 `deliver_files` 可将授权成果保存为私有只读快照，在当前原生分支打开、下载和核对；文件面板预览图片及隔离 HTML。交互 HTML 并非完全离线沙箱，只对可信内容手动启用脚本。更多范围、限制和恢复须知见[文件浏览与查看](../FILE_VIEWER.md)。
- **工作台与性能**：紧凑导航、手机输入布局、空线程起步卡、状态汇总及可展开的子 Agent 通知；会话列表元数据有界缓存、按项目优先加载线程、公开静态资源协商压缩、档案索引移入工作线程，长会话首开仍受原生发现影响。冷启动等待和无响应 worker 恢复采用有界探测，不中止正在运行的 worker。
- **安全与兼容**：生产树的 `undici` 约束至 8.11.2，修复所述 WebSocket 漏洞；不会因此升级 Pi 或任意扩展。扩展发现对 PPT Master 技能核对范围、启用状态及声明，不代表依赖或当前会话已就绪。定时任务网页兼容普通 HTTP 局域网下缺失 `crypto.randomUUID` 的浏览器。

完整细节和已实现边界见 [CHANGELOG](../../CHANGELOG.md)、[用户指南](../USER_GUIDE.md)和[API](../API.md)。

## 从 1.2.0 升级与回退

在独立应用目录安装锁定的新版代码和依赖，使用 `node scripts/install.cjs`；Windows 用 `node.exe scripts/install.cjs`。**不要覆盖 Pi 身份、会话、媒体、项目、配置或其他扩展**。先核对所有任务、Shell、侧聊、预约、媒体和配置操作；停止旧服务并做一致的停机备份，再切换应用代码。旧新版服务不能同时读写同一身份与调度数据库；不要在承载当前 Agent 对话的服务上直接执行停机。固定既有 `PI_CODING_AGENT_DIR`、媒体目录及 `PI_WEB_DEFERRED_FILE` 的绝对路径；若旧实例从 3001 迁到默认 11408，先保留原预约队列路径，再同时调整 `PORT`、`PI_WORKSPACE_BASE_URL` 与访问地址。

**定时任务不会自动接管外部调度器。** 若从 Hermes/Clover 等迁移，先停用状态建新任务、核对时区/目标/模型/提示词并受控试跑；确认旧任务无运行及待投递后暂停旧任务并回读，再启用新任务。保留旧配置和备份用于回退。恢复旧版时先停用新调度并核对，再按停机备份恢复整批数据，不与新服务同时运行。备份须包含身份目录下的 `pivane-cron`、`pivane-deliverables` 和原有会话、配置及媒体数据；旧版无法识别新调度和交付物，不应当把不可见当作丢失。操作指南见[安装与恢复](../INSTALL_RECOVERY.md)。
