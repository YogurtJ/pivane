# Pivane 1.0.0-rc.2 — 中文 / English

第二个预发布候选版本，为同一套工作台加入简体中文和英文界面，并补齐英文入门文档。RC1的标签与下载文件保持不变。

## 本版变化

- 1,931条中英文文案，覆盖当前聊天控件、项目线程、历史、文件、侧聊、附件、Shell、设置、媒体表单与提交清单，以及已知应用提示。
- 首次按浏览器偏好列表匹配首个受支持语言；中文变体使用简体中文，英文变体使用英文，没有匹配时回退英文。
- “设置 → 使用偏好 → 界面语言”可选择跟随浏览器、简体中文或English，保存在当前浏览器的此站点。**下次打开或刷新页面生效**，保存不自动刷新或中断当前工作。刷新前请保留草稿与附件；临时会话、侧聊沿用原有结束规则。
- 聊天、思考、工具正文、文件内容、用户自定义名称、已保存模板和媒体参数保持原文；界面语言不改变模型回复或朗读语言。
- 日期和数字显示跟随界面语言；平板设置导航使用网格以避免较长标签溢出。静态翻译只处理明确标记的应用文字，初始化后移除标记，保留原来的文字节点结构。
- 增加[英文首页](../../README.en.md)、[英文安装指南](../en/INSTALL.md)、[英文用户指南](../en/USER_GUIDE.md)和[语言契约](../I18N.md)。

## 安装与升级

下载 `pivane-1.0.0-rc.2.tar.gz` 及同名 `.sha256`，先校验再按[Linux安装与恢复](../INSTALL_RECOVERY.md)、[macOS](../MACOS.md)、[Windows](../WINDOWS.md)或[英文指南](../en/INSTALL.md)操作。

继续使用Node22.x、锁定的Pi0.85.0，以及与RC1相同的依赖和原生组件。不需要前端构建、全局Pi或安装时编译原生组件。本版没有服务器配置或会话格式迁移，沿用现有PI_*、pi5-*、API/RPC和数据目录；新增语言偏好只存在浏览器。

从RC1升级时，先结束任务、暂停预约、保留草稿，停机并整批备份。解压到新的版本目录，运行 `npm ci`，复制实例启动配置，继续使用原来的数据和项目绝对路径。不要同时运行新旧服务并共享身份。各个人部署不会因GitHub发布自动升级。

## 验证范围与限制

精确归档SHA256、平台、测试和升级恢复结果随本Release的 `pivane-1.0.0-rc.2.validation.json` 提供；发布验证从实际归档创建独立身份和合成服务，不使用真实付费供应商。开发双语浏览器回归覆盖320/393/768/1440宽度，以及原有功能专项。

RC1的Linux、M2/macOS、Windows原生验收仍为历史基线，不能把它当作RC2在这些机器上全部重跑的证明。此版未修改原生源码、二进制或服务器业务模块，其他平台的本包补验以validation.json的实际记录为准。浏览器手机宽度不等于Safari或手机操作系统验收。

旧媒体界面、后台Web Push文字、部分外部诊断和高级文档仍保留原语言。没有新增多用户隔离、自动更新、工具沙箱或完整会话树跨路径迁移。不要重复提交结果不确定的请求。

## English

This second prerelease adds **Simplified Chinese and English** to one Pivane workspace, with 1,931 message pairs and English getting-started documentation. RC1's tag and assets remain unchanged.

The first visit uses the browser's preferred supported language, falling back to English. Choose **Settings → Preferences → Interface language** to save a browser-specific preference. **Changes apply on the next page load**; saving does not automatically reload or interrupt work. Preserve drafts and attachments before refreshing, which ends temporary sessions and side chats.

Application controls, known messages, settings, file/history tools and media review are translated. User/model content, code, filenames, custom names, saved templates and generation parameter values remain unchanged. Interface language does not set reply or speech language. The legacy media interface, background push text, some external diagnostics and advanced documents may retain their original language.

Install the verified `pivane-1.0.0-rc.2.tar.gz` using the [English installation guide](../en/INSTALL.md), then follow the [user guide](../en/USER_GUIDE.md). Node22.x, Pi0.85.0, dependencies and native components are unchanged from RC1. There is no server-data migration. For upgrades, pause scheduled messages, stop tasks, back up the complete instance, stop the old service and install into a new code directory while retaining the original absolute data/project paths.

The Release's validation attachment binds actual checks to the archive SHA256. RC1's cross-platform results are a historical baseline, not proof that every platform was retested with RC2. Synthetic providers and browser viewport tests do not certify paid services or native mobile operating systems.
