# Pivane 1.5.0 · Pi 1.0、模型速度与语音输入

2026-10-02 正式发布，成组锁定 Pi Coding Agent 1.0.0，内置 pi-subagents 0.74.0 和 pi-hermes-memory 0.9.9。推荐 Node.js 22.x（至少 22.19）。下载包、校验文件与准确归档验收见 [v1.5.0 Release](https://github.com/YogurtJ/pivane/releases/tag/v1.5.0)。旧归档不修改，公开发布不表示运行实例已切换。

## 主要变化

- **Pi 1.0.0 与内置子 Agent**：适配原生 MCP 名称规范化、按需连接、Codemode 暴露别名及重载；更新官方 pi-subagents 至 0.74.0，并在 Pivane 边界适配宿主导出和子会话工厂。父子工具授权、嵌套权限、项目信任和技能继承继续受限，不改 vendor 官方实现。MCP 网页支持 description、OAuth 客户端名称／元数据及全局 HTTP auth.provider，私密字段不回显。详见[原生 MCP](../MCP.md)和[内置能力](../BUNDLED_CAPABILITIES.md)。
- **模型速度**：有能力声明的模型可选 Standard／Fast／Ultrafast，与思考等级独立；设置页管理默认、渠道参数与费用倍率。主会话选择按原生分支恢复，侧聊可独立选择，辅助任务使用各自模型默认。费用按实际服务档位计价，未知档位明确标注估算，不保证供应商加速效果或实际账单。详见[模型设置](../PROVIDER_SETTINGS.md#模型速度fast--ultrafast)和[用量](../USAGE.md)。
- **语音与输入区**：运行时空草稿显示停止，有文字／引用／附件显示发送，投递方式移到加号菜单。麦克风录音或 WAV／MP3 经已配置 MiMo／受支持的 OpenAI 兼容 ASR 转成可编辑草稿，不自动发送；取消／切线程等释放本地录音，已上传请求不因关面板而撤销，不自动重试。详见[语音转录](../COMPOSER_TOOLS.md#语音转录)。
- **线程跨项目移动**：普通空闲持久线程先预览再确认，保留原生 ID、时间和完整树；只改变 header cwd，历史正文及工具参数不文本替换。用量、归档、提醒和经证明的历史交付跟随线程；保留原始备份与中断日志，不自动重放。首版不支持助手绑定、任务／消息关系、预约／定时引用、被其他分叉引用的父线程及未完成后台工作。详见[会话工作流](../SESSION_WORKFLOWS.md#移动线程到其他项目)。
- **知识写前比较**：助手创建记忆／技能先查看相关旧内容，再按短期比较 token 提交；后台学习在原有一次辅助模型调用中选择跳过、新增、补充或纠正，跨 USER／MEMORY 保守查重。技能整理优先更新已有流程，支持核实来源的项目技能删除／撤销，不自动删除合并条目或改写成品技能。语义候选检索有界，不保证发现所有重复。详见[记忆适配](../PROFILE_MEMORY.md)。
- **长回复与设置体验**：公式用 TeX／HTML 总量预算替代固定数量截断，修复短公式误滚动；模型编辑持久化原生 modelOverrides，保留未知字段；侧聊执行确认分层展示参数，保持逐回复授权。模型覆盖须空闲重载或重开 worker 才生效。

完整改动见 [CHANGELOG](../../CHANGELOG.md)、[用户指南](../USER_GUIDE.md)及[API](../API.md)。

## 从 1.4.0 升级

使用部署机器上的独立维护 Agent，不直接停止承载当前对话的服务。先核对任务、Shell、侧聊、预约、定时、媒体、转录、线程移动及配置操作，保存浏览器草稿／附件，等待空闲；旧服务停止后完成一致的原始备份，再在独立应用目录安装准确包，运行 `node scripts/install.cjs`（Windows 使用 `node.exe`）。新旧服务不能同时读写同一身份、原生会话或调度数据库。

**只替换应用与锁定依赖，保留身份、原生会话、认证、模型、项目、媒体、记忆、调度、交付物及其他扩展。** 数据路径保持绝对且不变，特别是 `PI_WEB_DEFERRED_FILE`；变更端口时同步 `PORT`、`PI_WORKSPACE_BASE_URL` 和访问地址，不另建队列。备份包含整个身份目录中的 `pivane-session-moves`、速度偏好、用量账本、cron 和交付目录。普通升级不移动真实线程、不清理用户知识，不安装／重装无关扩展。

Pi 与原生适配须一起升级，不独立切换 Pi。本版保留 brace-expansion 5.0.12、undici 8.11.2 和 DOMPurify 3.4.16 安全约束，统一安装入口核实实际依赖解析，未知 shrinkwrap 布局失败关闭。Pivane 使用未打包 SDK／RPC，依赖目录修正不宣称覆盖 Pi 自带 bundle 内联字节。

### 兼容与隐私边界

- 已完成原生 MCP 配置迁移的 1.4.0 实例**不重复迁移**。旧 pi-mcp-adapter 用户仍须按[迁移指南](../MCP.md#从-pi-mcp-adapter-迁移)审查后显式停机转换；旧包和 OAuth 保留，不自动转换凭据。MCP 打开／保存配置不连接服务器，当前线程加载另行核对。
- 官方 Codemode 的 `models.generateImages()` 在主／子任务中拒绝直接执行；仍须使用 Pivane 媒体规划和用户确认票据。升级不扩大媒体执行权限，也不自动选择其他模型。
- 语音录音最多两分钟，WAV／MP3 最大 7.5MB；结束并转录才把音频上传所选供应商并使用账户额度。录音与转录正文不写媒体历史／会话，发送文字后才进入原生会话。进程内请求去重不是跨重启的永久执行账本，超时先核对，不自动重放。
- 线程移动首版只支持同一文件系统内、不超过 64 MiB 的原生 v3 文件；引用检查及日志有预算，未完成／中断状态阻止两端写入，需维护者核对记录与备份。独立 CLI 不得同时写入同一会话。
- 新速度默认只影响新选择，旧会话保留原方式；费用倍率是估算。供应商实际档位／价格可能不同，以其账单为准。

### 恢复

保留旧应用与一致停机数据备份。新服务接受消息后不能直接以旧数据覆盖新消息；代码回退不自动撤销已完成的线程移动或配置变化。恢复前停机、逐项核对路径和字节，启动后核对原生 ID、分支及语义，不文本替换 JSONL 正文。详细步骤见[安装与恢复](../INSTALL_RECOVERY.md)。
