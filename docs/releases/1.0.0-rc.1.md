# Pivane 1.0.0-rc.1

首个公开候选版本，采用ISC许可证。发布资产及发布时间见[GitHub Release](https://github.com/YogurtJ/pivane/releases/tag/v1.0.0-rc.1)。Pivane应用版本为1.0.0-rc.1，包内Pi版本为0.85.0；标签与资产固定已验收版本，主分支项目介绍可以继续完善。

## 主要能力

- 在浏览器管理Pi原生项目与会话：持续对话、附件、工具、Shell、停止、压缩、搜索、书签及会话树。
- 阅读文件差异、全文、Markdown、公式与Mermaid；支持临时侧聊、分叉、导入导出、用量和通知。
- 配置自己的聊天供应商及图像、视频、语音服务；媒体参数先规划和检查，确认后单项执行。
- 提供Linux、Apple Silicon macOS及Windows 11 x64原生适配，普通安装无需现场编译原生文件系统组件。
- 文档分别面向用户、用户的Agent和源码开发者；维护者私有记录不进入发布包。

## 获取与安装

从发布者提供的Release下载以下同名文件：

- `pivane-1.0.0-rc.1.tar.gz`
- `pivane-1.0.0-rc.1.tar.gz.sha256`
- `pivane-1.0.0-rc.1.tar.gz.manifest.json`
- `pivane-1.0.0-rc.1.validation.json`

先核对来源和SHA256，再按[Linux安装](../INSTALL_RECOVERY.md)、[macOS](../MACOS.md)或[Windows](../WINDOWS.md)安装。使用Node22.x（验收基线22.23.2）、锁文件npm ci及各平台所需的Bash/ripgrep。首次安装需要npm网络访问，没有默认可用的模型凭据或媒体服务。

内置TRIAL_MANIFEST.json保留原文件名以兼容现有工具，其中appVersion是Pivane版本，piVersion是Pi依赖版本。/api/pi/status.version仍表示实际加载的Pi版本。逐文件清单与包哈希用于确认安装内容。

## 升级与数据

Pivane名称沿用已有PI_*、pi5-*文件、API/RPC和浏览器偏好键。无需为改名迁移安装目录、身份或系统服务。

从早期试用包升级前，处理未保存草稿、暂停预约并等待任务结束，停机整批备份。旧包可能有上述退出问题，应先在网页显式结束各runtime和侧聊，再停机并确认进程确已结束；不能把异常退出计作正常清理完成。新代码放独立版本目录，运行npm ci后沿用固定数据绝对路径。不得同时启动新旧版本共用同一身份；恢复要求原路径，完整会话树跨路径迁移尚未提供。

本版本修复加载模型设置后停止信号可能提前结束异步清理的问题：保持停机监听直到清理完成，重复信号不重复执行清理，清理失败仍以非零状态退出。提供可移植的npm test和版本化pack:release入口，随包LICENSE及第三方声明。详细停机、备份和回退步骤见[安装与恢复](../INSTALL_RECOVERY.md)。

## 支持范围与限制

已验收的平台基线包括Debian ARM64、Ubuntu24.04 x86_64、M2/macOS26.5.1、Windows11 x64/NTFS。该RC包实际复验的平台、Node版本、测试与恢复结果以同名validation.json为准；其artifactSha256必须与下载包一致。旧基线不替代当前包验证。

尚未验收Intel Mac硬件、其他macOS版本、Windows10/Server/ARM64、ReFS/exFAT、网络/映射盘、Safari/Finder剪贴板和真实手机后台推送。Windows原生支持不依赖WSL。不会把浏览器手机宽度检查称为手机真机验证。

真实供应商与自有GPU环境由用户配置；合成服务测试不代表每种媒体服务均已实测。媒体失败或结果不明不自动重试。项目目录范围不是工具沙箱，个人实例不提供多用户身份隔离。暂不包含自动更新、系统服务安装器或离线模式。
