# Pivane 1.10.0（候选，Pi 1.4.0）

本版已定版为 1.10.0，发布前验证覆盖已补齐，等待公开发布确认。当前正式版仍为 [1.9.1](1.9.1.md)。最终发布以 [GitHub Releases](https://github.com/YogurtJ/pivane/releases) 的归档、SHA256 和验证附件为准；源码完成、本机启用与公开发行分别记录。

## 本版变化

- **Pi 1.4.0 与子 Agent**：成组绑定官方 Pi 1.4.0，内置 pi-subagents 更新至 0.80.0，pi-hermes-memory 保持 0.9.10。使用上游 MCP 就绪与完成通知持久化，保留精确工具授权、媒体确认、原生 SessionManager 和 JSONL。撤销的委派工具在重开、重载和树导航后保持撤销；仅排除按需加载入口时仍提供已允许的委派工具，dynamic 切换 eager 正确加载默认委派。
- **图片上下文**：统一检查新图片、有效历史与工具图片，依据实际模型能力处理数量、尺寸、格式和字节限制。纯文本模型使用省略提示，切回支持图片的模型后可重新使用上下文中的原图；转换只作用于出站副本，不改写会话历史。详见[输入与附件](../COMPOSER_TOOLS.md)。
- **通用附件与可恢复输入**：支持音视频、压缩包及其他原件，单个通用文件最多 100 MiB、单批 200 MiB；Office/PDF 仍为单个 20 MiB、每条最多五个，附件总数八项。新图片同时保存可下载原件。`get_attachment` 按当前分支授权将原件复制到项目 `.pivane-attachments`，保留修改过的工作副本。
- **粘贴与拖放**：文件逐项处理，失败时保留文字、路径或文件名以及成功附件。区分待发送、已上传和上传结果待确认；不确定上传按原编号查询，不自动重传。超出草稿限额的回退文字保留为可复制内容。
- **项目移除**：已移除的项目不再出现在会话移动、定时任务、渠道和成果等项目选择器中；清理相关偏好状态，保留原生会话与文件。详见[会话工作流](../SESSION_WORKFLOWS.md)。
- **下载与退出修复**：普通 HTTP 局域网地址下的文件下载不再依赖安全上下文的 `crypto.randomUUID`；显式退出期间避免退役 Shell 的中间广播引发另一已连接页面误报同步失败。
- **设置与翻译**：模型高级兼容设置读取 Pi 公开 API schema，重置保留未知和其他 API 字段。自动压缩的 Token 余量说明与实际触发阈值一致；修复新增说明插入翻译目录后导致英文导航、外观等静态标签错位的问题。

Codemode 达到本进程 VM 容量时按 FIFO 等待，等待计入执行期限；取消后的 VM 在实际退出前仍占用额度。原生恢复成对省略失败尝试及其工具结果，压缩保留自定义重点。MCP 配置迁移接受 UTF-8 BOM 并备份原始字节。完整变化见 [CHANGELOG](../../CHANGELOG.md)。

## 安装、升级与恢复

1. 待正式发布后下载 `pivane-1.10.0.tar.gz` 与同名 `.sha256` 文件，Linux 用 `sha256sum -c`、macOS 用 `shasum -a 256 -c`，Windows 用 `Get-FileHash -Algorithm SHA256` 比对。
2. 解压到独立新目录，用 Node 22 执行 `node scripts/install.cjs` 安装锁定依赖。不要跨系统复制 `node_modules`。
3. 保存草稿，等待主任务、子任务、Shell、侧聊、媒体、渠道发送、配置及导入导出结束；暂停待发送队列并保留原时间。正常停机备份身份、会话、附件、媒体、队列、配置和外部引用，再切换代码，保持原数据路径。
4. 启动后核对应用与 Pi 版本、原生会话分支、书签、受管工具、附件和队列。新增工具与 SDK 行为需在安全空闲时重新加载受管 worker。
5. 不确定提交先读取原回执，不自动重发。恢复先停机比对原路径字节，再核对原生会话 ID 与完整分支；新实例已接收写入后，不以旧备份覆盖新消息。

详见[安装与恢复](../INSTALL_RECOVERY.md)、[版本与更新](../UPDATES.md)。正常升级不迁移会话正文。

## English upgrade notes

Pivane 1.10.0 is a release candidate, not yet publicly released. It binds Pi 1.4.0 and pi-subagents 0.80.0 while retaining pi-hermes-memory 0.9.10 and native session storage. It improves image handling across the full request context, adds recoverable general attachments and branch-scoped original-file access, excludes removed projects from selectors, and fixes HTTP downloads, a cross-page quit warning and shifted English UI labels.

Install the verified archive in a separate directory with locked dependencies. Preserve data paths, save drafts, wait for active work, back up while stopped, then switch and reload workers while idle. Do not replay uncertain submissions or overwrite newly accepted messages with an old backup. Functional coverage for Linux ARM64, Apple Silicon macOS and Windows x64 is complete with a documented macOS fixture supplement and native-proof reuse; publication is awaiting confirmation. The original macOS browser failure remains recorded. DOMPurify findings remain unresolved by the maintainer's explicit decision; consult the SHA256-bound validation and audit attachments.
