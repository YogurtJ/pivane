# 命令、原生模板与项目文件引用

输入框命令与模板能力由 `/api/pi/status.composerTools=true` 标记，入口在输入联想、加号菜单和扩展的已安装页（Skills）中。

## 选中文字提问

在主对话或侧聊的单条消息正文内选择文字，选区附近会出现“加入主对话 / 在侧聊中提问 / 朗读选区”。桌面可右键唤出并使用方向键、Enter 和 Esc；手机保留系统复制菜单，并提供页面上的选区操作。跨消息选择、思考和工具记录暂不提供此入口。

“加入主对话”把选区放入输入区域的引用卡片，保留已有文字和附件；“在侧聊中提问”打开当前侧聊并加入引用草稿，不自动发送、不替换已有背景或重开已有侧聊。卡片显示来源、三行预览，点击标题展开，× 移除。用户可以继续输入问题再发送。

主草稿的引用与附件合计最多八项，发送正文沿用现有总长度限制；侧聊最多八段引用，引用与问题合计受侧聊返回的字符限额约束。超限明确拒绝，不截断。主输入框带引用时需先移除引用才能执行命令。切换线程、明确拒绝、提交结果不确定及新输入保护沿用原草稿规则；刷新不保留未发送草稿。朗读行为见[回复朗读](REPLY_TTS.md)。

引用只在本页草稿内存中暂存；发送时转换为可读的 `> [Quoted text · assistant]` 等来源标记和逐行引用文字，随原生用户消息进入会话，刷新后仍可显示引用卡片。来源标签是阅读提示，不是身份验证或权限授权。没有独立批注数据库、永久正文高亮或引用连线。

## 输入框入口

输入 `/` 搜索命令名或说明，列表可滚轮/触摸滚动，不再截断到八项。↑↓ 改变选择，Tab 填入首项或选中项，Enter 在已选择候选时只填入；没有选择候选时，Enter 保持原来的发送行为。Esc 关闭，Shift+Enter 换行，输入法组合键不会触发选择/发送。

输入框的加号菜单以接近输入框宽度的面板展开，提供“添加附件”“附件管理”“运行中消息投递方式”“延迟发送”和“创建定时任务”；行高与留白便于点击，内容较多或屏幕较矮时在面板内滚动。附件与延迟发送复用既有附件选择与预约表单。“创建定时任务”打开[定时任务](SCHEDULED_TASKS.md)表单并自动填入当前持久会话，无需输入草稿；未打开会话、断线或临时会话时不可用，后端未启用时隐藏。原会话操作菜单不再提供此项。投递方式用同风格菜单项展开引导（本轮工具后送达）和后续（当前任务完成后送达），当前选项带勾选标记，发送按钮提示所选方式。空闲时消息仍正常发送。菜单支持方向键、Home/End、Esc、Tab、点击外部关闭；选中动作前先关闭菜单，让文件选择器、预约窗口或任务表单接管焦点。断线/切线程会收起菜单，预约的可用性与草稿/附件读取状态沿用原工作流。

手机菜单和矮屏内容在面板内滚动，附件、预约和定时任务沿用各自焦点与提交规则。

命令、Skill、模板调用统一通过输入框 `/` 联想；文件通过 `@文件名` 模糊搜索。不再提供命令/项目文件对话框，也不接管 Ctrl/⌘ K。模板管理位于“扩展 → 已安装 → 其他选项 → 管理提示词模板”，也可输入 `/templates` 打开；管理入口不执行模板；调用时在聊天框直接填写 `/名称 参数`。迟到结果仍按输入、光标、线程和请求代次丢弃，不保存第二份历史。

命令来自 Web 操作、与当前 Pi 对应的内置命令映射以及原生 `get_commands` 的扩展、Skill、模板。内部导航命令不向网页公开。模板/Skill 使用原生 prompt/steer/follow_up 展开；扩展命令即使运行中也走原生 prompt 命令分派，因为 steer/follow_up 不支持扩展命令。Web 不为这些命令伪造用户消息。

## 附件添加与失败回退

粘贴、拖放和文件选择按文件逐项处理；批量中的成功项保留，失败项优先取回同时提供的文字，其次是浏览器实际提供的路径，最后是文件名。独立正文与文件可以一起加入，文件的重复名称或路径表示会去重。仅回填的名称／路径明确标为“未上传”，发送后仍保留这个说明；浏览器未提供真实路径时只使用文件名。

回退内容进入当前草稿，处理期间的新输入保留。选择文件时即绑定线程、连接和本次编辑；本地读取图片期间切换线程／连接，或关闭重开预约编辑器，会使旧读取失效，原件不会再提交到新目标。已经发出的上传保持原归属，迟到文件或上传结果不会进入新线程。回退文本超过草稿总限额时，在输入框旁完整保留，提供复制和移除；刷新仍会丢失页内未发送内容。

图片／文本显示“待随消息发送”；原件显示“已上传 · 待发送”，表示文件已保存，但消息尚未提交。网络或服务器错误造成保存结果不确定时显示“上传结果待确认”，保留原请求编号，点击该项只查询结果，不重传；处理或移除待确认项后才能发送。已发送原件以可下载卡片展示。

## 图片输入与模型切换

普通新图片在发送前检查模型能力和图片设置，不支持时保留草稿并提示切换模型或开启图片输入。实际模型请求出口再次检查完整有效上下文，覆盖历史用户图片、工具结果和后续工具轮次，也适用于受管侧聊和子会话。纯文本模型使用明确的图片占位说明，输入区状态显示省略数量；切回支持图片的模型后，仍在有效上下文中的原图重新参与请求。兼容处理仅作用于请求副本，不回写会话原始记录。

图片按实际字节核验格式和编码，规范 MIME；开启自动缩放时按当前模型的尺寸定义派生请求图片，并检查模型声明的每消息／每请求图片数量和上下文字节上限。检查预算为单张原始图片 32 MiB、有效上下文图片总量 128 MiB、单张 64 Mi 像素与单边 32768 像素；损坏或超限时提示消息／工具结果来源和处理建议。模型未声明的供应商限制仍可能由远端拒绝。

后端提供 `attachmentUploads=true` 时，新添加的图片同时保存原件引用；原件不随 Pi 的请求缩放改变，可从消息卡片下载。旧历史已被上游缩放的图片保留现有字节，不能恢复此前丢失的像素。单次图片仍最多六张、单张 6 MiB，编码后合计最多 24 MiB。

## 通用原件附件

持久线程支持音频、视频、压缩包、旧版 Office、其他图片格式和普通二进制文件。后端须提供 `attachmentUploads=true`；单个通用原件最大 100 MiB，单批附件总量最大 200 MiB，图片、文本、文档、原件和引用仍共用八项上限；每线程 256 MiB、实例 2 GiB／10000 项存储额度保持。

上传先保存私有原始字节，发送只加入文件 ID、校验和、名称、类型与大小。Agent 用 `get_attachment` 按当前原生分支授权把原件复制到项目的 `.pivane-attachments/<id>/<原文件名>`，再使用相应工具或技能转写、分析或解压；取得原件本身不会执行或解压文件。重复取用核对已有副本，副本被修改时明确拒绝覆盖。原件沿用办公附件的备份、下载、分叉引用与显式清理规则；项目中的工作副本独立保留。

## 上传办公文档与 PDF

在持久线程中，通过加号 → “添加附件”、粘贴或拖放上传 DOCX、XLSX、PPTX 和 PDF，然后输入任务，例如“总结合同”“分析销售表”“提取每页要点”。上传先保存原件，发送后在用户消息中显示文件卡片，可下载原件；文件正文由 Agent 按需读取，不会整份自动加入模型上下文。此功能要求后端 `documentUploads=true`；临时线程和侧聊不提供办公原件上传。

单个文档最多 20 MiB，每条消息最多 5 个文档，仍与图片、文本和引用共用 8 项附件上限。图片与文本沿用原有限额。旧版 DOC/XLS/PPT 可作为通用原件上传，使用 `read_document` 前须另存为 DOCX/XLSX/PPTX。办公解析不接收加密 Office 或包含宏的 Office 文件，需要密码的 PDF 须先解除密码；压缩包使用通用原件通道。

读取工具 `read_document` 先提供结构，再按范围返回内容：Word 按正文段落／表格行；Excel 按工作表、行和列；PPT 按幻灯片；PDF 按页提取可复制文字。结果有读取范围、后续位置和截断标记。Excel 公式返回原式及已保存的缓存值，未保存结果时为 `null`，不重新计算；日期等格式仍为原始值，并提供日期系统说明。图片文字、扫描页不自动 OCR，Office 原版布局、嵌入对象、图表数据、批注和 PPT 备注未提取。Office 在浏览器中提供下载，不提供原版预览或在线编辑。

原件保存在身份目录的私有 `pivane-uploads` 中，随身份目录备份，不进入源码包。发送的原生用户消息只保存文件 ID、SHA256、名称、类型与大小；读取资格来自当前完整原生分支，压缩保留引用，分叉继承已发送引用。上传本身不写聊天历史；移除草稿附件或刷新不会删除服务器原件。未发送文件允许原上传线程下载；该线程移动后，服务器通过已提交移动链、原生备份和目标前缀证明继承草稿下载资格，新旧上传格式均需核验，缺少或变化的证据明确拒绝，不能只凭相同会话 ID 放行。从历史问题创建的网页分叉也可下载该问题中经过验证的文档，草稿显示为可移除附件卡并复用原件，不重新上传。此下载资格不向模型开放，发送后仍须由当前原生用户消息授予读取资格。分叉证明与备份要求见[会话工作流](SESSION_WORKFLOWS.md#分叉与回退)。没有自动删除原件；每线程最多 256 MiB，实例最多 2 GiB、10000 项，到限额明确拒绝。导出 JSONL/HTML 不包含原件，跨实例迁移需要同时备份身份目录；在其他实例单独导入会话可能出现附件不可用。

服务器最多同时处理两项附件操作及两项解析。解析使用无供应商凭据的独立 Node 进程，V8 堆上限 192 MiB、20 秒超时；这不是整个进程 RSS 的硬限额。Office 最多 4096 个压缩条目、解压后 64 MiB、单个 XML 部分 8 MiB；超限提示缩小文件。单次正文结果最多约 24000 字符，Excel 单元格／公式最多各 2000 字符，总结果最多 256 KiB；PPT/PDF 每次最多 10 页，Word/Excel 最多 200 个单元。超限／截断均不冒充完整读取。

上传一次，网络错误不自动重传；页面仅用相同 requestId 查询保存结果。未确认时显示该标识，草稿和原有附件保留，迟到上传不会进入另一个线程的草稿。活动上传和读取参与维护空闲判断；解析取消或超时后等待子进程实际退出才释放额度。源码更新需要完整服务切换，单独更新静态页面不会启用。

## 附件用量与清理

后端 `documentStorage=true` 时，从加号菜单的“附件管理”，或设置 → 用量统计 → “附件用量与清理”打开。容量和数量汇总覆盖整个身份实例，文件明细只显示当前允许项目。不会自动删除原件；单次只清理一个经预览并明确勾选确认的文件。当前页的主草稿、切换线程前保存的页内草稿及预约编辑草稿也参与保护。

清理会核对所有已保存原生分支、规范会话目录中的受管子会话、分叉凭据、预约、持久排队意图，以及定时任务和未确认运行保存的引用。扫描不完整、遇到未知自定义会话目录、项目不可访问、存储损坏、超预算或文件变化时，只提供用量，禁止清理。预览与执行需全工作台空闲，且已打开的运行实例须先通过线程菜单退出并真正停止；空闲进程仍可能有扩展后台写入，不能仅凭 idle 状态删除原件。门禁关闭新的引用写入入口，核验不会启动或自动终止模型／worker；用量查看不要求退出运行实例。启用该能力的持久线程在菜单提供“退出运行实例”，保留本页文字和附件草稿；运行中退出需另行确认中断，不能撤销已发生的外部操作；处理完已打开线程后可从设置进入附件管理。尚未处理的兼容内存恢复或扩展草稿须先处理。

“未发现已保存引用”只说明上述范围的结果。其他浏览器未发送的草稿、外部／废纸篓中的会话副本、提示词或其他文件里保存的附件链接不能全部发现。确认前自行核对、备份需要的原件，并停止使用同一身份数据的外部 Pi 进程。清理永久删除服务器原件；这些外部引用或以后恢复的会话可能无法再读取它。

预览有效期为五分钟，引用变化后须重新预览。提交使用独立请求编号；响应丢失只查询原编号，不自动重复删除。清理凭据和删除标记保存在私有上传目录并随身份备份，旧上传请求不能复活已删除原件。仍不确定的结果需保留证据并由维护者核对，不自动继续未完成删除。此功能不删除图片消息中的 base64，也不清理成果库或其他媒体。

有可验证删除证据的中断残留会显示“附件清理残留待核对”，继续保守计入用量，不能下载、再次清理或用旧上传请求复活；它不会单独阻断其他合法附件的用量查询和上传。新回执按删除前证明的原件大小计费。旧格式只有匹配的删除标记与不确定回执、且残留结构可验证时才隔离处理：每项按 100 MiB 上界计入实例及每个线程预算，不展示未验证名称或归属；达到额度仍会拒绝新上传。未知、篡改或无法验证的残留继续报错，不自动补删。

## 语音转录

主输入框的麦克风使用已接入的 ASR/STT 模型：有可用模型时，点一次立即录音，再点结束并转录；结果追加到当前可编辑草稿，由用户发送。未配置时只提示“没有可用的转录模型。”，右侧“去配置”直接打开设置 → 模型与能力 → 语音。录音最多两分钟，到时自动结束；取消、切换线程、断线或页面进入后台会释放麦克风并放弃尚未上传的录音。麦克风需要 HTTPS 或 localhost 和浏览器许可。提示条使用关闭图标，取消尚未结束的录音；不再提供音频文件上传入口。

“语音”与图像、视频使用同一种配置弹窗。默认打开“语音合成（TTS）”，可新增、编辑 TTS 模型，并通过“朗读默认配置”选择回复朗读的模型、音色和参数；“语音转录（ASR）”页签管理录音转文字模型。“去配置”直接打开 ASR 页签，不在设置页下方展开表单。转录配置可手动填写模型 ID、服务地址和凭据，也可复用已接入语音服务的地址与 Key；协议与认证按需展开。保存配置不会上传录音。录音默认模型保存在当前浏览器，配置成功或关闭设置后重新读取目录，下次点击麦克风直接使用所选模型。删除转录模型保留共享服务与凭据。

网页录音在本地转换成单声道 16kHz WAV，结束并转录才上传至所选供应商，使用其账户额度。仅继续打字时，文字追加到最新草稿，保留原文字、引用和附件，不自动发送。录音或转录期间如果已经发起发送、引导／后续消息、命令、Shell 或首次预约，迟到结果留在转录面板，可检查／编辑后手动加入当前草稿或复制；提交失败或结果不明也保持这项保护。编辑已有预约不消费主草稿。线程或连接变化同样使自动追加失效。转录正文和原音频不写入媒体历史或持久会话；发送后文字才进入原生会话。页面刷新会失去未发送文字。

已有原生模型目录继续复用公开 ModelRuntime 的认证，识别官方 MiMo（包括中国／全球 Token Plan 渠道）与已登记的 Whisper／GPT 转录 ID。手动接入的转录模型使用媒体服务管理的公共凭据生命周期，支持音频转录 multipart 接口或音频消息 JSON 接口，可填写服务端实际模型 ID；转录定义不进入聊天或实验室生成模型目录。服务来源变化后须重新绑定凭据，配置修订变化会在上传前拒绝。网页入口需要支持 `transcription=true` 的后端。

每次请求只上传一次，不自动重试网络错误或超时。同一请求标识在本进程内保留 15 分钟的结果或失败，重复提交不会重复上传；不同录音不能复用标识。转录超时为 180 秒，远端可能已经处理音频；浏览器收起面板或切线程不表示取消已上传的请求。活动转录计入维护空闲判定，服务正常关闭时等待已开始的转录结束。

## 内置命令的网页行为

| 命令 | 网页操作 |
|---|---|
| `/settings`、`/login`、`/logout`、`/scoped-models` | 打开相应设置入口；不自动删除凭据，不声称已实现所有终端设置 |
| `/model [provider/model]` | 从当前运行时目录验证并切换；省略参数聚焦模型选择器 |
| `/thinking [level]` | 从当前运行时思考等级验证并切换；省略参数聚焦选择器 |
| `/name [名称]` | 通过已有命名 REST 改名；活跃 session 仍由 worker 写入 |
| `/session` | 打开当前会话详情 |
| `/new`、`/resume` | 新建当前项目线程或打开现有线程选择入口 |
| `/fork`、`/clone` | 打开已有历史问题分叉或当前分支复制窗口，仍需既有确认 |
| `/compact [要求]` | 原生 compact RPC；收到手动 compaction_start 后清除匹配的命令草稿 |
| `/copy`、`/quit` | 复制最近回复，或通过 quit_session 退出运行实例 |
| `/reload` | 空闲互斥区中通过本项目扩展调用公开 ctx.reload() |
| `/hotkeys` | 显示网页实际支持的快捷键 |
| `/btw` | 保留原侧聊行为 |
| `/templates` | 打开扩展 → 已安装页“其他选项”中的提示词模板入口；不提供独立的命令与文件面板 |

`/tree` 在 sessionTree 标记启用后打开右侧历史的会话树，无参数、不调用模型或直接导航；成功打开才清除匹配命令，临时/旧后端拒绝并保留草稿。完整交互见 [HISTORY.md](HISTORY.md)。`/share` 以及上游 `/changelog` 显示未接入/仅终端支持，不能发送给模型冒充执行成功。新后端 nativeSettings 启用 `/trust` 的独立项目信任窗口和 `/scoped-models` 的折叠配置分类直达；不接受 trust 参数、不自动保存决定。`/export` 和 `/import` 是本地窗口快捷入口，分别打开当前持久线程的导出窗口和默认当前项目的导入窗口；不接受参数，不向模型发送。成功打开仅清除匹配命令，拒绝保留输入；上传附件仍按既有本地命令规则拒绝，文件应在导入窗口中选择。受保护 REST 的格式范围见 [SESSION_TRANSFER.md](SESSION_TRANSFER.md)。未识别的单个斜杠命令同样保留草稿并提示；以 `/srv/path` 等绝对路径开头的普通正文不属于该命令模式。

普通命令在收到接受确认后清除仍匹配的文字和附件，期间新输入的内容保留；本地操作失败、明确拒绝、发送超时/断线均保留尚未确认的原稿。压缩以原生开始事件为接受证据，不等摘要结束才清空。模型执行或扩展处理失败不等于命令未被接受：原生错误继续显示，已接受的命令不自动重放。

## 模板管理

模板编辑读取、删除、资源重载和保存会在触发按钮上显示加载图标与动作提示，等待期间阻止同一按钮重复提交。保存时暂时锁定名称、位置和正文；失败后恢复编辑并保留内容。

Prompt Templates 是 Pi 原生的、按需调用的任务提示词。AGENTS.md 提供项目约定，README 主要说明项目；模板用于节省反复输入一次性任务的文字，不自动加入每轮对话，也不替代项目规则。网页管理界面由本项目提供，完全可以不配置模板。

- 全局目录：`getAgentDir()/prompts/*.md`；默认 `~/.pi/agent/prompts/`。
- 项目目录：当前规范 cwd 下 `.pi/prompts/*.md`。创建文件不写 trust，也不会自动批准项目。项目未被 Pi 信任时，模板可以管理但不会被描述为已加载。
- 使用原生 Markdown、frontmatter、`$1`/`$2`、`$@`、`${1:-默认值}` 等语法。编辑器保留完整 Markdown 和未知 frontmatter，参数由 Pi 展开，Web 不复制展开实现。
- 命令名为 1–80 个 ASCII 字母/数字/短横线/下划线，首字符必须为字母或数字，不能与 Web/内置命令重名。其他已有文件名仍可通过 Pi 原生目录使用，管理列表提示跳过。
- 单文件最大 64 KiB，必须是普通 UTF-8 文件；目录和文件符号链接不能通过管理接口读写。每个范围最多展示 500 项并提示截断。
- 保存/删除携带内容 SHA-256 修订；创建明确传 null。修订变化返回 409，保留编辑表单，不自动覆盖。
- 保存使用同目录 0600 临时文件和 rename。覆盖/删除前在 `prompts/.web-backups/` 保留 0600 旧版本；原生非递归发现不会加载备份。没有自动清理用户备份。
- 常用任务示例只填入编辑器，不自动创建私人模板。
- 管理列表显示当前实际加载状态，不提供调用参数对话框；参数直接写在聊天输入框命令后。Packages/显式配置的其他模板仍可通过 `/` 联想使用，管理接口不修改任意路径。
- 原生位置参数含空格时用引号，例如 `/explain-file "src/button click.js"`。原生 RPC 不返回 argument-hint，受管模板从目录 metadata 补齐后显示于联想项；参数展开与默认值继续由 Pi 处理。
- 模板窗口关闭后焦点回到设置入口；Esc 只关闭最上层原生窗口，不连带关闭设置。项目或会话改变后，迟到编辑结果不覆盖新窗口。

## 原生重载

`reload_resources` 仅允许已认证的主连接。Supervisor 在 await 前预占 session operation，确认原生 streaming/compacting/queue 与待确认请求均为空；已有侧聊快照读取尚未结束时同样拒绝。侧连接不能调用此命令。

通过已加载的本项目内部扩展命令传私有 token 调公开 `ctx.reload()`，不修改 Pi 包，不重开第二个持久 worker。重新加载扩展实例拥有新的描述标识；gateway 在私有 get_commands 中验证实例确已替换后广播去除内部命令的 `gateway_commands`。不会在 await reload 后调用旧 ctx/pi。旧实例不支持此协议时明确拒绝。

重载可重新加载已配置扩展、Skill、模板、主题及项目指令，不自动发送用户任务。保存模板不会触发重载。超时后不会重试，会销毁仍可能操作资源的对应 worker 并要求重连，不把超时当成取消成功。当前 session JSONL、工作目录及其他会话保留；侧聊原背景继续冻结。

## 项目文件

`@query` 在光标处补全，普通 email 中的 @ 不触发。选中项插入 `@./relative/path`，含空格的路径加引号；不读取文件正文、不上传服务器原件、不生成附件副本。Pi 后续按任务通过自己的工具读取文件。手机/电脑的文件上传从加号的“添加附件”进入，保留既有附件校验。

服务器通过 store.resolveProject 做 realpath/PI_PROJECT_ROOTS 检查，以无 shell 的 `rg --files --hidden --null` 搜索当前 cwd；尊重 Git 忽略规则，排除常见依赖、Git、备份、本项目生成媒体目录，以及 .env、auth.json、models-store.json 和常见私钥文件名。结果再次检查真实路径仍在当前项目内。此过滤不是凭据检测器或工具沙箱。

最多两项搜索，单次 1.8 秒、8 MiB 输出、100000 个候选，返回最多 50 个路径；超限明确返回 truncated。只返回路径，不返回文件内容。ripgrep 不可用时明确报错，不回落到 shell 拼接。查询最大 200 字符，客户端 debounce 并检查输入、光标、线程与请求代次，迟到文件结果丢弃。

## 接口

所有 REST 复用 `/api/pi` 的 token/Origin 中间件，响应 no-store。

| 方法 | 路径 | 输入与结果 |
|---|---|---|
| GET | `/composer/catalog?cwd=...` | `{cwd,builtins,templates,warnings}`，不启动 runtime |
| GET | `/composer/template?cwd=...&scope=user\|project&name=...` | `{name,scope,content,revision}` |
| PUT | `/composer/template` | `{cwd,scope,name,content,expectedRevision}`；返回 ok/requiresReload/revision |
| DELETE | `/composer/template` | `{cwd,scope,name,expectedRevision}`；旧版本先备份 |
| GET | `/composer/files?cwd=...&q=...` | `{cwd,files:[{path}],truncated}` |

主 WS `reload_resources` 无额外 payload；成功 data 为 `{commands:[...]}`，向同一 worker 所有订阅者广播 `{type:'gateway_commands',commands:[...]}`。不扩展裸 RPC 白名单，不向侧聊开放新权限。
