# Pivane 用户指南

简体中文 · [English](en/USER_GUIDE.md)

Pivane运行在你部署它的电脑或服务器上。浏览器可以在另一台设备上打开；项目目录、Shell和Agent工具使用的是服务器文件系统。

## 首次开始

1. 按[安装指南](INSTALL_RECOVERY.md)启动独立实例，打开启动日志中的网址。
2. 进入“设置 → 供应商与模型”，先核对复用的 Pi 配置；没有可用认证时再选择服务并完成API Key或OAuth登录。不要把Key发到聊天中。远程OAuth的localhost回调指服务器，按提供的设备码/手动回调步骤处理。
3. 返回 Pi Agent 后选择服务器项目目录，点击“新聊天”，选模型与思考等级。已打开线程会在空闲时刷新模型目录；没有可用模型时使用页面上的设置引导。
4. 发送一个简单问题；刷新页面，核对持久线程和回复仍可打开。这个请求会使用你自己的供应商账户。

原来的 Pi CLI 有模型而网页没有时，先核对实际身份目录和启动环境，见[已有 Pi 接入](PI_CLI.md)。普通安装默认复用原生身份，只有明确要求隔离时才建立另一套配置；已有空身份的切换不会自动合并会话。

没有选择项目时，可以先管理全局Pi配置、Packages和Skills。`@`插入服务器项目文件路径；附件按钮、粘贴和拖放则读取浏览器提供的真实文件，两者用途不同。

## 工作区导航

左侧导航在桌面按“工作”（Pi Agent、助手对话、定时任务、多媒体实验室）和“管理”（助手身份、扩展）分组，底部是工作台设置。手机底栏保留 Pi Agent、助手对话、主题和设置，定时任务、媒体实验室、助手身份与扩展收在“更多功能”中。助手身份与扩展是独立的管理页，不再重复列在设置分类里；设置导航底部的“管理”区保留跳转入口。Pi Agent 按真实目录列出原生线程；助手对话按档案、逻辑项目和线程浏览，不会复制历史或另外启动第二套聊天。身份、扩展和设置使用完整页面；浏览器地址可返回，页面右上角的返回按钮回到此前对话。进入管理页不会断开当前会话；在 Pi Agent 与助手对话之间切换时右侧会清空，需从相应项目重新打开线程，未发送文字和已读取附件按原线程暂存，不删除或停止原生会话。完整刷新页面不保留未发送草稿。

左侧顶部的彩色 π 是 Pivane 品牌标识。新浏览器默认使用带短标签的 72px 紧凑导航，点击品牌下方的侧栏按钮展开；已有浏览器明确保存的展开／折叠选择继续有效。项目线程栏默认 272px，右侧面板默认 336px，可拖动分隔线或用方向键调整，双击恢复默认。

项目线程栏的“项目”按目录浏览，“动态”集中显示需处理、处理中、状态待更新和最近会话。列表内搜索匹配项目与线程标题／首条问题，不是正文全文搜索；底部“搜正文”使用独立的跨线程搜索。Ctrl/Cmd+K 可聚焦列表搜索。浅色描边的“新聊天”按钮在当前项目创建线程，项目菜单的创建项也叫“新聊天”；临时会话在项目菜单内。底部“搜正文”保持单行显示。正文搜索关闭后再次打开，会在当前页面内保留关键词、结果页和滚动位置；打开结果后可再次点击“搜正文”继续浏览。项目范围显示实际搜索目录，不因打开其他项目的结果而悄悄改变；身份变化或访问锁定会清除保留结果，刷新页面不保留。修改关键词／范围、重新提交搜索仍读取服务器结果，打开旧结果时会重新核对线程是否存在。底部“定位当前线程”清除列表搜索、展开当前线程所在区域并移动焦点，不更改归档／隐藏状态，也不重新连接会话；退出列表搜索会尽量回到搜索前的阅读位置。列表刷新按可见线程保持位置，动态视图保留现有分组和排序规则。助手对话的长列表也先显示前 6 个线程，并额外保留当前线程，使用“显示其余”展开；搜索结果不截断。

右侧工具栏依次提供详情、文件、历史和侧聊，不再提供“任务”工具；手机从顶栏“当前线程工具”打开。面板顶部的选择器可切换工具，关闭后不会结束主任务或侧聊。桌面（浏览器宽度大于 900px）四种面板统一与主聊天并排，两边可同时操作，右栏可拖拽调整；窗口缩小时自动收窄显示宽度，保留已保存的偏好。窄桌面打开面板时暂藏项目／线程列表，关闭后恢复。“文件 → 展开阅读”会扩大右侧阅读区并暂藏项目／线程列表，主聊天仍可操作；收起后恢复普通面板宽度。900px 及以下使用覆盖抽屉，支持 Esc、遮罩和关闭按钮，关闭后恢复焦点。有效线程仍直接恢复；空线程首屏居中显示标识、“今天想推进什么？”、说明和项目标签，提供“熟悉项目”“排查问题”“规划想法”“撰写文档”四张起步卡，下方 Skills 探索使用胶囊入口。起步卡只追加到现有草稿，保留附件、选中括号占位内容供填写，不自动发送；手机卡片仅显示图标与标题。

窄屏平板自动使用图标栏，悬停可查看入口名称；手机底栏的“更多功能”展开定时任务、多媒体实验室、助手身份和扩展。项目与线程抽屉打开时，工作台导航仍可操作；点击 Pi Agent、助手对话、更多功能、主题或设置会先收起抽屉，再切换页面或展开菜单。浏览器返回可回到先前位置；身份与扩展页另有页面返回按钮。手机助手对话的项目和线程仍在抽屉中，抽屉底部的正文搜索、当前线程定位与刷新并排靠右；正文搜索不可用时隐藏对应入口。设置始终进入工作台设置，不会因刚访问过助手身份而打开身份页。旧的设置地址带有身份或扩展分类时，会转到对应的管理页。这两种布局不显示桌面的折叠按钮。

会话区左下角的状态标签汇总当前主会话、本页该线程的侧聊，以及服务器报告的子 Agent／后台保留工作。主会话结束一轮后，关联工作仍在进行就不会显示“空闲”；等待确认、停止／取回、历史切换、资源重载、Shell、重试、压缩、模型刷新、待发消息及子 Agent 需处理状态也会显示。悬停标签可查看同时存在的状态与模型。断线显示“连接已断开／状态待更新”，不推断服务器任务已停止；切换线程不会混入其他线程保留的侧聊状态。这是展示汇总，不改变主会话的发送／停止权限，也不代表所有独立任务线程、其他浏览器侧聊或全局媒体任务的总状态；未完成的计划步骤本身不算正在运行。

## 定时任务

从“定时任务”安排周期执行或一次性工作，目标可以是指定线程，也可以是身份按需创建／指定的主线程。支持文字问候、线程内工作、时区预览、错过跳过、忙时等待、运行记录与预算。线程菜单可直接创建绑定任务。启用才会自动执行，暂停和停止本次运行分别操作；不确定结果先核对，不自动重发。完整说明见[定时任务与主线程](SCHEDULED_TASKS.md)。

## 找不到其他项目目录

项目选择器只能浏览实例 `PI_PROJECT_ROOTS` 允许的服务器目录。它并不要求项目放在 Documents；当前网页没有修改这个范围的入口。若安装时被限制在 Documents 或 demo 所在目录，需要修改服务器启动配置，空闲重启后生效。个人 macOS 实例可使用 `PI_PROJECT_ROOTS=/` 选择系统用户有权限访问的目录，也可指定主目录或多个目录；macOS 隐私控制仍然有效。

具体配置位置、环境变量优先级和重启步骤见[目录范围排障](INSTALL_RECOVERY.md#项目选择器找不到目录)。不用搬动项目或迁移会话来解决范围限制。

## 可选助手身份

在支持助手档案与逻辑项目的版本中，**助手身份** 页面可创建身份，保存行为说明（SOUL）及独立记忆／技能设置。进入 **助手对话** 后，先在项目栏顶部选择已启用档案，再浏览该档案关联的项目与线程；没有可用档案时可从页面进入手动创建或由 Agent 辅助起草。新建项目的目录浏览器列出运行 Pivane 的服务器上允许访问的文件夹，也可手输完整服务器路径；浏览器无法选择访问网页设备上的本地文件夹。项目可附加自己的指令，同一个服务器目录可对应多个逻辑项目，但目录文件与 AGENTS.md 仍然共享。项目指令只在该组会话中追加，不修改共享 AGENTS.md；记忆仍按档案与真实目录归属，不按项目别名隔离。档案不构成安全沙箱。

Pi Agent 中新建的线程明确不绑定档案，不再沿用项目默认档案；已有绑定线程仍显示保存的档案，旧绑定但没有逻辑项目标记的线程列于真实目录下的“未分类”。助手对话新建线程使用顶部所选档案和当前项目；打开已有线程不会改变它实际保存的档案。逻辑项目可在编辑页归档，归档记录仍在项目栏的已归档分组里，可重新编辑恢复。标题和输入区显示当前线程的真实档案头像与名称，不将筛选所选档案冒充运行中的身份。保存新设置不会打断任务；运行中实际加载的配置须另外核对。临时会话在各项目的“…”菜单里启动，不绑定档案、不持久保存或学习。

不使用身份时，原有项目指令、工具和已配置 Skills 继续工作。身份的保存配置与运行中会话实际加载的配置分别核对；保存不会打断任务。记忆能力需要单独安装适配组件，管理页显示数据读取、索引同步、回执与当前会话重载状态，不把文件已安装当成会话已加载。身份的“学习与技能”中可对允许写入的身份记忆和已学习技能逐项编辑、版本对照、删除/恢复/撤销；项目范围未验证时只读，已安装技能继续在扩展页管理。从聊天提示的“编辑”或纠错卡的“本项目记忆”进入管理页时会带上当前会话，项目记忆按当前会话目录核实后才可编辑、删除或撤销，写入由服务端按会话目录取项目标识，网页不提交客户端项目标识；没有会话入口时项目记忆保持只读。当前身份线程上方的纠错卡可手动保存纠错并查看核实属于此线程的回执；手动纠错不会取得原生消息来源。学习开关、次数/token 预算和复盘周期分开保存，必须配置对应专用模型才可能运行；保存设置不会发模型请求。模型实际是否遵守记忆无法由保存或读取证明。详细限制和源码候选的验证状态见[助手档案](AGENT_PROFILES.md)与[记忆适配](PROFILE_MEMORY.md)。界面入口统一叫“助手身份”，后台接口和档案文件仍是 profile。

### 记忆学习的提示与反馈

后台学习或 Agent 写入记忆后，对应消息下方会出现一张本轮记忆卡片，每条一行：“已记住”（学习写入）、“Agent 记下”（工具写入）或“学会技能”（技能需重载会话后生效），旁注类别标签；正文默认显示两行，点击可展开全文。提示只在界面渲染，不写入会话记录，刷新页面后按服务回执重新显示；找不到对应消息（例如上下文已压缩或不在当前分支）时改在纠错卡里显示。技能提示旁的“重载会话”按钮只在当前聊天就是来源会话时出现，会话忙时禁用，点击后重新加载原生资源使技能生效。提示带三个按钮：“撤销”撤回该条记录，“不对”删除这条记忆（服务端留下防复活记录，学习不会再学回来；技能则直接撤销），“编辑”跳到身份页的“学习与技能”并定位到该条目。项目范围的提示只保留“编辑”（带会话进入管理页），不可撤销的记录不显示这些按钮；所有按钮都按服务器版本核对，版本冲突时会刷新并提示，不会静默覆盖。纠错卡默认收起，摘要显示“本会话已记住 N 条”和后台学习的处理状态。

聊天卡片与身份列表按学习状态显示状态点：绿色为正常，灰色为关闭，黄色/红色附一句原因（缺模型、今日额度用完、连续失败或不可用）。身份页学习区提供“一键开启自学习”：开启后若还缺专用模型（纠错模型/复盘模型/提炼模型），会列出缺什么并给出跳转“设置 → 使用偏好 → 辅助模型”的链接；不会自动改用主聊天模型。此前开过旧版自动学习的身份在学习区顶部显示迁移横幅，列出将要设置的用途和旧模型；旧模型不可用时可从辅助模型目录另选，确认“迁移并开启”后才继续学习，也可“不再提示”；部署不会自动开启任何学习。

记忆管理页顶部分别显示 MEMORY 和 USER 用量条（已用字符 / 上限）。达到 80% 变黄并提示“接近上限，下一步可整理合并”，同时提供“整理合并”按钮提交整理方案；达到 100% 或写入被拒时变红并提示“已满，新记忆会被拒绝”。方案在学习区按组展示：左边列出原条目预览和类别，右边可编辑合并后的正文和类别，逐组“应用”（一次发布合并结果并生成可撤销回执）或“忽略”；条目版本已变化或已消失的组标为“已过期”，不能应用。方案只生成不自动写入；应用后可从回执“撤销”，一次恢复全部原条目，被合并的正文不会被学习重新写回。学习运行记录中因记忆满而未保存的条目显示“记忆已满，未保存”。

学习区的“下一轮注入预览”显示身份记忆的条目数和字数，可展开只读原文；纠错卡的“查看本会话注入内容”按当前会话显示身份记忆、项目记忆和上一轮已注入的条数与字数，可展开只读原文，再点一次（或右上角关闭）收起；记忆未启用或正在同步时会直接说明原因。注入只是供模型阅读的材料，不代表模型一定遵守。身份列表和学习区在存在草稿技能时显示“N 个草稿技能待审”，点击跳到“已学习技能”并筛选出草稿，逐项审核后启用。

学习设置里可以修改每天的运行次数和 token 额度、复盘间隔和整理合并单次读取的字数。在对话里纠正助手（“不对，应该是…”“No, use … instead”）或说明长期偏好（“以后都…”“From now on …”）会被优先学习；标明“只这一次”“Just this once”的要求不会被记住。内置规则识别中文和英文，“自定义触发词”可以补充自己的习惯说法或其他语言，也可以填排除词。

记忆和技能不会保存疑似 API Key、Token、私钥、密码或“忽略之前的指令”一类内容：手动保存会提示原因，后台学习遇到这类内容会跳过。需要助手使用的凭据请放在 `.env` 或密钥管理工具里。

## 自定义系统提示词

打开 **设置 → 系统提示词**，按页面的三步操作：

1. **选范围**：所有项目使用通用偏好；当前项目卡片显示项目名称，用于设置专属要求。
2. **直接写要求**：例如“先给结论，再解释原因”。也可以点“简洁回答”等示例，追加到草稿后再修改；示例不会自动保存或发送。阅读预览和修改差异帮助你检查内容，点击 **保存要求** 完成保存。
3. **更新当前对话**：保存不会打断任务，也不会自动更新已打开的对话。对话空闲时点此按钮，重新加载该对话的全部原生资源并核对提示词；其他对话需分别更新。未连接或忙碌时页面会说明原因。

当前项目没有专属要求时，编辑框直接显示所有项目的已保存要求，可直接修改。项目保存后**替代**通用要求，不会自动叠加；项目提示词仍受项目信任控制。恢复默认或沿用所有项目的要求会先形成草稿，点击“保存恢复操作”后才移除本范围文件；原文有私有备份。“撤销本次修改”可回到已读取的保存内容。

点页面顶部 **查看当前对话**，或 **会话详情 → 查看系统提示词**，默认直接阅读完整提示词，支持搜索、复制，并可跳到“修改我的要求”。“组成与来源”提供基础提示、个人要求、上下文文件与 Skills；合成正文只读。文件位置、范围说明和替换基础提示词收在折叠区域，通常不需要修改高级设置。

草稿在当前页面内按项目/范围保留，关闭设置或切换分类后可以继续编辑；刷新页面前请保存，刷新网页不保证更新运行实例。遇到冲突或保存结果不确定，先“刷新并核对草稿”，检查最新磁盘内容与草稿差异后才能再次保存。详细范围、原生文件位置及限制见[Pi 原生配置](NATIVE_SETTINGS.md#系统提示词查看与编辑)。

## 网络与访问

设置中的“访问控制”现为 **网络与访问**：访问安全保留 Token 管理；访问范围选择本机或其他设备；出站代理选择运行环境、直连或自定义 HTTP/HTTPS 地址；远程访问提供 Tailscale、HTTPS 反向代理与本机隧道指引。详细参数按需展开，模型页与版本页提供代理跳转。

监听和代理分别保存，页面会显示等待重启，**不会自动重启、开放防火墙或中断任务**。代理地址的 localhost 指服务器。先启用登录验证，再修改网络或测试代理；其他设备候选地址不代表已连通。由 HOST 管理的部署需在服务器修改配置。当前或待生效监听仍非本机时不能关闭验证；同机反向代理/隧道仍可配合仅本机监听。详见[网络与访问](ACCESS_CONTROL.md)。

## 外观与字体大小

在“设置 → 使用偏好 → 外观”中选择主题和字号；左侧或手机底部的“主题”菜单也可以快速切换配色。保留原有的晴空、薄荷、夜间与跟随系统，并新增雾蓝、丁香两种浅色皮肤。跟随系统会随浏览器明暗偏好切换；其他皮肤不会自动切换。字号提供小（15px）、默认（16px）、大（18px）、超大（20px）四档，主要通过相对字号放大工作台文字；固定像素的代码、图标和部分输入控件不随之变化。手机输入框始终不小于 16px，避免聚焦时自动缩放。

选择后即时生效并保存在当前浏览器的此站点，其他设备可独立设置；不改变模型回复、会话数据或 Pi 原生主题资源。浏览器自身缩放仍可照常使用。

## 界面语言

Pivane 支持简体中文和英文。首次按浏览器偏好列表中首个受支持语言显示，中文变体使用简体中文，英文变体使用英文，没有匹配时回退英文。可在“设置 → 使用偏好 → 界面语言”选择“跟随浏览器 / 简体中文 / English”。选择只保存在当前浏览器的此站点，其他设备可独立设置。

保存后下次打开或刷新页面生效，页面不会自动刷新。刷新前请保留未发送草稿和附件；临时会话与侧聊会结束。界面语言不翻译聊天、文件、已保存模板或用户模型名称，也不修改模型请求和朗读语言。内置模板示例按页面语言提供，已保存的模板保持原文。

部分高级文档、上游与第三方诊断、后台推送文字仍保留原文；旧媒体界面暂未翻译。详见[界面语言说明](I18N.md)。

## 模型与能力

桌面在输入区点击模型名称，优先显示加星的常用模型、当前模型和最近使用。搜索名称、模型 ID 或供应商可直接查找完整目录；“查看全部模型”按供应商浏览。星标只整理常用列表，点击模型行才切换；常用模型由同一 Pivane 实例的设备共享，最近使用保存在当前浏览器；旧收藏会在原设备加载新版后自动合并。

手机顶部的文件夹/项目名称可直接打开项目选择器并添加目录，下方状态条显示线程标题或连接状态；桌面（宽度大于 900px）隐藏独立顶栏，将同一项目按钮和上下文指示器移到对话状态行，与线程标题、连接状态同排，平板和手机移回顶栏。项目路径可在按钮提示中查看。桌面模型与思考控件仍在输入区。手机输入区上方是整宽文本框，下方排列添加、上下文圆环、麦克风和发送／停止按钮；长草稿自动增高，达到高度上限后在文本框内滚动。模型、思考和上下文百分比摘要仅在文本框聚焦或任务运行时显示于输入区顶部。点击圆环打开底部设置面板，再点模型进入可搜索列表；思考等级来自当前模型的实际能力，关闭模型选择器后焦点返回圆环。压缩后等待统计时显示 `--`，不按 0% 估计。运行时主操作根据草稿切换：没有文字、引用或附件时显示停止，有内容时显示发送；空白文字不算内容。引导／后续的投递方式从加号菜单调整，发送按钮提示所选方式。手机长错误或 JSON 自动断行，聊天正文不横向平移；会话抽屉关闭后不在聊天边缘留下阴影。上下文压缩位于右侧“详情”，文件和历史有独立工具入口；消息显示（简洁/正文/完整记录）在设置的“使用偏好”中，新浏览器默认简洁，已有浏览器仍保留之前的选择。切换模型和思考需要会话空闲，手机模型列表打开时不自动聚焦搜索框。详见[模型选择说明](PROVIDER_SETTINGS.md#会话顶部快速选择模型)。

有可用的转录模型时，点击输入框下方的麦克风立即录音，再点结束并转录，文字会追加成可编辑草稿，由你发送。未配置时，提示右侧的“去配置”可直接打开设置 → **模型与能力 → 语音**；它直接打开语音弹窗的“语音转录（ASR）”页签，支持手动填写转录模型 ID、服务地址和凭据，或复用已有语音服务。默认模型只记在当前浏览器，配置保存后无需再打开录音面板。录音最多两分钟，麦克风需要 HTTPS 或 localhost 与浏览器许可。录音会上传到所选服务并使用其额度，失败不自动重试。详情与草稿保护见[语音转录](COMPOSER_TOOLS.md#语音转录)。

设置各子页面顶部统一显示分类图标、主标题和说明。供应商与模型、Pi 配置、系统提示词、访问控制、Packages 和 Skills 的刷新入口位于标题右侧；手机上会换到下方靠右显示。用量统计的刷新仍位于日期筛选区。

设置 → **模型与能力** 合并多模态服务和子 Agent 设置。“多模态”分区的图像、视频和语音均使用配置弹窗，各入口只展示对应类别的服务、模型和协议模板，数量不包含其他类别。点击模型名称可直接编辑；添加模型时选择已有服务复用地址和 Key，或新建服务后继续配置。设置页保存留在模型列表并显示结果，不改变实验室模型或草稿；共享服务的地址和凭据修改会影响它在所有类别中的模型。语音默认打开“语音合成（TTS）”，可直接新增、编辑 TTS 模型；“朗读默认配置”用于选择模型、音色和参数，另一个“语音转录（ASR）”页签管理录音转文字。生成仍需在实验室确认。

`node scripts/install.cjs` 准备随 Pivane 提供的 pi-subagents 0.74.0。版本随应用更新，子 Agent 设置页显示“Pivane 内置”；无需另行安装。已有 CLI 包声明和角色配置保留，Pivane 使用内置版本并沿用资源过滤。可在扩展页启用／停用资源，内置包不提供独立更新或移除。保存后在任务完成时重开运行实例，实际加载情况可在会话详情核对。安装和兼容说明见[内置能力包](BUNDLED_CAPABILITIES.md)。

子 Agent 支持所有项目/当前项目的默认模型、思考等级和角色覆盖，模型来自实际可用目录。中文界面为随附角色显示中文名称及用途，点击角色卡片可展开配置并查看原始英文标识；显示名称不会改变角色身份。点击模型按钮打开选择面板，可搜索名称、完整 ID 或供应商，并按供应商筛选；每批显示 40 个结果，可继续加载，选择后仍需保存。已保存但暂不可用的模型保留原值，不自动替换。

角色列表包含插件随附的原生角色及已有覆盖，不是完整运行时角色清单。“配置说明与插件信息”中可按已有自定义角色名称添加覆盖，这不会创建角色定义。选择“自动选择”并保存会删除本层字段、恢复继承；角色自身定义、供应商覆盖或单次运行参数可能优先于默认值。页面提示未保存项数，“撤销修改”只清除当前范围的未保存草稿。项目设置需要信任，保存不启动子任务、不改变正在运行的任务；任务结束后重开运行实例应用配置。

#支持 Fast/Ultrafast 的渠道模型会在桌面输入区显示“速度”，手机模型面板增加速度选项；普通模型隐藏该入口。速度与思考独立，选项显示费用倍率；设置 → 供应商与模型 → 模型“速度”可保存默认值或配置自定义渠道。当前选择随原生会话恢复，已有旧会话保持原方式。具体能力、继承与费用规则见[模型速度](PROVIDER_SETTINGS.md#模型速度fast--ultrafast)。

## 使用子 Agent

主 Agent 调用子 Agent 时，执行记录显示中文标题，例如“后台启动子 Agent · 代码审查”“启用子 Agent 工具”“回复子 Agent 请示”；展开后仍可看到原始工具名和参数。pi-subagents 0.74 根据模型是否支持动态工具选择加载方式：支持时先调用“启用子 Agent 工具”，其他模型在新会话开始时直接提供完整工具，避免启用时破坏提示缓存。已打开会话保持原工具选择，完成任务后重开运行实例使用新版本。子 Agent 发给主 Agent 的结果、进展、请示和状态提醒默认收起为一行，只显示类型、首行摘要和来源；需要主 Agent 回复的请示和监督提醒用琥珀色边框标出。点击该行展开完整内容，长内容在卡片内滚动。

后台子 Agent 运行时，输入框上方显示“子 Agent”小标签，显示运行数，会话保持时带绿色标记。它默认收起，与“当前进度”标签共占一行；点击后详情在输入框上方浮出，不占聊天区高度，同一时间只展开一个，点击其他位置或按 Esc 收起。手机窄屏同时显示两个标签时，隐藏当前步骤预览；更窄时只保留图标和计数。需要处理的运行优先显示，运行中与需处理数量可同时出现。计划、子 Agent 和任务结果标签仅保留在输入框上方，不移入右侧面板。详情中：

- 列出每个运行及其状态、耗时、当前工具、轮次和子步骤。
- **查看模型**：列出该运行各步骤使用的模型和思考等级；pi-subagents 未报告模型时显示“默认模型”。
- **引导**：向运行中的子 Agent 发送说明，可选择尽快送达或在当前任务完成后处理。
- **停止**：确认后请求停止；已完成的步骤保留。
- **继续**：对已暂停、停止、失败或已完成的运行追加说明后继续；沿用原运行的模型与权限。
- **用量与费用**：汇总本会话分支中主 Agent 和各子 Agent 报告的 token 用量与估算费用（需要 0.71.0 及以上）。

操作由 pi-subagents 核对运行归属与状态；未在时限内确认的引导、停止或继续显示为“结果不确定”，Pivane 不会自动重试。

后台子 Agent 未结束时，面板显示“会话保持中”：即使关闭页面，Pivane 也不会因空闲回收这个会话，以便子 Agent 完成后主 Agent 自动接着处理；维护、升级和重启也会等待这些工作结束。结果送达后自动恢复正常回收。若需要立即维护，可先在面板中停止相应运行。

## 扩展、精选与已安装资源

电脑左侧导航点击 **扩展**；手机从底栏 **更多功能 → 扩展** 进入。空白会话提供“探索技能”，可直接查看发现页；手机底栏不单列扩展按钮。发现、已安装包与技能使用同一个完整内容页面，返回按钮可回到原会话；页顶子导航和“安装扩展包”按钮始终可见。

扩展界面分为 **发现**、**已安装** 与 **MCP** 三页。发现页支持按名称、用途和作者搜索，收录 [PPT Master](https://github.com/hugohe3/ppt-master)、[Pi 原生 MCP](MCP.md)、[pi-web-access](https://pi.dev/packages/pi-web-access)、[pi-computer-use](https://github.com/injaneity/pi-computer-use)、[pi-subagents](https://pi.dev/packages/pi-subagents) 和 [pi-hermes-memory](https://pi.dev/packages/pi-hermes-memory?name=memory)。卡片展示来源、用途与使用前提。Pi MCP 随应用锁定的 Pi 提供，无需安装适配器；在“扩展 → MCP”管理全局或受信项目配置，现有私密字段只显示是否存在，默认保留，明确替换／移除；保存不连接、不求值也不重载。已有项目部分覆盖仅编辑状态和工具暴露，连接／凭据继续继承全局；不提供新增专门页面。先打开持久线程，才能显式读取原生状态、重连或 OAuth 登录／退出；授权链接与重定向输入在聊天继续。工具通过 Codemode 或按需搜索接入；“设置 → Pi 配置 → 工具”可设置名称与 +/-、呈现模式和声明预算。旧配置迁移须停机备份，不能直接照搬旧工具缓存或凭据文件。PPT Master 的状态会按所选全局／项目范围核对 Pi 已发现技能的名称与来源声明，显示已发现、已停用或未发现；未受信项目或旧服务无法完整核对时显示需助手核对。此状态不保证依赖或当前会话已加载。PPT Master 需要 Python 和项目依赖；电脑操作需要部署端图形会话与系统权限，并不直接控制访问网页的手机或电脑。记忆扩展会在部署端保存记忆与索引，配置前需核对记录范围、自动学习和原生依赖。

发现页卡片直接显示安装状态：**已安装**（带范围）、**未安装**、**已配置 · 文件未就绪**，或无法确认时的 **需助手核对／状态待核对**。默认读取所有项目范围，可切换到当前项目（含全局），点击“刷新安装状态”重新核对。状态按原生清单中的登记来源匹配，不凭技能名称猜测手动复制的内容；未信任项目无法确认的项目项不会标为未安装。读取失败会清除旧状态，显示待核对。已安装不代表当前会话已经加载或通过任务验证。独立的档案记忆组件安装通过核对时，pi-hermes-memory 卡片显示“档案适配已安装”，其范围由助手身份管理，不表示上游默认扩展已全局启用。

点击 **了解与配置** 将准确来源和核对要求带入扩展助手；**添加自定义** 可填写其他需求或链接。打开发现页、搜索或点击卡片都不会安装，也不会自动发送模型请求。用户在助手中确认范围、进入会话并发送需求后，才开始检查与配置。已安装清单继续来自原生资源接口，安装完成后需在会话空闲时重新加载并核对。

执行记录会将技能文件读取、扩展清单检查和包操作显示为易读名称；有调用时来源信息的扩展工具会带“来自…”标记。展开可核对原始工具名、来源、参数和结果。旧记录缺少来源时不会按当前安装状态补填；读过技能文件不等于模型已遵循它。正文视图仍折叠工具记录，可展开或切换完整视图查看。

需要助手帮助时，点击输入框加号 → **添加能力…**，或扩展的已安装页面 → **让助手帮我配置**。选择安装范围，说明需求或粘贴来源链接，点击底部“进入助手”即可创建独立的扩展助手会话；安装位置与项目路径可按需展开。需求先放入输入框，由你发送，不会自动开始安装。“检查更新”气泡会填入检查全部已安装 Packages/Skills 更新的需求：先核对清单、来源、范围和版本，再列出更新、兼容性与方案；无法确认的版本明确标注，等你确认后才更新。“办公文档”示例检查 Word/PDF 能力、来源、配置与兼容性后给出方案；不再提供“制作 PPT”气泡，可从精选进入 PPT Master。包/技能卡片的问号提供“了解这个包 / 技能”和“排查问题”：前者请助手先只读说明用途、适用场景、使用示例和依赖，后者先诊断并提出方案。两项都会带入准确来源与范围，需求仍由你确认发送。

助手可检查已有资源，查找并核对来源与许可，给出方案后安装、配置和验证。安装位置是运行 Pivane 的机器；包操作通过网页确认。独立技能和依赖配置使用当前启用的 Agent 工具，不保证任意项目都能自动适配。“返回原会话”保留当前页面里的原草稿与附件；安装不会自动重载其他会话，使用前按提示在空闲时重新加载资源。详细范围见[扩展助手](NATIVE_SETTINGS.md#扩展助手)。

“扩展 → 已安装”先选择所有项目或当前项目，再用类型按钮（全部／Packages／技能／扩展模块／提示词模板／终端主题）聚焦。“全部”按类型分节，每节有一句用途说明：技能是任务匹配时 Agent 自动读取的说明与脚本；扩展模块为 Agent 增加工具或命令并会执行代码；提示词模板在输入框用 /模板名 插入；终端主题只影响 Pi 终端界面，不改变网页外观。列表按统一的行结构展示名称、范围、状态和来源，“启用”为实心按钮、“停用”为描边按钮；更新与移除收在行尾的“⋯”菜单中，移除仍需确认。扩展页顶部的 **安装扩展包** 打开统一安装窗口：选择范围、填写 npm、Git 或部署机器上的本地路径，并确认来源；未信任的项目范围不能写入。

“已安装”页把 Packages、扩展、Skills、提示词和主题放在同一列表。资源优先使用已读取的技能名称；没有元数据时用文件或目录名区分。列表可搜索，默认每批显示 40 项；展开“查看来源”核对完整路径，行内“启用/停用”立即保存，项目继承的“恢复继承”在“⋯”菜单中。切换类型过滤只改变显示，不重新读取或保存。启用 Skill 时会再次提示指令会影响 Agent 行为；“其他选项”保留 `/skill` 命令显示和提示词模板管理。未信任项目不允许项目写入。读取失败可点击刷新重新核对，不自动重试操作；配置保存后在会话空闲时重新加载资源。详见[Pi 原生配置](NATIVE_SETTINGS.md)。

手机上的“使用偏好”支持纵向触摸滚动，语言、自动标题、模块 Agent 和通知控件按可用宽度换行；页面的浏览器缩放入口保留。

## 版本与更新

“设置 → 版本与更新”用两张卡片显示当前 Pivane / Pi 版本和可用的最新版本。首次打开且没有缓存时自动查询一次，也可点击“检查更新”：服务器查询 GitHub Releases（包含预发布版）与 npm，结果缓存 5 分钟，不会安装。Pi 默认在页面可见时最多每 24 小时自动检查一次；发现新版后可从提醒进入版本页、延后或忽略该版。自动检查也不会安装。

网页不再提供应用安装、Pi 安装、仅备份、重启、下载包和校验文件入口。需要升级时展开“交给独立 Agent 协助更新”，复制提示词交给部署机器上的**独立 Agent**；它应先核对实例、目标版本、兼容性和备份/回退方案，等你确认后再执行。不要让运行在待更新 Pivane 中的 Agent 停止或重启承载当前会话的服务。官方发布页面仍可从卡片打开；安装与恢复资料见[安装与恢复](INSTALL_RECOVERY.md)及[版本查询契约](UPDATES.md)。

## 对话与工具

主聊天、侧聊和 Markdown 文件预览支持 LaTeX 公式。短公式正常嵌入正文，超出可用宽度的公式可在自身区域横向滚动，不会撑宽整页。长回复不再按 128 个公式截断渲染；超出公式文本或渲染输出预算、语法无效的公式保留 LaTeX 原文，后续正文继续显示。

流式回复随浏览器画面更新合并显示，正文、思考和工具参数保留完整内容；回复结束时立即显示最终结果。切线程或重新连接时，旧线程尚未绘制的片段不会追加到新线程。预约状态继续自动同步，未变化时减少重复详情读取；打开待发送列表时仍读取最新记录。

消息显示在“设置 → 使用偏好 → 消息显示”中切换，也可从线程标题栏的 `⋯` 菜单点“消息显示…”直达；选项下方一行说明会随所选（或悬停）的选项变化。新浏览器默认简洁：任务结束后每轮只保留最终回复，中间回复和执行记录收进一条“用时 ×× · 工具调用次数”摘要，点击摘要展开核对。正文显示每条回复，连续思考和工具记录合并为一行“执行记录”；完整记录逐条展开，便于排查。各视图中的长行内代码、路径和标识符会按可用宽度换行，代码块保留独立横向滚动。出错或中断的轮次在摘要上标红提示，停在待确认工具调用的轮次不会折叠。浏览器会记住你的视图选择；展开状态在实时更新和重连期间保留，刷新页面后恢复默认折叠。运行中在加号菜单选择引导／后续消息；输入区没有内容时主按钮显示停止，有内容时显示发送。超时或断线时先核对线程状态，避免重复发送。

Codemode 等嵌套工具归属父调用，展开父过程可看子调用状态和有界参数。原生历史不保存嵌套输出，未完成、参数缺失和编辑差异无法恢复会明确提示；本轮文件只归属可核实的成功子调用，不从当前文件伪造历史差异。

长对话中，实时更新主要刷新当前轮次；回复结束和重连时复用未变化的历史消息，保留阅读位置和已展开内容。完全复用的消息不重复整理尾部布局，工具、Shell 和工作流状态仍正常核对。阅读历史时，上方内容延迟增高或缩短会尽量保持可见段落的位置；手动滚动或拖动滚动条优先，不强行拉回旧位置。首次打开线程时，加载占位随连接／读取／错误状态更新；同一线程断线重连保留已显示的正文。历史工具的参数、输出、图片和差异在首次展开时显示；需要用浏览器页内查找搜索工具输出时，先展开对应工具。服务端历史搜索和导出仍包含完整记录。

主聊天中，最终回复底部操作图标右侧显示消息的本地时分，悬停可查看完整日期时间。此时间来自原生消息记录，可能是开始生成的时刻，并非精确的完成时间；旧记录缺少有效时间时不显示。

主聊天中的用户消息使用宽松的长文折叠：单段正文超过 2,400 字符或 30 行时默认保留约 20 行预览，点击“展开全文”查看完整内容，也可再次收起。短消息保持完整显示，图片附件不随正文隐藏，复制问题仍复制完整原文。当前聊天更新时保留展开状态，刷新页面后恢复默认折叠。

主输入框`!命令`执行服务器Shell，`!!命令`排除后续模型上下文但仍保留原生执行记录。工具使用当前系统用户权限，项目选择范围不构成沙箱。只安装你信任的Packages/扩展/Skills。

临时线程刷新或断开后结束，不保存会话文件。未发送草稿和附件只存在于当前页面，刷新或关闭前自行保留。

停止或取回队列失败时，“操作结果待核实”提示会保留到核对、收起或切换线程。“核对当前状态”只刷新当前会话并打开详情，不重放停止／取回；“查看取回内容”打开原运行队列。提示消失不证明外部操作已撤销，仍需核对实际状态与恢复文字。

## 任务进度卡

Agent 为多步骤任务建立计划后，输入框上方会出现“当前进度”标签，默认收起，显示完成数和当前步骤。点击后在输入框上方浮出完整步骤列表（待开始、进行中、已完成），不占聊天区高度；点击其他位置、再次点击标签或按 Esc 收起，全部完成后保留用户当前的展开选择。长计划在浮层内滚动；没有计划时不占位置，草稿和附件不受更新影响。

这是内置的 `update_plan` 工具，无需安装额外包或修改自己的提示词。Agent 会根据任务复杂度选择使用，你也可以直接说“列个计划并更新进度”。进度由 Agent 明确报告，不表示系统自动验证了工作；停止、出错或回复结束不会自动勾选剩余步骤。需要调整或清除时，直接让 Agent 更新计划。

正式线程的计划保存在 Pi 原生会话中，刷新、重连和重新打开后恢复，历史导航及分叉跟随所选分支；压缩上下文不清除计划。临时线程只在本次运行中保留，侧聊不提供该卡片。一个线程分支只展示最近一份计划，旧更新仍保留在原生记录里。已打开的旧 worker 需要在空闲时重载扩展或重新打开运行实例，单独刷新网页不能给旧 worker 增加工具。

## 选中文字继续讨论

选中主对话或侧聊单条消息里的正文，会出现“加入主对话 / 在侧聊中提问 / 朗读选区”菜单，桌面也可右键打开。加入对话会把文字放进输入区域的引用卡片，保留已有草稿；点击卡片标题展开，× 移除，再输入问题发送。打开侧聊不自动发送问题，也不重置已有侧聊背景。朗读只处理选中的文字，沿用当前语音默认配置。手机仍可使用系统复制菜单。

引用随已发送消息保存；未发送引用跟随本页草稿，刷新不会保留。具体限制见[输入与引用](COMPOSER_TOOLS.md#选中文字提问)及[选区朗读](REPLY_TTS.md#选区朗读)。

## Agent 新建任务线程

在正式线程里说“新开一个线程做这件事”，Agent 可把已明确的任务交给同项目的新线程并立即执行。可指定模型和思考等级，省略时使用新线程默认配置。原线程显示创建回执和打开入口，新线程的首条任务标注 Agent 来源，刷新后仍保留。

回执是创建时的状态；最新进度从目标线程查看，也可让 Agent 查询任务标识。启动未确认时先打开已创建的线程检查，不要重复创建。结果以回执送回来源线程，但不自动唤醒它；停止原线程不停止新线程，多个线程仍共享项目文件。详情和限额见[Agent 任务线程](AGENT_THREADS.md)。需要更新后的后端及 worker，旧实例仅刷新网页不会启用此能力。

### 线程之间直接沟通

同一项目的任意两个线程可以互发消息，不需要是创建关系，对方关闭时也能唤醒。例如在前端线程里说“问一下后端线程接口最终用哪个端口”，Agent 会找到对应线程发送；对方空闲时处理并回复，回复到达后会唤醒原线程继续。对方正忙时消息排队，本轮结束后处理；只需告知不需处理的内容可让 Agent 以“仅留言”发送。

收到的消息显示为“来自 Agent 的消息 / Agent 回复”卡片，标出发送线程和是否唤醒，可一键打开来源线程。Agent 消息不是你的指令，不扩大授权。连续自动往返达到上限后消息仍会送达但不再唤醒，需要你查看后继续。线程仍共享项目文件，协作时请让 Agent 约定各自修改的文件。规则见[线程间消息](AGENT_THREADS.md#线程间消息)。

任务说明、回执、结果、线程间消息和上下文压缩摘要默认折叠成一行，点击“展开全文 / 查看摘要”查看，长内容在卡片内部滚动。

## 项目与线程归档

项目线程栏默认“项目”。项目菜单的“归档项目”把整个项目放到列表底部的“已归档项目”，线程菜单的“归档线程”把单条线程放到所属项目下的“已归档线程”；两处默认折叠，数量随实际列表显示。展开后可以直接打开查看，菜单中的“恢复项目 / 恢复线程”才将它移回常用区。查看不会自动恢复。

项目和线程归档互相独立：恢复项目不会恢复其中单独归档的线程；恢复线程也不会恢复它的项目。“随项目归档”表示该线程由项目归档收起。归档只保存展示偏好，不删除目录或会话，不停止正在运行的任务；状态跨设备同步，折叠展开只在当前页面记忆。

“动态”仍显示归档线程的运行、新回复、失败和待确认提醒，并标注归档状态；它们不会进入最近会话。列表搜索和跨线程正文搜索默认不查归档项，勾选“包含已归档”后可查找旧内容。归档入口需要后端支持，旧后端不会显示不可用操作。

线程菜单的“历史与记录”二级菜单统一收纳会话树、搜索历史与书签、导出记录；复制名称和ID仍在“复制”二级菜单。方向键、返回和Escape沿用现有菜单操作。

## 辅助模型

“设置 → 使用偏好 → 辅助模型”按用途集中配置标题生成和媒体规划。每行可选择供应商与模型，齿轮展开说明及现有选项；修改后点击“保存更改”。已有标题模型和媒体“模块 Agent”选择会直接沿用，无需重新设置。重新进入此页会读取最新本地模型目录并保留未保存的选择；子 Agent 和辅助模型目录来自原生配置，仅在会话扩展中新增的模型需先配置到“供应商与模型”。

标题行的“自动”使用当前线程模型；媒体行的“自动”使用媒体规划默认规则，具体顺序在该行说明中。也可以为两项都选择同一个便宜模型。专用模型不可用或失败时不会自动换成其他模型。“全部设为自动”先修改选择，保存后生效，并保留自动标题开关。

这里仅管理已有的辅助任务，不改变主聊天模型、媒体执行模型或安装行为。扩展助手使用独立的正常聊天会话和该会话的模型选择，不在辅助模型中另设路由。完整范围与扩展方式见[辅助模型说明](AUXILIARY_MODELS.md)。

## 会话列表显示

当前源码在打开普通聊天页时，先向服务器核实上次项目的规范路径及可见性，再优先恢复其线程；其他展开项目可继续后台加载。被隐藏的项目不会因刷新页面自动恢复可见，验证不可用时回退到项目列表加载。项目／线程列表复用经文件身份校验的内存摘要，单个会话变化不要求重复解析其他未变化正文；服务重启后的首次发现、大文件及安全回退仍可能较慢。这不是聊天记录副本，也不改变原生历史、搜索或导出。

常用线程以标题和底部信息两行展示，不再固定显示首条问题的重复摘要。有名称时标题为一行，截断后可悬停查看完整标题；没有名称时以首条问题兜底，最多两行。保留更新时间和选中高亮；鼠标在线程行停留约 0.7 秒后显示提示卡（触屏不显示，移开、滚动、点击或 Esc 关闭），内容为完整标题、更新时间，并在列表提供统计时显示当前分支消息数、压缩次数、上下文保留消息数、最近上下文 token 与模型。统计由启用助手档案／项目功能的后端提供，缺失时不虚构数值。动态跨项目展示时仍标注所属项目。

处理中、工具执行、压缩、重试、等待确认、未读、失败、停止及连接未知等提示继续显示。仍保留运行实例的线程显示绿色对勾图标与“空闲”，悬停可查看 `/quit` 退出说明；没有本工作台运行实例的线程不常驻“未运行”文字。搜索命中首条问题且需要补充说明时显示关键词附近片段，清空搜索后收起。临时会话仍显示不保存及退出/断开后销毁的说明。

项目菜单将“导入 Pi 会话”“项目信任”“复制项目路径”收进“更多操作”二级菜单，常用的新建、置顶、刷新及归档等操作仍在一级。线程菜单不重复提供“待发送消息”；请从对话框输入区的待发送数量／管理入口查看队列，线程卡片上的待发送提示继续保留。

空闲不等于资源已释放。默认空闲回收阈值为 15 分钟，还需没有浏览器订阅、运行任务或阻止回收的待处理操作；保留中的恢复草稿等也可能阻止回收。切换线程不会立即退出运行实例，需要主动释放时可打开对应线程使用 `/quit`。

## 移动线程到其他项目

线程菜单 → **移动到项目…**，选择目标服务器目录 → **检查并预览** → **确认移动**。默认列表只显示有会话的其他项目；零会话旧项目可通过“其他项目路径…”手动填写。会话 ID、完整历史、分支、书签与创建时间保留；归档、完成提醒、用量及历史交付跟随线程。当前页面的草稿和已读取附件会保留并跟随同一线程连接到目标项目，旧会话地址仍可解析。后续工具使用目标工作目录和项目指令，原项目文件需要另行准备，历史正文中的旧路径保持原文。

首版支持空闲的普通持久线程。同一身份和文件系统、完整 v3 会话、64 MiB 上限；助手绑定、任务回执／线程间消息、预约／定时引用、其他分叉的父会话及未结束的侧聊／后台工作会在预览中说明阻碍。移动失败或响应不明时先核对两边列表，不自动重试；需恢复的线程会阻止继续写入，并保留私有原始备份。完整范围和恢复说明见[会话工作流](SESSION_WORKFLOWS.md#移动线程到其他项目)。只有实际后端启用能力时才显示入口。

## 会话标题

“设置 → 使用偏好 → 辅助模型 → 标题生成”的齿轮中提供“自动生成会话标题”开关，默认开启，设置在本实例的设备之间共享。开启后新建且未填写名称的持久线程，会在首轮有效问答结束后后台生成一次短标题；寒暄会暂缓，之后的聊天不会持续改名。生成前仍显示首条问题的截断文本。已有历史、复制/导入的线程与手动名称不会自动覆盖。

在“标题生成”行可以保留“自动 · 当前线程模型”，或选择专用供应商和模型，再点击统一的“保存更改”。此选择与其他辅助用途和聊天默认模型独立，不改变任何线程的聊天模型。保存只核对模型目录与认证，不执行生成。只关闭自动命名开关也会保留模型选择，仍可手动生成。

线程菜单的“重新生成标题”使用上述模型设置生成建议，先在窗口里预览并编辑，点击保存才改名；关闭窗口保留原名称。如果生成期间别人改了名称或对话位置发生变化，旧建议不能覆盖新状态。原“重命名”仍可直接使用。生成成功后显示本次实际使用的模型，以及 Pi 返回的输入、输出和缓存 Token 数；缺失字段显示“—”，没有用量数据时明确提示未上报。

标题请求最多引用最近 6 条问题／完整结束的回答，每条最多 2,000 字符，合计最多 8,000 字符；即使会话很长，也不会发送完整历史。摘录不携带思考、工具输出或图片，也不在主聊天里增加消息。专用模型可与主线程属于不同供应商，这份摘录会发送给你选定的服务。它会产生额外模型用量，目前不计入持久会话用量统计，也不保存标题请求的累计用量日志。无法生成时保留原显示，不打断聊天、不自动重试；依赖扩展注册或请求钩子的特殊模型可能不能独立生成标题，可手动命名。关闭自动命名或更改标题模型不会取消已经发出的供应商请求；新选择用于后续请求，先前正在生成的自动结果会被丢弃。手动建议会标出它实际使用的模型，仍需明确保存。

## 历史、文件与侧聊

实例启用 `sideChatModels` 后，展开侧聊“设置”可单独选择模型和 Thinking，默认继承主聊。仅空闲时可切换，保留记录和草稿、不影响主聊；容量不足或不支持现有图片时会拒绝，不自动丢弃背景。

历史页可以搜索、保存书签和查看会话树。导航、编辑重试和恢复旧版本改变对话位置，**不会撤销文件、命令或外部请求**。复制/分叉创建新线程；HTML适合阅读，JSONL导出只含当前活动分支，完整备份仍需停机保存数据目录。

右侧“文件 → 项目文件”可以按目录树浏览当前项目，或按文件名／相对路径查找尚未展开的目录中的文件；无需先让 Agent 修改。点击文件查看当前内容，路径栏支持返回目录、定位和复制路径。目录和文件均需手动刷新，不自动向模型发送内容。

桌面可点击“展开阅读”，文件区足够宽时并排显示预览和目录树；窄屏通过“浏览项目文件”切换目录与正文。隐藏文件开关保留凭据和私密目录限制。本页记忆目录展开和有限的阅读位置，刷新页面后重置。

“本轮文件”保留每轮成功的 edit/write 列表。差异是原生操作记录；当时的写入内容和“当前文件”是不同来源，当前磁盘内容需要显式读取或刷新。后端启用新文件预览后，图片可适应窗口或原尺寸查看并下载；PDF 支持翻页、缩放和本页文字，CSV/TSV 支持分页表格，SVG 支持受限静态图片与源码切换，音频使用浏览器播放器且不自动播放。关闭文件面板停止 PDF 任务和音频，单文件仍最多 16 MiB；HTML 默认静态隔离展示，仅对可信页面点击“运行交互”。“交付物”保存 Agent 明确交付时的版本，与当前磁盘文件分开；可直接点击回复中的交付链接，不必切换到服务器输出目录。项目外旧路径尚未登记时，请让 Agent 使用 `deliver_files` 发布本次成果，而非扩大项目范围。范围、HTML 限制和搜索限额见[文件浏览与查看](FILE_VIEWER.md)。

启用 `sideChatLifecycle` 后，点击侧聊只展开面板，首次发送才冻结主线程的有效背景并创建运行实例。回复完全结束后闲置12小时会释放运行资源，记录和草稿仍在本页；点击“新开侧聊”准备新段。设置中的“更新背景并新开”保留旧段为可展开历史，发送时重新抓取背景，新Agent看不到旧侧聊，需用户自行复制所需信息。“结束并清空”会删除当前主线程全部侧聊展示和草稿，不影响其他线程；刷新／关页不恢复这些临时记录。侧聊顶部的信息按钮可按需查看用途、历史不继承、12小时闲置与本页记录限制及执行确认要点，默认界面不重复显示这些说明。侧聊默认冻结主线程的有效背景。实例启用 `sideChatTools` 后，可读取、检索当前文件；明确要求修改时，侧聊会在首次写入或运行命令前询问本次回复的执行授权，结束后恢复询问。工具记录和授权状态在侧聊中显示。主侧共享目录，请避免同时改同一文件；停止不会回滚已发生的改动。有用内容可复制到主草稿。本页切换持久线程可保留有限段侧聊；刷新、关页和退出登录会结束它们。

## 在聊天里生成图片、视频和语音

配置好图像、视频或语音模型后，直接在 Pi Agent 或助手对话里说要什么，例如“给这份报告画张封面”或“把这段话配成语音”。Agent 读取你配置的模型和参数要求，在对话中放一张生成卡片：模型、摘要和主要参数一目了然，提示词或朗读文字可展开。卡片出现时还没有生成，也没有调用付费服务。

- 点“确认生成”才会按卡片上的参数生成一次；完成后图片、音频或视频直接显示在卡片里，可查看原图或下载，并进入多媒体实验室的生成记录。
- 不满意可点“修改参数”直接在卡片里改，或继续告诉 Agent 怎么改，它会给出新卡片。服务端若调整了默认值或格式，会先把调整后的参数给你核对，再次确认才生成。
- 生成在服务器上继续进行，可以离开页面或换到手机，回来后卡片显示结果；同一张卡片不会因刷新、多开页面或连点被重复提交。
- 再生成一次需要点两下确认；上次结果不确定时会提示可能已经计费。失败或结果不确定都不会自动重试，请先在生成记录里核对。
- 卡片在“精简”“阅读”“完整”三种显示模式下都保持可见。侧聊不提供生成卡片。

多媒体实验室继续保留生成记录、模型接入和完整参数编辑，今后会逐步收敛为作品库与配置入口。

## 多媒体实验室

新安装没有默认可执行的图像/视频/语音服务。在“设置 → 模型与能力”的图像、视频或语音入口，或实验室管理入口添加服务地址、Key和模型ID；按实际文档选择协议。聊天模型的凭据不代表媒体服务自动可用。

填写创作要求，让Agent生成方案或直接编辑常用参数；检查提交清单后确认单项生成。方案、连接探测和生成是不同操作。失败或结果不确定时先检查服务端任务和历史，不自动重试。回复旁的喇叭点击会按当前默认语音配置生成这一条朗读，可能收费。

## 管理与排障

新源码统一使用 Pivane 名称，并兼容旧配置和会话标记。普通升级无需手动重命名文件；迁移项目目录时需要同时处理原生会话归属和启动配置，不能全文替换聊天 JSONL。维护者操作见[命名与迁移](development/NAMING.md)。

用量统计读取持久会话原生记录，并入账新建侧聊在引用边界之后的实际模型调用；继承的主线程历史不重复计算。费用是历史配置估算，不等于供应商账单。侧聊不会保存正文或引用，仅保存精简用量事实；关闭前若账本持续故障，未成功入账的用量无法恢复，已结束的旧侧聊无法追溯。普通临时会话、标题生成和媒体规划仍不纳入累计统计。配置保存通常对新运行实例生效，已有任务不会因此被自动停止。

本机通知可使用浏览器页面通知/提示音；手机后台推送需要HTTPS和系统支持。开启远程入口前检查访问验证。升级或备份前暂停预约并停止任务，再按[安装与恢复](INSTALL_RECOVERY.md)停机操作。

更多功能与接口见[文档目录](README.md)。让Agent排障时使用[操作指南](AGENT_GUIDE.md)，提供脱敏错误与实例路径，不提供凭据正文。
