# Pivane 用户指南

[English](en/USER_GUIDE.md) · [安装](INSTALL_RECOVERY.md) · [文档目录](README.md)

Pivane 运行在你部署它的电脑或服务器上。浏览器可从其他设备访问，但项目目录、Shell 和 Agent 工具使用的是**服务器文件系统与系统用户权限**。

## 首次开始

1. 按[安装指南](INSTALL_RECOVERY.md)启动实例，打开启动日志中的网址。
2. 在“设置 → 供应商与模型”核对已有 Pi 配置；缺少认证时再填写 API Key 或完成 OAuth。不要把凭据发到聊天中。远程 OAuth 的 localhost 指服务器，按服务提供的设备码或手动回调步骤操作。
3. 回到 Pi Agent，选择服务器项目目录，点击“新聊天”，选择模型与思考等级。
4. 发送一个简单问题，再刷新并重开持久线程，核对回复保留。请求会使用你的供应商账户。

CLI 有模型而网页没有时，先核对身份目录和启动环境，见[已有 Pi 接入](PI_CLI.md)。没有选择项目也可管理全局模型与扩展。

## 工作区导航

- **Pi Agent** 按真实目录管理线程；**助手对话**按身份和项目分类管理线程；身份、扩展、定时任务和媒体实验室各有独立页面。
- 桌面左侧导航可收起为窄栏：展开时点击右上角的面板按钮收起；收起后把鼠标移到 Logo 上（或用键盘聚焦）会变成展开按钮，触屏设备在 Logo 角落显示展开标记。选择保存在当前浏览器；平板宽度始终显示窄栏，不改变已保存的桌面选择。
- 手机底栏的“更多功能”收纳其他入口。项目／线程抽屉打开时，底栏和顶部导航仍可操作；顶部抽屉按钮可直接收起抽屉，项目名称可打开项目选择器。打开其他入口或面板前会先收起抽屉。
- 左栏“项目”按目录浏览，“动态”集中显示运行、需处理和最近会话。列表搜索匹配标题及首条问题；底部“搜正文”搜索完整对话，Ctrl/Cmd+K 聚焦列表搜索。
- 正文搜索在当前页面保留关键词、结果页和阅读位置；“定位当前线程”调整列表和焦点，不改变归档状态或重新启动会话。
- 右侧提供详情、文件、历史和侧聊。桌面面板并排且可调宽，窄桌面暂藏线程列表；手机使用抽屉，Esc 或关闭按钮退出。关闭面板不会停止任务。

进入设置等管理页面不会结束会话。返回助手对话时会重新读取项目与线程，保留本页草稿和附件。在 Pi Agent 与助手对话间切换后，重新选择线程即可继续；本页暂存各线程草稿和已读取附件，**刷新或关闭页面前请自行保留未发送内容**。

管理页面在首次使用时加载，等待时显示加载状态，资源读取失败可点击重试。加载期间仍可切换页面，迟到的结果不会把你带回旧页面。聊天中的身份名称、配置查看和自动更新提醒无需先访问管理页面。

## 模型与能力

桌面点击输入区的模型名称，手机点击上下文圆环打开模型面板。可搜索名称、ID 或供应商；星标整理跨设备共享的常用模型，最近使用保存在当前浏览器。模型、思考等级和可选速度取自实际能力，切换需要会话空闲。

支持 Fast／Ultrafast 的渠道显示速度和费用倍率；速度与思考独立。模型默认值在“设置 → 供应商与模型”修改，详见[模型与速度](PROVIDER_SETTINGS.md)。

“设置 → 模型与能力”管理图像、视频、语音服务及子 Agent。各媒体入口只列对应类别；语音分为 TTS 和 ASR。共享服务地址或凭据的修改会影响其所有模型。聊天凭据不会自动配置媒体服务。

## 对话与工具

`@` 插入服务器项目文件路径；附件、粘贴和拖放上传浏览器提供的文件。持久线程支持 DOCX、XLSX、PPTX 和 PDF 原件，每份最多 20 MiB、每条最多五份；上传后输入总结、分析等任务，Agent 按需读取，文件卡片可下载原件。读取范围、公式与扫描页限制见[办公附件](COMPOSER_TOOLS.md#上传办公文档与-pdf)。运行时可在加号菜单选择“引导”或“后续”：空草稿显示停止，有文字、引用或附件时显示发送。

在“设置 → 使用偏好 → 消息显示”选择：

| 视图 | 显示方式 |
|---|---|
| 简洁 | 每轮保留最终回复，执行过程可展开 |
| 正文 | 显示每条回复，合并思考和工具记录 |
| 完整记录 | 逐条查看过程，适合排障 |

成功的 `deliver_files` 调用会在聊天内显示紧凑的文件列表卡片：每行有文件类型图标（8 MB 内的图片显示缩略图）、文件名、格式和大小，点击整行打开预览，行尾按钮直接下载；超过 5 个文件时可展开其余文件。无需依赖模型在最终回复里重复链接；回复中的交付链接和项目文件链接会带上文件类型图标。卡片在简洁视图保留，并从仍可见的原生历史恢复，失败调用不生成成功卡片。

需要用户选择方案或补充信息时，Agent 可调用内建 `ask_user_question`，一次最多提出 4 个问题。问题面板停靠在输入框上方，不遮挡对话：选项带序号和说明，点击或按数字键即可选择；也可在“或自行撰写回复”中直接输入自己的答案，或“跳过”某一题。多个问题可用左右箭头来回查看和修改，全部答完后才一次提交；面板可收起，关闭（×）表示不回答。提交后对话中保留一张回答摘要卡片。默认等待 10 分钟，最多 30 分钟，最后两分钟显示倒计时。取消、超时、停止和缺少交互界面都不会被视为同意，跳过的问题也不代表默认选择；刷新或重连会恢复尚未结束的提问，不自动重新提问。

Codemode 与嵌套工具行显示原生记录的执行耗时，包括零毫秒及历史结果；没有原生耗时的旧记录不推算。压缩摘要不再包含历史 thinking 文本，原生会话中的历史 thinking、工具和用量仍保留。

同一区域可开启“显示回复请求平均速度”，默认关闭，仅保存当前浏览器的显示偏好。最终回复下方显示 `请求平均 ≈ … tok/s`；悬停或键盘聚焦可查看有效请求数、输出 Token 和请求耗时。按本轮有效主模型请求的输出 Token 总数除以对应请求耗时总和，包含首次输出等待、思考、网络和请求内重试；不包含工具执行、压缩摘要及请求之间的等待，因此不是云端纯生成速度。自动压缩前后继续累计，摘要的用量和耗时都不计入；失败、停止、缺少用量或计时不可用的请求不计入，有其他有效请求时标为“部分”。思考 Token 沿用供应商用量且不重复相加。旧消息无统计时不显示；侧聊和子 Agent 请求不合并到主回复。

计时只在请求边界读取单调时钟，少量累计字段随原生消息保存，不增加逐 Token 监听、定时器、模型调用或独立统计文件。显示开关不停止这部分轻量记录，刷新后可直接查看已有数据。

工具参数和输出需展开后才能用浏览器页内查找搜索。长行内代码自动换行，代码块和宽公式在自身区域滚动；公式无法解析或超预算时保留原文；公式内的常见中文标点 `，。、；：！？` 可正常显示，其他严格检查和渲染限制保持不变。主聊天、侧聊和 Markdown 文件预览支持 `$…$`、`\(…\)`、`$$…$$`、`\[…\]` 及 `math`／`latex` 围栏。公式可紧接上一段文字，公式里的单行等号或减号不会被当作标题；列表、引用、表格及粗体／斜体混排会保护公式中的竖线、星号和下标，表格中的 `\|x\|` 保留范数语义。流式未闭合的显示公式保留原文，闭合后自动渲染。兼容中文标点后紧接加粗结束标记和汉字的写法。兼容仅在显示时生效，代码示例、转义字符和原始消息保持原样，已有消息重新显示时也适用。长用户消息可展开，复制仍取得完整文本。回复时间来自原生消息记录，不一定是完成时间。

长回复按当前段落识别公式，重复公式在有界缓存中复用；嵌套工具的连续状态更新会合并到同一显示帧。主聊天和侧聊的流式正文会保留未变化的段落、代码与公式节点，后续内容改变其含义时仍重新显示；最终回复以原生记录校正。原始消息和渲染预算保持不变。

数学命令以本地 KaTeX 的支持范围为准，常见分式、根式、矩阵、分段函数、多行对齐和显示公式编号 `\tag` 可用；中文文字放在 `\text{…}` 中。自定义宏只在当前公式内有效，不加载外部 LaTeX 宏包。化学扩展 `\ce`、跨公式的 `\label`／`\ref`／`\eqref` 和未加数学分隔符的环境不自动渲染。

`!命令` 执行服务器 Shell；`!!命令`不进入后续模型上下文，但仍保留原生执行记录。项目范围不是工具沙箱，只安装可信扩展。超时、断线或停止／取回结果不明时先核对状态，勿重复发送；停止不会撤销已发生的文件修改或外部请求。

连接来不及接收大量输出时，服务器会关闭该慢连接。持久线程会尝试重新连接并读取当前记录，已接受的操作继续执行，其他连接可继续使用；页面不会自动重复发送结果未知的请求。临时线程不保存会话文件，刷新或断开后结束。详见[输入与命令](COMPOSER_TOOLS.md)、[Shell](WEB_SHELL.md)和[运行控制](NATIVE_CONTROLS.md)。

### 语音输入

点击麦克风录音，再点结束并转录；文字加入可编辑草稿，由你发送。录音最多两分钟，需要 HTTPS 或 localhost 和浏览器许可；音频会上传所选服务并可能收费，失败不自动重试。未配置时通过“去配置”进入“模型与能力 → 语音 → ASR”。见[语音转录](COMPOSER_TOOLS.md#语音转录)。

## 任务进度卡

多步骤任务可显示输入框上方的“当前进度”，点击展开步骤，也可直接让 Agent 创建或更新计划。进度由 Agent 报告，不表示系统已验证；停止或回复结束不会自动完成剩余步骤。持久线程刷新后按当前分支恢复计划，侧聊不提供此卡片。

## 使用子 Agent

可以明确让主 Agent 委派任务。输入框上方的“子 Agent”面板显示状态、模型、工具和用量，并提供引导、停止及符合条件运行的继续入口。结果和请示默认折叠，点击查看全文；操作是否可用由实际运行状态决定，结果不明时先核对。

子 Agent 随 Pivane 内置，无需另装。全局／项目默认模型和角色覆盖在“设置 → 模型与能力”保存；角色覆盖不会创建角色定义，保存不会改变正在执行的任务，空闲后重开运行实例生效。详见[内置能力](BUNDLED_CAPABILITIES.md)。

后台工作未结束时会显示“会话保持中”：关闭网页不会停止这些任务，维护和重启也须等待。需要结束时使用对应运行的停止入口。

## Agent 新建任务线程

说“新开一个线程做这件事”，Agent 可创建同项目的持久任务线程并立即执行。可指定模型与思考等级，省略时使用新线程默认值。结果回执返回来源线程，但不自动唤醒它；停止原线程不会停止新线程。

创建结果不明时先查原任务，勿重复创建。多个线程共享项目文件，应明确各自修改范围。详见[任务线程](AGENT_THREADS.md)。

### 线程之间直接沟通

可让 Agent 联系同项目其他线程，对方空闲时处理，关闭时也可被唤醒；“仅留言”不主动唤醒。连续自动往返达到上限后仅投递，等待用户继续。Agent 消息标明来源，不是新的用户授权。见[线程间消息](AGENT_THREADS.md#线程间消息)。

## 可选助手身份

在“助手身份”创建身份，随后到“助手对话”选择身份、项目分类和线程。普通 Pi Agent 新线程不绑定身份。身份页分为五页：**概览**汇总记忆、技能、学习状态和需要处理的事项；**设定**编辑名称、头像、能力开关和 SOUL（行为，可从示例模板开始）；**记忆**按“关于你（USER）”“长期记忆（MEMORY）”“项目记忆”逐条管理，也可切到“全文”直接编辑 USER.md／MEMORY.md；**技能**审核草稿并管理已学习技能；**学习**设置后台学习和每日预算。不再使用的身份可移到回收站，随时恢复，数据不会删除。

分类可复用同一服务器目录，附加不同指令；**文件、AGENTS.md 和按物理目录划分的记忆仍共享**，身份不是安全沙箱。打开已有线程不会改变其原身份。分类整理、起草和保存限制见[助手身份](AGENT_PROFILES.md)。

### 记忆学习的提示与反馈

- 在“记忆”和“技能”页管理条目、删除记录和撤销。保存反馈区分已保存与索引待同步；保存不代表当前会话已加载或模型一定遵守。记忆条目上的“检索命中 N 次”是助手用记忆搜索找到它的次数；USER／MEMORY 全文每轮都会提供，没有标记不代表没被看到，修改内容后重新计数。
- 聊天中的“已记住／Agent 记下／学会技能”卡片可查看回执，并按条目支持的操作撤销、纠错或编辑。技能启用后需空闲重载会话。
- 后台学习默认关闭，需要专用辅助模型。缺模型、额度用完、记忆满和失败状态会明确显示，不自动改用主聊天模型。每日预算可选“节省／均衡（默认）／积极”或自定义（最多每天 500 次、500 万 tokens）；“今日用量”标明先用完的是运行次数还是预留 tokens，以及重置时间。学习页每个选项都有 (i) 说明。
- “整理合并”先生成方案，用户逐组检查并应用；不会自动删除旧内容。已变更条目的旧方案不能覆盖新版本。
- 从聊天入口进入项目记忆管理时核对当前会话目录；无法核实范围时只读。

明确纠错和长期偏好可被学习，“只这一次”可排除；支持自定义触发词。记忆与技能会拦截疑似凭据和提示词注入，凭据应由模型设置或密钥管理工具保存。学习开关、预算、迁移与恢复见[记忆说明](PROFILE_MEMORY.md#background-learning)。

## 自定义系统提示词

在“设置 → 系统提示词”选择所有项目或当前项目，编辑、预览并保存要求；对话空闲后点击“更新当前对话”加载。**项目要求替代通用要求，不会自动叠加**，项目范围受信任设置限制。

“查看当前对话”显示实际提示词及来源。保存不打断任务，网页刷新也不保证重载；冲突或结果不明时先刷新并比较草稿。详见[原生提示词配置](NATIVE_SETTINGS.md#系统提示词查看与编辑)。

## 扩展、精选与已安装资源

桌面打开“扩展”，手机从“更多功能 → 扩展”进入：

- **发现**：按类型（扩展包、技能、消息渠道、MCP）和安装状态筛选精选能力。卡片显示安装状态与已安装版本，最近一次检查发现新版本时标“有可用更新”；“使用前提与示例”在卡片内展开。“了解与配置”把需求放入独立扩展助手草稿，由你发送。浏览和筛选不会安装或调用模型。
- **消息渠道**：顶部汇总组件、账号、绑定和需处理的消息；未完成时按“安装组件 → 扫码 → 绑定线程”逐步引导。允许用户以标签增删，有改动才出现保存栏；卸载组件、停用连接收在 `⋯` 菜单并需确认。线程菜单的“连接微信…”可以直接带入目标。支持文字与图片私聊、文件回传、斜杠指令和定时通知，详情见[微信与消息渠道](MESSAGE_CHANNELS.md)。
- **已安装**：按 Packages、技能、扩展模块、模板或主题筛选，扩展包与技能显示版本（来自包清单或 SKILL.md；包内资源显示所属包版本）。点“检查更新”才会联网查询 npm 与 Git 远端，发现新版本的包在行内出现“更新”；固定版本、本地路径和 Pivane 内置组件不参与检查，离线模式不联网。启用／停用在行内，其余更新、移除和恢复继承在 `⋯` 菜单；安装须核对来源、范围和代码执行影响。
- **MCP**：编辑全局或受信项目配置，保存与连接／重载分开；凭据默认保留，替换和删除须明确操作。查看状态、重连和 OAuth 使用已打开的持久线程。

已安装不等于当前会话已加载；配置完成后空闲重载并核对。项目未受信时不能写项目配置。旧 MCP 适配器迁移须停机备份，详见[MCP](MCP.md)与[原生资源管理](NATIVE_SETTINGS.md)。

加号 → “添加能力…”可让扩展助手帮助安装或排障；包操作通过网页确认，工具运行在部署机器。桌面控制扩展不会直接控制访问网页的手机。只选择可信来源，第三方能力还需自己的依赖和权限。

## 定时任务

从“定时任务”安排周期或单次工作，目标为指定线程或身份主线程；也可从输入区加号创建当前线程任务。核对时区、下一次执行、预算与错过处理后启用。

暂停计划和停止本次运行是不同操作。服务器须持续运行；忙时等待、不确定结果先核对。详见[定时任务与主线程](SCHEDULED_TASKS.md)。

## 会话列表显示

线程列表显示标题和状态，鼠标悬停可看完整标题及可用统计。正文继续输出或滚动时，当前行的悬停统计仍可查看；滚动线程列表或离开该行时关闭。动态列表自动刷新时保留阅读位置和展开状态。线程菜单在布局未变的刷新中保持打开，窗口布局或锚点位置变化时关闭。“空闲”不表示运行实例已释放；需要主动退出时，在对应线程使用 `/quit`。切换线程不会立即停止 worker。

## 项目与线程归档

在项目或线程菜单归档，再从“已归档”分组查看或恢复。两种归档互相独立，只整理显示，不删除数据、不停止任务。动态视图仍提示归档线程的运行与新结果；搜索旧内容时勾选“包含已归档”。

## 移动线程到其他项目

线程菜单 → “移动到项目…” → “检查并预览” → “确认移动”。目标为服务器目录，空项目可手动输入。移动保留会话 ID、完整历史与书签；后续工具使用目标目录，项目文件不会随线程搬移。

仅支持满足条件的空闲普通持久线程；助手绑定、任务关系、调度或后台工作等阻碍在预览中列出。失败或结果不明时先查两边状态，不自动重试。详见[移动与恢复边界](SESSION_WORKFLOWS.md#移动线程到其他项目)。

## 会话标题

新建未命名线程可在首轮有效问答后自动命名，已有历史和手动标题不被覆盖。线程菜单的“重新生成标题”先给建议，编辑并保存后才改名；也可直接重命名。

标题生成发送有界问答摘录给所选服务，会产生额外用量且不计入持久聊天统计。自动开关与专用模型在辅助模型中配置。

## 辅助模型

“设置 → 使用偏好 → 辅助模型”按用途选择标题、媒体规划及后台学习模型。标题“自动”跟随线程；媒体“自动”按页面说明选择；后台学习需要专用模型。显式模型不可用或失败时不自动换模型，保存设置不执行请求。见[辅助模型](AUXILIARY_MODELS.md)。

## 历史、文件与侧聊

桌面聊天区左缘的**对话目录**每个问题一条刻度：指向即可预览问题与回复摘要，点击跳转，卡片右上角或问题标题行可一键加书签（手机在问题标题行操作）。书签是 Pi 原生标签，终端 `/tree` 同样可见。上下文压缩后，较早的问答显示在“上下文已压缩”标记上方，向上滚动即可继续回看；这部分仅供阅读，模型不会再读取原文，目录同样包含这些问题。详见[历史](HISTORY.md#压缩前问答回看2026-10-11)。

**历史**可搜索、加书签、查看树、分叉和恢复对话位置；预览中“在对话中定位”可跳回正文上下文。恢复历史**不会撤销文件、命令或外部请求**。HTML 导出用于阅读，JSONL 导出当前活动分支；完整会话树应通过停机备份保留。见[历史](HISTORY.md)、[工作流](SESSION_WORKFLOWS.md)和[导入导出](SESSION_TRANSFER.md)。

**文件**可浏览项目和关联目录、搜索路径并查看当前内容，不自动送给模型。浏览位置下拉可切根；“添加或管理目录”支持临时打开或按项目保存关联，选择的是服务器目录，不改变聊天工作目录。项目外文件链接可仅打开文件，或关联所在目录，无需先交付；移除关联不删除文件。“本轮文件”的历史差异、“当前文件”和“交付物”的固定版本是不同来源；右栏顶部只常驻“浏览”和“交付物”，从回复下方的“本轮文件”卡片打开记录时才显示“本轮文件”标签。回复下方的文件卡片展开更多文件后，可用键盘选择文件或收起；焦点跟随明确选择的控件。桌面可展开阅读区；全屏阅读支持 Esc／返回侧栏，保留 PDF 页码、缩放和表格分页。图片及 SVG 支持拖动、滚轮和双指缩放；音视频不自动播放。预览单文件最多 16 MiB，独立下载默认最多 512 MiB；超出预览预算仍可下载原件，下载和交付额度可按[文件限额](FILE_VIEWER.md#下载和交付限额)配置。隐藏文件开关不放开私密路径。自包含 HTML 默认隔离静态预览，仅对可信页面启用交互；隔离不保证完全断网。需要稳定下载时请 Agent 用 `deliver_files` 交付成果。见[文件与交付物](FILE_VIEWER.md)。

**侧聊**用于围绕当前背景另开讨论，首次发送冻结主聊背景；可单独选模型，读写当前项目文件。修改与命令需要侧聊内本次回复的执行确认，主侧共享目录，应避免同时改同一文件。空闲 12 小时释放运行资源；更新背景可保留本页旧段供阅读，但新 Agent 不继承旧讨论。刷新、关页和退出登录结束临时侧聊，重要内容先复制回主聊。见[侧聊](SIDE_CHAT.md)。

## 选中文字继续讨论

选中主聊或侧聊正文，选择“加入主对话”“在侧聊中提问”或“朗读选区”。引用加入草稿，不自动发送；手机仍可使用系统复制。未发送引用刷新后不保留，朗读可能收费。见[输入与引用](COMPOSER_TOOLS.md#选中文字提问)。

## 在聊天里生成图片、视频和语音

配置媒体模型后，直接说“给报告画张封面”或“把这段话配成语音”。Agent 放置生成卡片，**出现卡片尚未生成或收费，点击确认后才执行**。

- 分阶段做视频：先让 Agent 为场景准备首帧、尾帧或参考图，确认并等图片完成；下一轮要求使用这些图片生成视频。Agent 查询当前会话结果并使用固定素材引用，卡片标明首尾帧和参考顺序。完成的视频可直接播放、下载，也可继续作为模型的参考视频。
- 慢任务：视频默认等待2小时，可在模型接入中设为最长24小时，已有模型保留原设置。异步卡片超时或重启后可点“继续查询原任务”取回同一个任务的结果，不会重新生成；同步接口未提供任务编号时需先到服务端核对。
- 图片编辑：在 Pi Agent 或助手对话上传 PNG/JPEG/WebP，说明“保留主体，把背景改成夜景”等要求。Agent 选择支持图片输入的编辑模型，卡片展示原图供核对；也可继续要求修改刚生成的图。参考图可在“修改参数”中替换，具体能力以所选模型为准，见[聊天图片编辑](MEDIA_AGENT.md#聊天图片编辑与参考素材)。
- 可先修改参数；服务器调整了参数时会再请你核对。
- 结果显示在卡片及实验室历史中，离页、重连和换设备后继续同步，同一卡片不会重复提交。状态刷新保留本页未保存的参数编辑和同一结果的播放进度；切换线程会释放旧卡片。卡片状态查询与生成任务的等待时限分别处理。
- 同时确认多张卡片会按名额排队，可取消尚未开始的项；远端最多 4 项（视频 2 项），本地后端 1 项。
- 超时可能意味着服务商仍处理并计费。先核对历史与远端任务；失败或不确定结果不自动重试，再生成需重新确认。

侧聊不提供生成卡片。详细用法见[媒体实验室](MEDIA_LAB.md)。

## 多媒体实验室

新安装没有默认可执行媒体服务。在“模型与能力”或实验室添加服务地址、凭据、模型与其支持的协议；可上传参考素材、直接编辑参数，或让 Agent 帮忙规划，再检查清单并确认生成。

回复喇叭按当前朗读默认值生成语音，点击即授权该次请求，可能收费。界面语言不改变音色或朗读语言。见[媒体接入](MEDIA_CONNECTIONS.md)与[朗读](REPLY_TTS.md)。

## 网络与访问

“设置 → 网络与访问”管理登录验证、监听范围和代理。监听／代理分别保存，安全重启服务后生效；保存不会重启或开放防火墙。先启用登录验证再开放其他设备访问；代理地址的 localhost 指服务器。见[网络与访问](ACCESS_CONTROL.md)。

## 外观与字体大小

在“使用偏好 → 外观”或侧栏调色板选择主题、跟随系统或字号，即时生效并保存在当前浏览器；其他设备独立设置。浏览器缩放仍可使用，手机输入字号不低于 16px。

主题有晴空（天蓝）、薄荷（青绿）、燕麦（暖米色配陶土色）、石墨（黑白中性）和夜间（深色配天蓝）；各主题的界面底色接近中性，颜色主要用于按钮、选中项和链接。“跟随系统”在晴空与夜间之间切换。新增内容、连接正常等状态在所有主题中都用绿色表示。旧版的雾蓝和丁香已停用，之前选择它们的浏览器显示为晴空，重新选择后保存新主题。

## 界面语言

支持简体中文和英文，默认跟随浏览器，未匹配时回退英文。在“使用偏好”修改后页面立即刷新切换，各线程输入框里未发送的文字在刷新后恢复；若有未发送的附件、临时会话、侧聊或正在提交的消息，设置页先列出会受影响的内容，由你点“立即切换”确认，或留到下次刷新时生效。语言设置不翻译对话、文件和自定义名称，也不改变模型请求或朗读语言。见[界面语言](I18N.md)。

## 找不到其他项目目录

项目选择器受服务器 `PI_PROJECT_ROOTS` 和系统权限限制，不要求项目放在 Documents，也不能选择访问设备的本地目录。网页不能修改范围，应在启动配置中调整，空闲重启后生效；无需为此迁移会话。见[目录范围排障](INSTALL_RECOVERY.md#项目选择器找不到目录)。

## 版本与更新

“设置 → 版本与更新”检查 Pivane 和 Pi 版本，不自动安装。需要更新时复制独立 Agent 提示词，在部署机器由另一个 Agent 核对兼容性、备份和方案后执行；承载当前会话的服务不能由本会话直接停止。Pi 与 Pivane 成组升级。见[更新](UPDATES.md)。

## 管理与排障

- 用量来自持久会话和支持的侧聊记录，费用为估算，不等同供应商账单；标题、普通临时会话和媒体规划等范围见[用量](USAGE.md)。
- 配置保存通常不改变已打开的运行实例。需要重载时先结束工作；网页刷新可能仍连接同一 worker。
- 页面通知、提示音和后台推送的权限及平台限制见[通知](NOTIFICATIONS.md)。
- 升级前保留草稿、等待任务和相关活动空闲，再按[安装与恢复](INSTALL_RECOVERY.md)备份与切换；普通升级无需重命名数据文件。

排障提供脱敏错误、操作步骤和实例路径即可，不提供凭据正文。可把[用户 Agent 指南](AGENT_GUIDE.md)交给协助者。
