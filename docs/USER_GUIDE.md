# Pivane 用户指南

[English](en/USER_GUIDE.md) · [安装](INSTALL_RECOVERY.md) · [文档目录](README.md)

Pivane 运行在你部署它的电脑或服务器上。浏览器可从其他设备访问，但项目目录、Shell 和 Agent 工具使用的是**服务器文件系统与系统用户权限**。

## 首次开始

1. 按[安装指南](INSTALL_RECOVERY.md)启动实例，打开启动日志中的网址。
2. 在“设置 → 供应商与模型”核对已有 Pi 配置；缺少认证时再填写 API Key 或完成 OAuth。不要把凭据发到聊天中。远程 OAuth 的 localhost 指服务器，按服务提供的设备码或手动回调步骤操作。
3. 回到 Pi Agent，选择服务器项目目录，点击“新聊天”，选择模型与思考等级。
4. 发送一个简单问题，再刷新并重开持久线程，核对回复保留。请求会使用你的供应商账户。

CLI 有模型而网页没有时，先核对身份目录和启动环境，见[已有 Pi 接入](PI_CLI.md)。没有选择项目也可管理全局模型与扩展。

## 工作区导航

- **Pi Agent** 按真实目录管理线程；**助手对话**按身份和项目分类管理线程；身份、扩展、定时任务和媒体实验室各有独立页面。
- 手机底栏的“更多功能”收纳其他入口。项目／线程抽屉打开时仍可导航，切换入口会先收起抽屉。
- 左栏“项目”按目录浏览，“动态”集中显示运行、需处理和最近会话。列表搜索匹配标题及首条问题；底部“搜正文”搜索完整对话，Ctrl/Cmd+K 聚焦列表搜索。
- 正文搜索在当前页面保留关键词、结果页和阅读位置；“定位当前线程”调整列表和焦点，不改变归档状态或重新启动会话。
- 右侧提供详情、文件、历史和侧聊。桌面面板并排且可调宽，窄桌面暂藏线程列表；手机使用抽屉，Esc 或关闭按钮退出。关闭面板不会停止任务。

进入设置等管理页面不会结束会话。在 Pi Agent 与助手对话间切换后，重新选择线程即可继续；本页暂存各线程草稿和已读取附件，**刷新或关闭页面前请自行保留未发送内容**。

## 模型与能力

桌面点击输入区的模型名称，手机点击上下文圆环打开模型面板。可搜索名称、ID 或供应商；星标整理跨设备共享的常用模型，最近使用保存在当前浏览器。模型、思考等级和可选速度取自实际能力，切换需要会话空闲。

支持 Fast／Ultrafast 的渠道显示速度和费用倍率；速度与思考独立。模型默认值在“设置 → 供应商与模型”修改，详见[模型与速度](PROVIDER_SETTINGS.md)。

“设置 → 模型与能力”管理图像、视频、语音服务及子 Agent。各媒体入口只列对应类别；语音分为 TTS 和 ASR。共享服务地址或凭据的修改会影响其所有模型。聊天凭据不会自动配置媒体服务。

## 对话与工具

`@` 插入服务器项目文件路径；附件、粘贴和拖放上传浏览器提供的文件。持久线程支持 DOCX、XLSX、PPTX 和 PDF 原件，每份最多 20 MiB、每条最多五份；上传后输入总结、分析等任务，Agent 按需读取，文件卡片可下载原件。读取范围、公式与扫描页限制见[办公附件](COMPOSER_TOOLS.md#上传办公文档与-pdf)。运行时可在加号菜单选择“引导”或“后续”：空草稿显示停止，有文字、引用或附件时显示发送。

在“设置 → 使用偏好 → 消息显示”选择：

| 视图 | 显示方式 |
|---|---|
| 简洁 | 每轮保留最终回复，执行过程可展开 |
| 正文 | 显示每条回复，合并思考和工具记录 |
| 完整记录 | 逐条查看过程，适合排障 |

工具参数和输出需展开后才能用浏览器页内查找搜索。长行内代码自动换行，代码块和宽公式在自身区域滚动；公式无法解析或超预算时保留原文。长用户消息可展开，复制仍取得完整文本。回复时间来自原生消息记录，不一定是完成时间。

`!命令` 执行服务器 Shell；`!!命令`不进入后续模型上下文，但仍保留原生执行记录。项目范围不是工具沙箱，只安装可信扩展。超时、断线或停止／取回结果不明时先核对状态，勿重复发送；停止不会撤销已发生的文件修改或外部请求。

临时线程不保存会话文件，刷新或断开后结束。详见[输入与命令](COMPOSER_TOOLS.md)、[Shell](WEB_SHELL.md)和[运行控制](NATIVE_CONTROLS.md)。

### 语音输入

点击麦克风录音，再点结束并转录；文字加入可编辑草稿，由你发送。录音最多两分钟，需要 HTTPS 或 localhost 和浏览器许可；音频会上传所选服务并可能收费，失败不自动重试。未配置时通过“去配置”进入“模型与能力 → 语音 → ASR”。见[语音转录](COMPOSER_TOOLS.md#语音转录)。

## 任务进度卡

多步骤任务可显示输入框上方的“当前进度”，点击展开步骤，也可直接让 Agent 创建或更新计划。进度由 Agent 报告，不表示系统已验证；停止或回复结束不会自动完成剩余步骤。持久线程刷新后按当前分支恢复计划，侧聊不提供此卡片。

## 使用子 Agent

可以明确让主 Agent 委派任务。输入框上方的“子 Agent”面板显示状态、模型、工具和用量，并提供引导、停止及符合条件运行的继续入口。结果和请示默认折叠，点击查看全文；操作是否可用由实际运行状态决定，结果不明时先核对。

子 Agent 随 Pivane 内置，无需另装。全局／项目默认模型和角色覆盖在“设置 → 模型与能力”保存；角色覆盖不会创建角色定义，保存不会改变正在执行的任务，空闲后重开运行实例生效。详见[内置能力](BUNDLED_CAPABILITIES.md)。

后台工作未结束时会显示“会话保持中”：关闭网页不会停止这些任务，维护和重启也须等待。需要结束时使用对应运行的停止入口。

## Agent 新建任务线程

说“新开一个线程做这件事”，Agent 可创建同项目的持久任务线程并立即执行。可指定模型与思考等级，省略时使用新线程默认值。结果回执返回来源线程，但不自动唤醒它；停止原线程不会停止新线程。

创建结果不明时先查原任务，勿重复创建。多个线程共享项目文件，应明确各自修改范围。详见[任务线程](AGENT_THREADS.md)。

### 线程之间直接沟通

可让 Agent 联系同项目其他线程，对方空闲时处理，关闭时也可被唤醒；“仅留言”不主动唤醒。连续自动往返达到上限后仅投递，等待用户继续。Agent 消息标明来源，不是新的用户授权。见[线程间消息](AGENT_THREADS.md#线程间消息)。

## 可选助手身份

在“助手身份”创建身份，编辑 SOUL（行为）、USER（偏好）和 MEMORY（长期记忆）；随后到“助手对话”选择身份、项目分类和线程。普通 Pi Agent 新线程不绑定身份。

分类可复用同一服务器目录，附加不同指令；**文件、AGENTS.md 和按物理目录划分的记忆仍共享**，身份不是安全沙箱。打开已有线程不会改变其原身份。分类整理、起草和保存限制见[助手身份](AGENT_PROFILES.md)。

### 记忆学习的提示与反馈

- 在“学习与技能”管理记忆、已学习技能、删除记录和撤销。保存反馈区分已保存与索引待同步；保存不代表当前会话已加载或模型一定遵守。
- 聊天中的“已记住／Agent 记下／学会技能”卡片可查看回执，并按条目支持的操作撤销、纠错或编辑。技能启用后需空闲重载会话。
- 后台学习默认关闭，需要专用辅助模型。缺模型、额度用完、记忆满和失败状态会明确显示，不自动改用主聊天模型。
- “整理合并”先生成方案，用户逐组检查并应用；不会自动删除旧内容。已变更条目的旧方案不能覆盖新版本。
- 从聊天入口进入项目记忆管理时核对当前会话目录；无法核实范围时只读。

明确纠错和长期偏好可被学习，“只这一次”可排除；支持自定义触发词。记忆与技能会拦截疑似凭据和提示词注入，凭据应由模型设置或密钥管理工具保存。学习开关、预算、迁移与恢复见[记忆说明](PROFILE_MEMORY.md#background-learning)。

## 自定义系统提示词

在“设置 → 系统提示词”选择所有项目或当前项目，编辑、预览并保存要求；对话空闲后点击“更新当前对话”加载。**项目要求替代通用要求，不会自动叠加**，项目范围受信任设置限制。

“查看当前对话”显示实际提示词及来源。保存不打断任务，网页刷新也不保证重载；冲突或结果不明时先刷新并比较草稿。详见[原生提示词配置](NATIVE_SETTINGS.md#系统提示词查看与编辑)。

## 扩展、精选与已安装资源

桌面打开“扩展”，手机从“更多功能 → 扩展”进入：

- **发现**：查看能力、来源和依赖；“了解与配置”把需求放入独立扩展助手草稿，由你发送。打开卡片不会安装或调用模型。
- **已安装**：按 Packages、技能、扩展模块、模板或主题筛选。启用／停用在行内，更新、移除和恢复继承在 `⋯` 菜单；安装须核对来源、范围和代码执行影响。
- **MCP**：编辑全局或受信项目配置，保存与连接／重载分开；凭据默认保留，替换和删除须明确操作。查看状态、重连和 OAuth 使用已打开的持久线程。

已安装不等于当前会话已加载；配置完成后空闲重载并核对。项目未受信时不能写项目配置。旧 MCP 适配器迁移须停机备份，详见[MCP](MCP.md)与[原生资源管理](NATIVE_SETTINGS.md)。

加号 → “添加能力…”可让扩展助手帮助安装或排障；包操作通过网页确认，工具运行在部署机器。桌面控制扩展不会直接控制访问网页的手机。只选择可信来源，第三方能力还需自己的依赖和权限。

## 定时任务

从“定时任务”安排周期或单次工作，目标为指定线程或身份主线程；也可从输入区加号创建当前线程任务。核对时区、下一次执行、预算与错过处理后启用。

暂停计划和停止本次运行是不同操作。服务器须持续运行；忙时等待、不确定结果先核对。详见[定时任务与主线程](SCHEDULED_TASKS.md)。

## 会话列表显示

线程列表显示标题和状态，鼠标悬停可看完整标题及可用统计。“空闲”不表示运行实例已释放；需要主动退出时，在对应线程使用 `/quit`。切换线程不会立即停止 worker。

## 项目与线程归档

在项目或线程菜单归档，再从“已归档”分组查看或恢复。两种归档互相独立，只整理显示，不删除数据、不停止任务。动态视图仍提示归档线程的运行与新结果；搜索旧内容时勾选“包含已归档”。

## 移动线程到其他项目

线程菜单 → “移动到项目…” → “检查并预览” → “确认移动”。目标为服务器目录，空项目可手动输入。移动保留会话 ID、完整历史与书签；后续工具使用目标目录，项目文件不会随线程搬移。

仅支持满足条件的空闲普通持久线程；助手绑定、任务关系、调度或后台工作等阻碍在预览中列出。失败或结果不明时先查两边状态，不自动重试。详见[移动与恢复边界](SESSION_WORKFLOWS.md#移动线程到其他项目)。

## 会话标题

新建未命名线程可在首轮有效问答后自动命名，已有历史和手动标题不被覆盖。线程菜单的“重新生成标题”先给建议，编辑并保存后才改名；也可直接重命名。

标题生成发送有界问答摘录给所选服务，会产生额外用量且不计入持久聊天统计。自动开关与专用模型在辅助模型中配置。

## 辅助模型

“设置 → 使用偏好 → 辅助模型”按用途选择标题、媒体规划及后台学习模型。标题“自动”跟随线程；媒体“自动”按页面说明选择；后台学习需要专用模型。显式模型不可用或失败时不自动换模型，保存设置不执行请求。见[辅助模型](AUXILIARY_MODELS.md)。

## 历史、文件与侧聊

**历史**可搜索、加书签、查看树、分叉和恢复对话位置。恢复历史**不会撤销文件、命令或外部请求**。HTML 导出用于阅读，JSONL 导出当前活动分支；完整会话树应通过停机备份保留。见[历史](HISTORY.md)、[工作流](SESSION_WORKFLOWS.md)和[导入导出](SESSION_TRANSFER.md)。

**文件**可浏览项目目录、搜索路径并查看当前内容，不自动送给模型。“本轮文件”的历史差异、“当前文件”和“交付物”的固定版本是不同来源。桌面可展开阅读区；全屏阅读支持 Esc／返回侧栏，保留 PDF 页码、缩放和表格分页。图片及 SVG 支持拖动、滚轮和双指缩放；音频不自动播放。单文件限额 16 MiB，隐藏文件开关不放开私密路径。自包含 HTML 默认隔离静态预览，仅对可信页面启用交互；隔离不保证完全断网。需要稳定下载时请 Agent 用 `deliver_files` 交付成果。见[文件与交付物](FILE_VIEWER.md)。

**侧聊**用于围绕当前背景另开讨论，首次发送冻结主聊背景；可单独选模型，读写当前项目文件。修改与命令需要侧聊内本次回复的执行确认，主侧共享目录，应避免同时改同一文件。空闲 12 小时释放运行资源；更新背景可保留本页旧段供阅读，但新 Agent 不继承旧讨论。刷新、关页和退出登录结束临时侧聊，重要内容先复制回主聊。见[侧聊](SIDE_CHAT.md)。

## 选中文字继续讨论

选中主聊或侧聊正文，选择“加入主对话”“在侧聊中提问”或“朗读选区”。引用加入草稿，不自动发送；手机仍可使用系统复制。未发送引用刷新后不保留，朗读可能收费。见[输入与引用](COMPOSER_TOOLS.md#选中文字提问)。

## 在聊天里生成图片、视频和语音

配置媒体模型后，直接说“给报告画张封面”或“把这段话配成语音”。Agent 放置生成卡片，**出现卡片尚未生成或收费，点击确认后才执行**。

- 可先修改参数；服务器调整了参数时会再请你核对。
- 结果显示在卡片及实验室历史中，离页、重连和换设备后继续同步，同一卡片不会重复提交。
- 同时确认多张卡片会按名额排队，可取消尚未开始的项；远端最多 4 项（视频 2 项），本地后端 1 项。
- 超时可能意味着服务商仍处理并计费。先核对历史与远端任务；失败或不确定结果不自动重试，再生成需重新确认。

侧聊不提供生成卡片。详细用法见[媒体实验室](MEDIA_LAB.md)。

## 多媒体实验室

新安装没有默认可执行媒体服务。在“模型与能力”或实验室添加服务地址、凭据、模型与其支持的协议；可上传参考素材、直接编辑参数，或让 Agent 帮忙规划，再检查清单并确认生成。

回复喇叭按当前朗读默认值生成语音，点击即授权该次请求，可能收费。界面语言不改变音色或朗读语言。见[媒体接入](MEDIA_CONNECTIONS.md)与[朗读](REPLY_TTS.md)。

## 网络与访问

“设置 → 网络与访问”管理登录验证、监听范围和代理。监听／代理分别保存，安全重启服务后生效；保存不会重启或开放防火墙。先启用登录验证再开放其他设备访问；代理地址的 localhost 指服务器。见[网络与访问](ACCESS_CONTROL.md)。

## 外观与字体大小

在“使用偏好 → 外观”选择主题、跟随系统或字号，即时生效并保存在当前浏览器；其他设备独立设置。浏览器缩放仍可使用，手机输入字号不低于 16px。

## 界面语言

支持简体中文和英文，默认跟随浏览器，未匹配时回退英文。在“使用偏好”修改后，下次打开或刷新生效；刷新前保留草稿、附件和侧聊内容。语言设置不翻译对话、文件和自定义名称，也不改变模型请求或朗读语言。见[界面语言](I18N.md)。

## 找不到其他项目目录

项目选择器受服务器 `PI_PROJECT_ROOTS` 和系统权限限制，不要求项目放在 Documents，也不能选择访问设备的本地目录。网页不能修改范围，应在启动配置中调整，空闲重启后生效；无需为此迁移会话。见[目录范围排障](INSTALL_RECOVERY.md#项目选择器找不到目录)。

## 版本与更新

“设置 → 版本与更新”检查 Pivane 和 Pi 版本，不自动安装。需要更新时复制独立 Agent 提示词，在部署机器由另一个 Agent 核对兼容性、备份和方案后执行；承载当前会话的服务不能由本会话直接停止。Pi 与 Pivane 成组升级。见[更新](UPDATES.md)。

## 管理与排障

- 用量来自持久会话和支持的侧聊记录，费用为估算，不等同供应商账单；标题、普通临时会话和媒体规划等范围见[用量](USAGE.md)。
- 配置保存通常不改变已打开的运行实例。需要重载时先结束工作；网页刷新可能仍连接同一 worker。
