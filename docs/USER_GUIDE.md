# Pivane 用户指南

Pivane运行在你部署它的电脑或服务器上。浏览器可以在另一台设备上打开；项目目录、Shell和Agent工具使用的是服务器文件系统。

## 首次开始

1. 按[安装指南](INSTALL_RECOVERY.md)启动独立实例，打开启动日志中的网址。
2. 进入“设置 → 供应商与模型”，选择服务并完成API Key或OAuth登录。不要把Key发到聊天中。远程OAuth的localhost回调指服务器，按提供的设备码/手动回调步骤处理。
3. 关闭设置后选择服务器项目目录，新建线程，选模型与思考等级。已打开线程会在空闲时刷新模型目录；没有可用模型时使用页面上的设置引导。
4. 发送一个简单问题；刷新页面，核对持久线程和回复仍可打开。这个请求会使用你自己的供应商账户。

没有选择项目时，可以先管理全局Pi配置、Packages和Skills。`@`插入服务器项目文件路径；附件按钮、粘贴和拖放则读取浏览器提供的真实文件，两者用途不同。

## 对话与工具

正文视图默认折叠连续思考和工具记录，完整记录可逐项检查；浏览器会记住你的选择。运行中可以发送引导/后续消息，也可以停止。超时或断线时先核对线程状态，避免重复发送。

主输入框`!命令`执行服务器Shell，`!!命令`排除后续模型上下文但仍保留原生执行记录。工具使用当前系统用户权限，项目选择范围不构成沙箱。只安装你信任的Packages/扩展/Skills。

临时线程刷新或断开后结束，不保存会话文件。未发送草稿和附件只存在于当前页面，刷新或关闭前自行保留。

## 历史、文件与侧聊

历史页可以搜索、保存书签和查看会话树。导航、编辑重试和恢复旧版本改变对话位置，**不会撤销文件、命令或外部请求**。复制/分叉创建新线程；HTML适合阅读，JSONL导出只含当前活动分支，完整备份仍需停机保存数据目录。

每轮成功的edit/write会形成文件列表。差异是原生操作记录；当时的写入内容和“当前文件”是不同来源，当前磁盘内容需要显式读取或刷新。长代码、公式与图表可在各自区域查看。

侧聊默认冻结主线程的有效背景，没有工具，可独立讨论再显式追加到主草稿。本页切换持久线程可保留有限段侧聊；刷新、关页和退出登录会结束它们。

## 多媒体实验室

新安装没有默认可执行的图像/视频/语音服务。在“设置 → 媒体模型”或实验室管理入口添加服务地址、Key和模型ID；按实际文档选择协议。聊天模型的凭据不代表媒体服务自动可用。

填写创作要求，让Agent生成方案或直接编辑常用参数；检查提交清单后确认单项生成。方案、连接探测和生成是不同操作。失败或结果不确定时先检查服务端任务和历史，不自动重试。回复旁的喇叭点击会按当前默认语音配置生成这一条朗读，可能收费。

## 管理与排障

用量统计读取持久会话中的原生记录，费用是历史配置估算，不等于供应商账单；临时会话、侧聊和媒体规划不纳入该持久统计。配置保存通常对新运行实例生效，已有任务不会因此被自动停止。

本机通知可使用浏览器页面通知/提示音；手机后台推送需要HTTPS和系统支持。开启远程入口前检查访问验证。升级或备份前暂停预约并停止任务，再按[安装与恢复](INSTALL_RECOVERY.md)停机操作。

更多功能与接口见[文档目录](README.md)。让Agent排障时使用[操作指南](AGENT_GUIDE.md)，提供脱敏错误与实例路径，不提供凭据正文。
