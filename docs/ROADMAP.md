# Pivane 路线图

本页记录产品方向。已发布能力以 [Releases](https://github.com/YogurtJ/pivane/releases) 和对应版本说明为准；当前源码中尚未发布的改动见 [CHANGELOG](../CHANGELOG.md)。源码完成、维护实例已启用和公开版本已发布分别核对。

## 已有能力

- 原生 Pi 会话与唯一受管 worker；浏览器流式回复、附件、工具、停止、压缩、运行恢复与手动 Shell。
- 供应商认证、动态模型与思考等级、原生设置、Packages/Skills、扩展中心、扩展助手与项目信任。
- 项目与线程管理、搜索、书签、会话树、分叉、重试、导入导出、归档、标题与延迟消息。
- Agent 任务线程、临时侧聊及本次回复确认后的工具操作、选区提问、文件阅读、数学公式、图表、用量与朗读。
- 媒体模型自配置、HTTP 协议、参数规划、单项确认执行与生成历史。
- 中英文界面、响应式布局、后台常驻安装、Pi 与 Pivane 应用更新、停机备份和原路径恢复。

公开下载、反馈入口和带校验值的 RC 发行已经建立。平台范围及每个版本的验证见 [平台说明](RELEASE_INSTALL_VALIDATION.md)；跨平台实现不代表每次发布都完成各平台实机验收。

## 当前工程方向

- 连续的源码 Git 主线与独立私有维护资料，明确源码、运行版本和发布包的对应关系。
- 集中源码发现与生命周期规则，按职责逐步提取网关和前端协调逻辑。
- Pivane 命名与旧版本兼容；经验证的项目路径迁移和原生会话保护。
- 文档按读者与职责维护，Agent 入口简短，历史资料按需查阅。

具体已实现部分见变更记录与 [开发文档](development/README.md)。

## 后续候选方向

以下方向尚无固定日期，也不表示已具备完整实现：

- 更多真实媒体供应商、手机/Safari和原生平台验收。
- 更广的媒体协议、参考文件输入和可恢复的持久批量工作流。
- 通用的跨平台/跨身份会话树迁移、代码检查点与后台任务总览。
- 随新增功能继续收敛前端状态责任和旧媒体入口，避免维护多个同义状态。

个人实例继续使用自己的身份和数据。项目目录范围不是工具沙箱，规划不授予执行权，失败或不确定操作不自动重放；会话历史仍以 Pi 原生记录为准。
