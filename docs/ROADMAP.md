# Pivane 路线图

本页记录产品方向。已发布能力以 [Releases](https://github.com/YogurtJ/pivane/releases) 和对应版本说明为准；当前源码中尚未发布的改动见 [CHANGELOG](../CHANGELOG.md)。源码完成、实例已启用和公开版本已发布分别核对。

## 已有能力

- 原生 Pi 会话与唯一受管 worker；浏览器流式回复、附件、工具、停止、压缩、运行恢复与手动 Shell。
- 供应商认证、动态模型与思考等级、原生设置与系统提示词、扩展中心、扩展助手与项目信任；原生 MCP、Codemode 与 Tool Search。
- 项目与线程管理、搜索、书签、会话树、分叉、重试、导入导出、归档、标题与延迟消息；简洁消息视图与轮次摘要。
- Agent 任务线程与线程间消息、任务进度卡、内置子 Agent、临时侧聊及本次确认的工具操作。
- 助手身份与独立工作区、可管理的档案记忆与可选后台学习。
- 定时任务与身份主线程；文件浏览、受管交付物，图片、PDF、CSV/TSV、SVG、音频与隔离 HTML 预览，数学公式、图表、用量、朗读与语音输入。
- 媒体服务与模型配置、参考图／视频、可选参数规划、聊天生成卡片、确认后排队执行与生成历史。
- 中英文界面、主题与字号、响应式布局、网络与访问设置、后台常驻安装、版本检查、独立 Agent 更新提示和原路径备份恢复。

平台范围及每个版本的验证见 [平台说明](RELEASE_INSTALL_VALIDATION.md)；跨平台实现不代表每次发布都完成各平台实机验收。

## 当前工程方向

- 跟随 Pi 更新，成组验证 Pivane 适配与依赖。
- 按职责逐步收敛前端协调逻辑与旧媒体入口，理由和约束见 [架构 · 设计取舍与已知技术债](development/ARCHITECTURE.md#设计取舍与已知技术债)。
- 长会话与大项目下的列表、任务目录、索引与首开性能持续测量。

## 后续候选方向

以下方向尚无固定日期，也不表示已具备完整实现：

- 更多真实媒体供应商、手机/Safari 和原生平台验收。
- 更广的媒体协议和可恢复的持久批量工作流。
- 通用的跨平台/跨身份会话树迁移、代码检查点与后台任务总览。
