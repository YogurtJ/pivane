# 中英文界面与浏览器语言

当前源码的一套界面提供简体中文与英文，不拆分安装包或服务。用户入口见[用户指南](USER_GUIDE.md)、[英文用户指南](en/USER_GUIDE.md)。已发布1.0.0-rc.1归档早于此改动，固定发布资产未替换。

## 选择与生效

设置 → 使用偏好 → 界面语言提供 `system`（跟随浏览器）、`zh-CN`（简体中文）、`en`（English）。偏好保存在当前来源的浏览器 `localStorage['pi.workspace.language']`，不新增服务器用户、配置接口或会话存储。

没有有效显式偏好时，按 `navigator.languages` 顺序匹配首个受支持语言，缺失时读取 `navigator.language`。`zh`及其地区/脚本变体使用简体中文，`en`及其变体使用英文；没有匹配时使用英文。浏览器通常继承操作系统语言，但也允许用户独立配置，因此不根据服务器语言、时区或IP判断。

一页打开时确定语言，并在本页生命周期内保持一致。保存选择、其他标签页修改偏好或浏览器语言变化只更新设置说明；下次打开/刷新页面才应用。不会自动刷新或重新渲染正在编辑的表单，不发消息、不改变模型、不重连/停止worker、不结束临时侧聊。用户手动刷新前需保留草稿与附件，刷新导致的临时状态丢失沿用原有生命周期。

读取浏览器存储失败时按浏览器语言显示；保存失败明确提示，不能假报已保存。选择不跨浏览器/设备同步，清理站点存储会恢复自动选择。

## 展示范围

当前界面的静态文字、标题、按钮、可访问名称、占位提示，以及聊天控制、项目线程、历史/树、文件查看、侧聊、Shell、附件、媒体表单、提交确认、设置和已知应用消息接入词典。原生设置字段仍由服务端schema决定，网页只翻译已知显示标签；不写死工具/模型候选项，也不替换协议值。日期与数字的显示使用当前界面语言，查询日期和时区语义不变。

以下保留原文：

- 用户和模型消息、思考与工具正文、文件内容和路径、会话/模型/服务自定义名称。
- 已保存提示词、模板、Skill内容、媒体参数值及服务要求。新建模板时的内置示例使用页面语言，保存过的模板不被迁移。
- 未收录的上游、第三方和部分诊断文字；错误翻译只识别明确的已知消息，不对任意文本模糊替换。
- 后台Web Push仍使用服务器原有通用文字；页面提醒跟随本页语言。旧媒体界面和完整高级/开发文档不属于首轮翻译范围。

界面语言不隐式设置模型回复语言、不向模型请求附加语言指令，也不修改语音模型、voice、language或其他生成参数。英文README、安装和用户指南提供完整入门路径，详细文档仍可链接中文契约。

## 源码约定

`public/pi-i18n-catalog.js`保存成对的中文源文案与英文译文；`public/pi-i18n.js`提供 `PiI18n.t(source, ...values)`、语言协商、静态绑定和本地偏好。新增文案追加到词典，不重排已有条目：静态HTML注释 `<!--i18n:s编号-->` 与 `data-i18n-title/aria-label/placeholder/alt` 使用这些稳定编号。

静态绑定只处理明确标记的应用文字节点或属性，不包装额外布局元素。动态文字在源代码的显示位置显式调用 `translateUi`，完整句子使用 `{0}` 等参数占位符，参数按原值插入且不递归解释。各独立模块保留无国际化宿主时的中文格式化回退，以兼容旧入口及独立测试。

没有扫描并替换聊天DOM的MutationObserver，没有修改 `innerHTML`/`textContent` 原型，也不在运行时请求翻译服务。词典本身不携带HTML；原有HTML模板中的动态值继续在调用位置转义，用户/工具正文继续使用安全DOM或marked + DOMPurify。翻译API返回文本，不是HTML清理器，不可用它替代转义。

新脚本由现有静态JS允许清单与发布目录规则包含。REST/WebSocket响应和Pi原生JSONL格式不变；服务端返回的文字在明确展示边界按词典翻译，未知内容保持原样。

## 验证

`test/pi-i18n.test.js`检查浏览器语言优先级、显式偏好、无存储权限、页面语言稳定、占位符、重复/缺失词条和静态绑定。原中文浏览器用例显式声明 `zh-CN`，不再依赖宿主默认语言。

`test/browser/pi-i18n.cjs`启动独立静态服务并拦截所有API/WebSocket，使用合成项目、会话、附件与媒体清单，检查中英文在320/393/768/1440宽度的静态/动态显示、实际子项宽度、抽屉、设置、原生schema、工具与附件状态、媒体review、参数与原始正文保留。语言保存不能新增网络写入、发送消息或执行生成。截图只含合成数据，输出到系统临时目录。

这些浏览器模拟不等于macOS/Windows原生部署、Safari或真实媒体供应商验收；发行验收仍绑定实际候选包与SHA256。
