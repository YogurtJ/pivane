# 成果中心

成果中心入口为侧栏「成果」（手机「更多功能」），路由 `#/artifacts`。它提供独立保存、星标、合集、项目标签、批量管理和安全预览，不是项目文件浏览器。

支持通过局域网 HTTP 地址访问（例如 `http://服务器局域网IP:11408`）：保存、星标、合集、回收站及永久删除均可使用。浏览器未提供 `crypto.randomUUID()` 时，操作标识由 HTTP 页面可用的 Web Crypto 随机数生成；丢失响应仍只查询原操作结果，不自动重发。

## 会话与成果分开

**会话负责交流，成果库负责保存。删除会话，不删除已经保存到成果库的成果；删除成果，也不删除来源会话或原文件。**

界面明确区分：

- **待保存**：发现的交付快照或媒体历史。依赖当前会话分支／媒体历史，不是独立保存。
- **已保存**：点击「保存」后，原始字节复制到身份私有成果库。成果 ID 在保存期间稳定；重启、来源文件改变、来源会话删除或媒体历史删除均不影响库内文件。
- **星标**（原「收藏」）：用于快速查找常用成果。「保存并加星标」会先保留独立副本；取消星标不删除文件。原有星标和分组直接沿用，不迁移用户数据。
- 来源项目／会话只记录追溯信息，不再作为已入库文件的读取授权。来源消失时「返回来源会话」提示不可用，预览和下载继续可用。不猜测旧媒体的来源会话。

已有交付和媒体历史**不自动全量迁移**。清理旧会话前，请先选中需要保留的文件保存。删除线程确认框会提示此区别。旧 `#pi-delivery=...` 链接仍沿用原生分支授权，不因新成果库改为永久公开链接；独立保存结果在成果中心访问。

## 来源与收录

默认进入「已保存」，只展示独立文件。「待保存」单独展示预算内发现、尚未入库的来源：

- 当前合法原生分支的 `deliver_files` 交付。多格式交付仍按明确交付组显示，详情切换文件；保存或多选可针对组内具体文件。
- 现有图片／视频／音频生成历史。旧历史缺少可靠项目归属时显示「无项目标签」，不从提示词、文件名或供应商任务 ID 推测。
- 不根据聊天路径抓取，不自动收录源码改动、参考附件、日志、临时文件或未登记的回复朗读。

首页不展开历史提示词和生成参数。所有保存动作在重新验权并取得完整原字节后进行，不扫描内部交付对象来绕过会话分支。

## 星标、合集与整理

顶部视图为「已保存」「星标」「待保存」（带数量；待保存有数量时高亮），「回收站」「已隐藏」作为次要视图靠右。标题旁的问号说明保存、星标、合集与删除的区别；右上角显示成果库已用容量、刷新和「去创作」。工具栏依次为搜索（桌面按 `/` 聚焦）、类型、项目与合集两个下拉按钮和「选择」。生效的筛选在网格上方显示为可逐个移除的标签，并给出结果数；当前合集标签的「⋯」可重命名或删除合集，合集下拉末项可直接新建合集。

- **合集**（原「收藏夹」）按主题或用途分组，**不是磁盘目录，也不同于星标**。可创建、重命名、删除；一个文件可加入多个合集。删除合集／移出合集只移除分类，不删除文件或星标。加入时可直接新建合集。
- **成果重命名**修改库内显示及导出文件名，原文件名保留。不可输入路径、控制字符或平台保留名。不改磁盘原件、预览类型或旧交付链接。
- **设置项目标签**放在「更多操作」，只修改成果筛选标签，不保存文件到项目目录、不改来源信息、会话 cwd 或 Agent 权限。可设为「无项目标签」。
- **文件信息**显示独立副本位置、记录的原文件位置和来源会话。原文件路径是历史记录，不保证该原件仍存在；不会暴露原生会话 JSONL 路径、凭据或生成参数。
- **下载到设备**位于预览常用操作区，由浏览器下载完整原字节到当前电脑／手机。
- **导出到服务器文件夹**位于「更多操作」，在运行 Pivane 的服务器上复制原字节到现有允许目录，不是下载到当前设备；成果库仍保留独立版本。只创建新文件，不覆盖同名文件，不递归创建目录，不删除／移动原件，拒绝重定向目录与私密目录。不同平台未实机验收时不宣称通过。

卡片以封面区分类型：图片显示缩略图，文档、网页、音频、视频使用对应的示意封面并标出扩展名，多文件交付显示叠放和文件数。桌面悬停时显示角标选择框与星标；已加星标的卡片常显星标。待保存卡片直接提供「保存」，回收站卡片提供「恢复」，已隐藏卡片提供「取消隐藏」。

「选择」进入批量模式，也可以点卡片角上的选择框、按 Ctrl/⌘ 点卡片，或在手机上长按卡片开始选择；「完成」、操作栏的关闭按钮或 Escape 退出。多格式交付点卡片选整组，选择模式下卡片内的文件标签可逐个选择；桌面 Shift 连选，Ctrl/⌘+A 全选本页，Delete 打开删除确认。「全选本页」只选择已显示页、最多 50 文件；换页、改变搜索／类型／视图时清除选择，避免操作看不到的文件。

操作栏悬浮在页面底部，未选择时只显示提示，不铺开禁用按钮。待保存提供保存、保存并加星标、加入合集；已保存和星标提供星标、加入合集、删除，移出此合集／项目标签／导出／隐藏／移到回收站收进「更多操作」；已隐藏提供取消隐藏、加入合集、删除；回收站提供恢复和永久删除。星标按选中状态显示加星标或取消星标，移出合集只在当前合集内出现。全部成功后退出选择模式；部分失败保留失败项选择并逐项解释。

操作进行中，相关卡片显示处理状态，操作栏显示「正在处理」。完成后在页面底部弹出提示：保存、恢复提供「查看」；星标、合集、隐藏、移到回收站提供「撤销」。撤销是用户再次点击发起的新请求，使用最新修订，不重放原请求；涉及待保存文件时不提供撤销。打开详情时提示显示在详情之上。

每次最多 50 文件，批量保存／导出／永久删除校验预算 128 MiB（分别按源读取、导出或删除校验的文件大小计费；写后哈希验证另读同等字节）。逐项返回结果，不把部分失败当成整体成功。

批量写入先登记独占请求标识，客户端断线不提前释放真实操作。丢失响应通过操作状态查询核对，**不自动重发写请求**。持久操作记录至多 10000 项，到上限须管理员整理，不能把旧请求默默当新操作。

## 成果删除与恢复

- 「隐藏」只从普通视图移出，可在「已隐藏」恢复，完成提示可撤销。
- **删除**位于已保存成果的操作栏、详情顶部和回收站。确认框列出文件名、说明不可恢复和影响范围，提供「移到回收站」与「永久删除」两种选择，不需要输入文字；回收站中的文件和删除待核对的文件只提供永久删除。所有永久删除都经过这个确认。
- 「移到回收站」只标记库内副本，可在回收站恢复，完成提示可撤销。也可从详情或操作栏的「更多操作」直接移到回收站。界面不向待保存结果提供删除；兼容 API 对未入库结果的 trash 仍会先保存副本。
- 回收站不自动过期清空，仍占用成果库额度。详情不发起被拒绝的预览；恢复后才能预览／下载。
- 永久删除时服务端要求 `confirmed=true`、精确库 ID 和当前修订，可直接删除已保存、星标或已隐藏的条目，不要求先移到回收站；验证真实父目录／文件描述符、完整身份、大小和哈希后删除库内字节，并释放额度。
- 永久删除**不删除来源聊天、旧交付快照、媒体历史、原文件、已导出副本或既有备份**，不是磁盘安全擦除。保留不含文件正文的操作记录与最多 10000 个来源哈希标记，避免原来源马上在待保存中重新出现。若再次通过合法来源显式保存，会获得新的库 ID，旧链接和旧请求不能操作新副本。
- 删除前持久记录意图（未在回收站的条目同时标记为已移入回收站），崩溃／失败后不会自动重放；未完成条目出现在回收站并标记「删除待核对」，不能恢复成丢失字节的文件，只能核对后再次明确确认删除。
- 不提供自动清空回收站、物理移动原件、批量改磁盘名、主动上传任意文件或自动收录新生成结果。

## 浏览与安全预览

每页最多 36 张卡片，图片封面懒加载，最多保留 36 个封面 Blob。首次加载显示占位卡片。独立详情从右侧滑出（手机全屏），不占聊天右栏，不自动播放音视频。详情顶部集中显示类型、大小、项目和保存时间，以及保存／恢复、星标、下载到设备、删除和「更多操作」（加入合集、重命名、项目标签、返回来源会话、文件信息、导出到服务器、隐藏、移到回收站）；所属合集以标签显示，可直接移出或加入。尚未保存的结果显示提醒；多文件交付用文件标签切换，已保存的文件带勾。Markdown 以阅读版式呈现，Markdown／HTML／SVG／表格可切换「预览／源码」；读取失败显示原因与重试。「文件信息」可复制服务器路径与来源会话。Markdown、文本、HTML、图片、SVG、PDF、CSV/TSV、受支持音频、MP4 可预览；其他格式提供下载。

HTML 默认无权限 sandbox＋限制 CSP：不运行脚本、加载外部资源、提交表单或导航外部 frame。Markdown 经 marked＋DOMPurify，SVG 净化后作为图片，CSV 按文本展示不执行公式。下载重新读取完整原字节，不下载净化后的预览。离页取消读取并释放播放器、PDF 任务和对象 URL。

来源发现按预算工作，搜索／类型筛选作用于已加载结果。「部分结果」不表示其余成果不存在；可按项目或从会话入口限定 `cwd/sessionId`。已保存列表独立分页，不依赖来源发现成功。

## 预算、资格与接口

独立存储位于身份私有目录的 `pivane-artifacts/`，不在会话目录下。库内总上限 4 GiB／10000 文件（含回收站），单文件 64 MiB。不可变字节具备哈希、大小、真实描述符路径与完整身份校验；整理信息原子保存并带修订。该目录由现有身份根备份覆盖，源码发现和 Git 明确排除，不作为静态目录开放。没有第二份聊天正文或媒体历史。

目录 `catalog.json` 的读写上限均为实际 UTF-8 字节 16 MiB，独立操作记录为 1 MiB；预算包含 JSON 缩进与末尾换行，超限时在替换前拒绝并保留旧文件。新目录中的操作只保留 id、参数摘要和时间，完整结果留在既有 `operations/<requestId>.json`，不会因每次返回全部文件／合集而反复膨胀目录。目录摘要仍保留最近 200 项，离开此窗口不删除独立操作回执，也不允许同一请求重新执行；完成回执保存失败时保留 pending／noReplay 证据。

旧目录内已有的完整结果继续可读，不自动删除或压缩历史。已经超过读取上限的旧库仍会明确拒绝读取，不能通过提高在线读取额度或清空 operations 绕过；应先在维护窗口保存完整私有备份，再核对冗余结果与独立回执，制作并验证限定范围的恢复候选。当前版本没有自动迁移或自动修复入口。

来源发现最多 300 会话目录、800 会话文件、12000 条目、128 MiB 会话字节、单会话 32 MiB，循环约 8 秒，外层 Worker 12 秒超时后等待终止。媒体每类历史 JSON 16 MiB／最多 300 条。每批最多 8 会话、每候选最近 40 交付清单，最多返回 200 文件。成果会话证明字节预算 96 MiB，读取前预占（含前后验证和 EOF），失败不返还；已有迁移 `deliveryProof` 单会话 64 MiB／前缀哈希合计 256 MiB 为独立边界。源交付每文件仍限 16 MiB，媒体 64 MiB，cover 2 MiB。两项并发操作，写入独占；操作参与维护空闲、迁移互斥与真实停机等待。

接口均在登录／同源校验后，返回 `no-store`、`nosniff`、sandbox CSP 的 JSON：

- `GET /api/pi/artifacts?cwd?&sessionId?&snapshot?&offset?`：待保存来源目录；旧字段保持，snapshot 2 分钟／最多 4，source key 定位 15 分钟／最多 3000，不是读取授权。
- `GET /api/pi/artifacts/library?offset?&revision?`：独立库列表、合集、项目、容量及用于防重复／已删除来源重现的 savedSources 哈希集合；每次最多 200 文件，最多 10000；分页必须保持 catalog revision，变化时刷新。
- `GET /api/pi/artifacts/:key/preview`、`/cover`：source key 重验来源；library ID 按库内状态、完整文件身份／字节读取，不依赖来源会话。
- `GET /api/pi/artifacts/:key/origin`：只返回仍可证明的来源 `{cwd,sessionId}`；来源删除不影响库内文件。
- `GET /api/pi/artifacts/:key/location`：已入库返回存储路径、记录的源路径、原文件名、追溯来源与归类；未入库先重新验权。
- `POST /api/pi/artifacts/batch`：`{requestId,action,files?:[{key,revision?}],name?,favorite?,collectionId?,cwd?,directory?,confirmed?}`。文件最多 50；库内文件用修订防陈旧操作。actions：`save|favorite|rename|collection-add|collection-remove|project|trash|restore|purge|hide|unhide|export|collection-create|collection-rename|collection-delete`。trash/purge/export/collection-delete 要求 confirmed=true；purge 还必须提供库 ID 和当前 revision，不能用 source key，可直接删除未入回收站的库条目。成功删除返回 deleted=true，不再返回 item。返回 `{requestId,results:[{key,ok,item?,exported?,deleted?,code?,error?}],collections?,error?}`；局部失败不假报整体成功。
- `GET /api/pi/artifacts/operations/:requestId`：持久写操作结果或 `{pending:true,noReplay:true}`，不自动执行。

库内 items 是独立单文件卡片，`source=library`、`independent=true`、`sourceKey`、`revision`、`favorite`、`collections`、`trashedAt`、`hiddenAt`、`savedAt`、`deletionPending`（删除待核对）；普通列表不返回绝对文件／会话存储路径。项目手动归类不赋予其他文件浏览权限。

常见错误保留 `ARTIFACT_INPUT|EXPIRED|SOURCE|SCOPE|ORIGIN|BUSY|SUSPENDED|TIMEOUT|BUDGET`，新增 `ARTIFACT_STORAGE|LIMIT|CONFLICT|CONFIRM|MISSING|INCOMPLETE|TRASHED`；既有 `DELIVERY_*`／`FILE_*` 校验错误仍有效。
