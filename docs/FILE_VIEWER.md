# 文件浏览与查看

项目文件浏览需要 `/api/pi/status.fileBrowser=true`，全文读取需要 `fileViewer=true`。仅更新前端时，旧后端仍可查看本轮写入记录与原有文件链接，并明确提示不支持项目浏览。

2026-09-11 Windows适配：文件打开拒绝末尾reparse，内核最终路径及完整卷/128位File ID共同校验，读取前后BigInt stat保留。Windows大小写敏感目录不使用大小写折叠的relative作为安全边界；ADS/设备路径拒绝。网页盘符/反斜杠/file URI/行号链接归一化为受控文件入口，不执行原生路径协议。详情见WINDOWS.md与native/README.md；Windows11 x64实际文件、路径/权限、浏览器回归已通过。

2026-09-09 实现。成功 write 的本轮文件记录属于静态展示；读取当前磁盘文件需要 `/api/pi/status.fileViewer=true`。不修改 Pi 上游，不创建文件基线或第二份会话历史。

## 使用

- 打开右侧“文件”默认进入“项目文件”：目录按需展开，文件夹优先，点击普通文件读取当前磁盘内容，不需要修改记录或启动会话 worker。空线程和仅选中项目时均可使用。
- 顶部查找按文件名／相对路径匹配，包括尚未展开的目录；搜索默认跳过隐藏项、依赖和常见构建输出目录，结果不代表 Git 跟踪清单或全文搜索。隐藏文件开关可包含普通隐藏文件，但不解除私密路径限制。依赖和输出目录可从树中手动展开。
- 目录刷新、文件刷新分别显式触发；浏览、搜索和预览不调用模型，不自动添加上下文。树支持方向键、Home/End 和 Enter；显示失败、空目录、部分结果时不伪装为完整结果。
- 每轮结束后的“本轮文件”同时列出成功 edit 和 write。edit 仍按文件保留各次原生差异；write 显示“写入 N 次”，不能仅凭 write 断定文件为新建，因为它也可能覆盖已有文件。
- 点击编辑文件默认看“差异”；只有写入的文件默认看“全文”，选中本轮最后一次成功写入的记录。多次写入可以在“内容来源”切换，混合 edit/write 的文件仍可查看两者。
- 卡片内累计新增行数 `+N` 使用主题绿色，删除行数 `−N` 使用主题红色；次数、写入和未知行数保持中性色与原有含义。默认显示前三个文件，点击“其余 N 个文件”后展开完整列表，底部显示“收起文件”，列表中间不再夹着展开入口。收起后恢复前三项及展开入口；键盘可展开、选择文件、收起，快照仍按原生 details 的页面状态恢复，不持久化展开状态。
- 全文的“写入记录 N”来自已加载原生 toolCall.arguments.content 与成功 toolResult 的关联，不读取磁盘、不随后续修改变化；它是当时的工具输入内容，不是另建的磁盘版本库。
- “当前文件”在用户首次选择时读取，读取时间和文件修改时间收在“文件信息”中。再次切回使用这次读取的快照；只有显式“刷新”重新请求，不因 Agent 结束、重连、轮询或模型文字自动读取。
- 回复中的常规相对/绝对项目文件链接可直接在同一右栏打开，支持 `path:行号`、`path:行号:列号` 和 `path#L行号`，仅定位到行。空格、中文和 URL 编码路径支持；外部 HTTP(S)、mailto、页面锚点及媒体下载等应用链接保留原行为。主回复与侧聊回复共用点击入口。
- Markdown 默认排版预览，可切换源码；带行号链接默认显示源码并定位。预览中的相对文件链接以所查看文件的目录为基准。代码/文本提供行号、常见语言高亮、换行开关和复制全文；复制使用完整原文字串，不复制行号或高亮 HTML。空文件明确显示 0 字符，禁用无内容的复制。
- 右侧页签名为“文件”，项目浏览与本轮记录共用查看器。从回复卡片打开时定位到原记录；从目录树打开时查看当前文件。原轮次／文件选择器保留为浮层，选择后收起。
- 桌面支持“展开阅读”，文件面板至少 760px 宽且已打开文件时，目录树可在预览右侧并排显示；较窄面板和手机切换浏览／阅读。“浏览项目文件”、面包屑目录和“在项目中定位”均可返回树。图片、PDF 等非文本仍显示现有不支持提示，没有新增编辑或下载接口。

## 文件面板布局

顶部提供项目文件／本轮文件切换、浏览目录与展开阅读入口。文件路径使用可滚动的面包屑，支持返回目录、复制路径和定位；轮次选择与本轮文件列表仍在浮层中，不压缩正文高度。Escape 依次关闭文件浮层、目录浏览、展开阅读，再关闭右栏，并返回相应入口。

差异/全文切换和全文来源同行，来源始终可见，明确区分当前磁盘快照与历史写入。全文操作使用一行简短按钮：刷新、源码/预览、换行、复制与文件信息。完整路径、读取/修改时间及来源说明在文件信息浮层中按需查看；加载和失败提示仍直接显示，不收进信息浮层。没有额外的大标题、常驻说明段或重复文件路径。

正文与差异区域占满剩余高度，内部滚动；当前文件没有差异或历史写入时，省去多余的来源切换行。打开目录不会重新读取正文，切回同一文件恢复阅读位置。本轮来源和请求迟到保护保留；不因轮次刷新覆盖用户正在浏览的项目文件。目录浏览需要更新后端，单独刷新旧部署的静态页面不会启用。

隔离 Chromium 使用 1440×1000、1024×768、393×852、320×740 检查既有记录；带新导航的历史全文占面板约 77%／69%／66%／60%，保留所有来源和操作控件。另以四种宽度的中英文项目树检查明暗主题、实际子项宽度、手机切换、键盘导航和迟到请求。

## 已加载记录与生命周期

仍按原生 user 消息分段，尾段等 agent_settled 后取得权威快照再显示；失败/停止保留此前成功编辑与写入。失败、孤立、调用 ID 有歧义、write 缺少字符串 content 的记录不计入；已知私密路径不新增全文入口。原始工具执行记录继续保持原逻辑。

目录展开和滚动按项目保留在本页内存，最多记忆 8 个项目、每项目 128 个展开路径；每次浏览最多缓存 80 个目录及 4000 个条目，超出后提示刷新或部分结果。查看器记忆最多 40 个文件阅读位置，切线程立即清空正文、阅读位置与请求；树保留项目展开偏好，但清空目录数据并重新校验。网页刷新不恢复这些临时状态。

文件记录、读取的当前文本、展开/选中/换行状态都只在本页内存。刷新后从仍加载的原生消息重建 write 内容；压缩/导航后缺失的记录不作为独立审计保留。切线程立即清空选择、正文和请求；来源/文件切换取消旧读取，并同时检查请求序号及主会话 key/socket generation。迟到请求不能覆盖新的写入记录或另一线程的文件。当前文件读取失败会明确显示错误并禁用复制，不把旧内容当作最新结果。

## 只读 API

`GET /api/pi/files/content?cwd=<project>&path=<relative-or-absolute-file>`

复用现有 Pi Bearer token 和 Origin 校验；不启动 worker、不要求为读取另开 session、不调用模型、不写文件或 session。只接受 cwd/path 字符串参数，最大各 4096 字符。响应为 JSON，设置 `Cache-Control: no-store` 与 `X-Content-Type-Options: nosniff`，不返回可直接运行的 HTML 文件响应。

成功字段：

```json
{
  "cwd": "/projects/example",
  "path": "docs/report.md",
  "absolutePath": "/projects/example/docs/report.md",
  "content": "# Report\n",
  "size": 9,
  "modifiedAt": "2026-09-09T06:00:00.000Z",
  "readAt": "2026-09-09T06:10:00.000Z",
  "revision": "sha256-of-file-bytes"
}
```

- 项目先由 PiSessionStore 执行 realpath/PI_PROJECT_ROOTS 检查；文件的原始绝对路径、最终 realpath 和已打开文件描述符都必须位于所选项目内。允许项目内普通软链接，越界/指向私密路径的链接拒绝；不把所有允许项目根当作当前文件链接的可访问范围。
- 拒绝 `.env` 及其变体（包括 `.env.example`）、auth/models/models-store/credentials/connections JSON 及常见备份名、SSH/证书私钥文件，以及 `.pi/.ssh/.aws/.azure/.gnupg/.config/.git/backups/.web-backups` 目录。原生 getAgentDir 和显式媒体配置目录另按真实根拒绝，即使用户改用了非默认名称。共享公开策略只含文件名规则，不包含配置内容或密钥。
- Linux/macOS通过O_NOFOLLOW/O_NONBLOCK打开、fstat核对普通文件，以共享描述符边界在读取前后核对内核报告的位置及原请求路径：Linux使用`/proc/self/fd`，macOS使用随包Node-API组件的F_GETPATH。组件与源码/manifest不匹配时拒绝，不用请求路径或仅inode检查兜底。规范路径使用系统原生realpath，保留Mac实际大小写。读取前后大小、inode、设备、mtime/ctime 不一致时报冲突，避免返回读取过程中的混合版本。该机制不构成对同一系统用户的 OS 沙箱，也不检测任意普通文件中嵌入的秘密。
- 每文件最大 2 MiB，最多 4 项并发读取；只返回完整 UTF-8 文本，保留 BOM/换行。拒绝二进制控制字符、无效编码、目录/FIFO等非普通文件。超限明确报错，不默默截断。历史 write 全文同样限制 2 MiB。
- 大于 500000 字符或 4000 行的文本使用完整纯文本展示，减少 DOM，暂不逐行高亮；高亮只处理最多 100000 字符的已知语言，不进行自动语言探测。正文仍可滚动和完整复制。

错误响应仅含 `error`、`code`，不包含文件内容或底层系统路径：400 参数无效；401/403 鉴权、项目范围、私密文件或权限拒绝；404 文件不存在；409 文件/路径读取时变化；413 超过大小限制；415 非文本/编码/非普通文件；429 并发额度满；500 其他读取失败。错误不自动重试。

## 目录与文件名搜索 API

- `GET /api/pi/files/list?cwd=<project>&path=<directory>&hidden=false`：`path` 必传，可为空字符串表示项目根，也可使用项目内相对／绝对目录；返回 `cwd/path/entries/partial`。
- `GET /api/pi/files/search?cwd=<project>&q=<query>&hidden=false`：非空 `q` 最多 200 字符，按相对路径不区分大小写的子串匹配，优先文件名命中；返回 `cwd/entries/partial`。不读取文件正文。
- 条目为 `{name,path,kind:"file"|"directory",link:boolean}`，路径使用网页斜杠；不提供 Git 状态或“新建”推断。
- `cwd/path` 最多 4096 字符；只接受列出的字段，`hidden` 可省略或为 `true/false` 字符串。两种浏览请求共用 2 并发额度，扫描每 3 秒预算内检查取消；目录最多扫描 4000 项、返回 500 项，搜索最多扫描 12000 项、返回 100 个文件、待扫描队列最多 500 个目录。命中预算或权限不完整时 `partial=true`，不自动重试。
- 搜索跳过目录符号链接及 `node_modules/vendor/dist/build/coverage/__pycache__/.next/.venv/venv`，这些是性能范围而非安全规则。普通隐藏项由 `hidden` 决定；私密路径和越界别名始终过滤。
- 使用相同鉴权、Origin、no-store/nosniff、项目 realpath 与私密根规则。父目录和每个返回条目分别打开描述符，核对内核路径、身份、对象类型和前后状态；Linux 通过已打开目录的 `/proc/self/fd` 枚举，其他平台枚举内核确认路径并逐条重新验证。目录变化报 409，不发布已收集的部分目录。系统权限拒绝保留，私密内容不返回。
- 连接关闭会取消后续扫描，不启动 worker，不写会话或项目文件。错误格式沿用全文 API，另有 `FILE_ABORTED`（499，仅内部已取消请求）。

## 渲染边界

新增精确依赖 `@highlightjs/cdn-assets@11.11.1`，脚本从本实例 `/vendor/highlight/highlight.min.js` 提供，不访问远端 CDN 获取代码或语言包。高亮结果只允许 span/class，经 DOMPurify 后再构造安全逐行 DOM；HTML/SVG/脚本文件显示源码，不执行。

Markdown 继续经过 marked + DOMPurify；文件预览额外移除图片、音视频、iframe/object/embed 和表单，不自动加载文件正文中的远端资源。源码切换可查看完整原文。文件链接由受控查看器解析后交给同一只读接口校验，不能把模型提供的链接或 `#pi-file` 标记当成权限凭证。

## 验证与部署

```bash
node --test test/pi-file-service.test.js test/pi-file-browser.test.js
PLAYWRIGHT_MODULE=/path/to/playwright node test/browser/pi-file-browser.cjs
PLAYWRIGHT_MODULE=/path/to/playwright PI_FILE_TEST_URL=http://127.0.0.1:3118 node test/browser/pi-file-viewer.cjs
```

Node 测试使用独立临时项目/Agent 目录，验证完整文本与版本、软链接/私密路径、文件变化、FIFO/编码/二进制/大小/并发边界、鉴权及不启动 worker。浏览器使用 mock REST/WS，在桌面与手机验证写入记录、历史与当前区分、显式刷新、Markdown/源码/高亮/行号/换行/复制、文件链接、空/缺失文件、来源/线程迟到结果、刷新恢复和旧后端降级，不调用真实模型或修改用户文件。

本次项目目录功能在 Linux 上完成接口与 Chromium 合成验证；macOS／Windows 复用已有原生描述符后端，本批未新增这两个平台的实机验收。

磁盘全文需当前实例fileViewer能力可用，更新后按实际状态核对；旧后端降级展示不代表支持磁盘读取。
